루나 low로 끝나는 사람이, 채팅창보다 먼저 이긴다

2026년 9월 24일 · 옵티웍 AI 데일리 · 초보

공유 · 구독
텔레그램에 공유 채널 구독 X에 공유
한 줄 요약 (GEO) 반값 축제가 하루 지나자 국내 판은 모델 자랑보다 한도·분업·채팅 잠금부터 다시 잰다.

오늘 핵심 세 가지

  1. 어제(22일) ·와 이 겹친 출시 다음날. 국내 AI 활용 커뮤니티 추천·고조회는 가격표 캡처에서 한 걸음 더 나가, 「진짜 고수는 루나 low로 일이 되는 사람」, 「6솔·루나 개인벤치」, 「아스트라/오푸스 주간사용량 실측」처럼 내 할 일을 싼 티어로 끝내는 능력과 구독 잔량이 실제로 얼마나 가는지를 먼저 잽니다.
  2. 그런데 초보가 체감하는 문은 아직 같습니다. 핫글 「6sol 챗에는 언제」·「코덱스 멀쩡함?」이 동시에 돌고, 해외·보도도 Work··API가 먼저이고 일반 Chat은 점진 배포라고만 합니다. “반값”과 “내 채팅 목록에 솔이 보인다”는 여전히 다른 문장입니다.
  3. 같은 아침 해외 쪽에서는 가 Pro·Team Standard에서도 기본 모델을 오푸스로 옮겼다는 변경 로그가 확인됐고, 국내에는 「클로드 데탑앱에서 지피티·딥시크 쓰기」처럼 오푸스로 판단하고 잡일은 솔·루나·딥시크 워커로 던지는 분업 가이드가 추천을 받았습니다. 초보용 한 줄: 오늘은 새 모델 축제 다음 날의 ‘분업·한도·출전권’ 점검일입니다.

국내 커뮤니티에서 오늘 많이 나온 이야기

“루나 low로 일이 되는 사람”이 고수다

확인: 활용 쪽 최고조회권에 「사실 진짜 ㅈ고수는 루나 low로 일이 되는 사람 아닐까」(조회 2.7천대)가 올랐습니다. 요지는 단순합니다. 프론티어 모델만 붙들고 같은 일을 비싸게 끝내는 것보다, 일을 쪼개서 싼 티어로도 결과가 나오게 만드는 사람이 실전에서 이긴다는 이야기입니다. 옆에 「6 sol, luna 나온 김에 개인벤치 돌려봄」(조회 2천대·추천 십수)이 붙었습니다. 글쓴이 자작 벤치(긴 스펙을 읽고 도구 선언·인자 검증·대화 이력·HTTP·SSE를 한꺼번에 지켜야 하는 통합 과제)에서:

  • [[GPT-6 솔]] high: 33/34, 약 10분, 토큰 약 161만 — “메인으로 쓸 수 있는 구간”
  • [[GPT-5.6 솔]] high: 33/34, 토큰 약 46만 — 점수는 비슷한데 6솔이 토큰을 훨씬 더 씀
  • [[GPT-6 루나]] high: 23/34 — 도구 선언·변환에서 연쇄 실패, 메인 후보에서 탈락
  • 오픈 계열(큐웬 3.8 Flash/Max, 딥시크 Flash 등): 32/34 전후 — “메인 가능” 문턱은 넘지만 우열을 1점으로 가르지 말라는 주의

미확인: 이 자작 벤치가 당신 업무(짧은 요약 vs 긴 에이전트)와 같은지. 초보가 가져갈 태도: 점표 1등보다 ‘루나로 초안 → 솔로 한 번만 다듬기’가 내 일에서 되는지를 하루만 실험.

아스트라 vs 오푸스 5.5, 주간 한도를 숫자로

확인: 「아스트라 / 5.5푸스 주간사용량 실측」이 추천·고조회로 올랐습니다. MAX 20·Pro 기준으로 주간 100%까지 쓴 데이터라며 글쓴이가 올린 환산은 대략 이렇습니다.

  • : 약 7.2억 토큰 / API로 환산하면 큰 금액
  • [[오푸스 5.5]]: 약 116억 토큰 / API 환산도 크지만, 같은 구독 막대 100% 안에서 쓸 수 있는 토큰 양이 아스트라 쪽보다 훨씬 크다(글 기준 약 15배)는 해석

댓글·주변 핫글(「클코 빡세게 안 굴리면 프로 사용량 널널」, 「이젠 토큰 모자랄 일 없겠네」)은 클로드 쪽 한도 체감이 어제보다 넉넉하다는 방향으로 모입니다. 앤트로픽이 출시 때 “5시간 한도 상향·리셋권”을 말한 것과 결이 같습니다.

미확인: 글쓴이 환산식·작업 길이·플랜이 당신과 같은지. API 달러와 구독 %는 다른 저수지입니다. “오푸스가 15배 싸다”고 친구에게 단정하지 말고, 내 주간 막대가 평소보다 천천히 내려가는지만 이틀 적으세요.

채팅은 잠금, 코덱스·Work는 먼저 — 그리고 “사용량 장난?” 의심

확인: 챗지피티 핫에 「6sol 챗에는 언제」, 「6sol 뭔가 글쓰기 성능이 애매하다」, 「코덱스 멀쩡함?」이 보입니다. 댓글 한쪽은 “솔6로 잘 돈다”, 다른 쪽은 첫 채팅만 되고 무한 로딩이라고 합니다. 활용 핫 「Codex 사용량 … 증거」는 같은 작업을 사흘 반복했는데 퍼센트와 토큰 숫자가 어긋난다(30%≈7.6억 → fast 켠 날 70%≈9.5억 → 리셋권 날 30%≈9.6억)는 개인 로그를 올렸습니다.

미확인: 회사 정책으로 “퍼센트를 줄였다”가 맞는지. 모드(fast)·리셋권·캐시·작업 길이가 섞이면 퍼센트와 토큰은 어긋날 수 있습니다. 초보는 음모로 퍼뜨리지 말고, 아침·저녁에 잔량 %와 ‘오늘 한 일 세 줄’만 같이 적어두세요.

「혼자만 안 돼도 터졌다고 하는 건 자유지만 분간이 안 된다」는 추천글은, “서버 터짐” 글이 매일 올라와도 한 페이지를 도배할 급이 아니면 대규모 장애로 읽지 말라는 냉각수입니다. 댓글도 “99%는 잘 씀 / 안 되는 사람만 글을 쓴다” 쪽입니다.

클로드 데탑에 솔·루나를 붙이는 분업

확인: 「클로드 데탑앱에서 지피티, 딥시크 등 쓰기 정리」가 추천권입니다. 요지: 공식 “타사 모델 게이트웨이”를 켜면 앱 모드가 바뀌어 채팅·리모트·커넥터가 죽는데, 커뮤니티 도구(오픈소스)로 코드 탭·서브에이전트만 다른 모델이 답하게 하면 클로드 로그인·편의성은 유지된다는 설명입니다. 글쓴이 패턴은 메인은 오푸스/페이블로 판단, 잡일은 6솔·루나·딥시크 워커. “클로드 한도가 훨씬 오래 간다”는 체감이 붙습니다.

미확인·주의: 타사 모델을 구독·API로 붙이는 행위는 이용약관·보안·계정 정책을 본인 책임으로 확인해야 합니다. 초보에게는 “설치하라”가 아니라 ‘한 앱에서 모든 모델을’ 원할 때 공식 설정과 커뮤니티 우회의 트레이드오프가 있다는 정보만 전달합니다. 공식만 쓰려면 Work/Codex/클로드 코드에서 모델 목록만 확인해도 됩니다.

챗지피티 쪽: 멍청해짐·앱 퇴보·프로·탈옥

확인: 「지피티 왜 다시 멍청해짐?」, 「대화수준 저능아」, 「앱 편의성 퇴보·웹 최적화 악화」, 「플러스인데 무료랑 차이 없다」, 「아스트라랑 솔 차이를 못 느끼겠다」가 추천·핫에 이어집니다. 「gpt 프로는 좀 다를까여?」는 월 3만 원대 구독자가 와 프로 업그레이드를 같이 고민하는 글인데, 어제와 같이 클라우드 구독 티어와 로컬 GPU는 별개라는 댓글 합의가 유지됩니다. 「오푸스5.5 탈옥 … 역대급으로 어려웠다」는 핫은, 새 모델의 안전장치가 체감으로 단단해졌다는 개인 후기입니다.

미확인: 의도적 너프 여부. 운영 휴리스틱은 그대로 — 새 창, 짧은 수정 루프, 첫 결과 고점을 먼저 쓰고, “프로로 올리면 5090이 살아난다”는 기대는 버리세요.

벤치 표·바이브코딩·로컬·일상

「아스트라만 왜 하이로 비교해놨노」, 「하이가 더 높게 나오니까 하이로 비교해준 거다」는 회사 표가 특정 모드만 고른다는 불신이 출시 다음날에도 이어짐을 보여 줍니다. 「바이브코딩의 위험성을 예견한 90년대 애니메이션」·「제일 생산성 없는 일: 게임 만들기」는 “AI로 게임 만들기”가 재미는 있지만 품 대비 결과가 안 나오는 전형이라는 자기조롱입니다. 「M5U 성능 궁금한 로컬LLM단」은 Mac Studio급 로컬 후기 링크 공유(조회 2천대) — 로컬 관심은 있으나 오늘은 주인공이 아닙니다. 이미지·점메추·컬러테마는 짧게만: 놀이 채널과 업무 파이프라인은 분리.

해외·언론에서 교차 확인한 것

채팅 잠금은 보도와도 맞다

확인: 오픈AI 개발자 커뮤니티·TechCrunch 계열 보도 요지 — 솔·루나는 ChatGPT Work·Codex·API에 먼저, Free/Go는 데스크톱에서 루나, 일반 Chat은 점진. “목록에 없다”는 국내 핫과 같은 레이어입니다.

Claude Code, Pro도 오푸스 기본

확인: 클로드 코드 changelog·외신(9월 23일 전후) — Pro·Team Standard 기본 모델이 소넷에서 오푸스(오푸스 5.5) 로 바뀌었다. /model로 바꿀 수 있고, 잠금은 아닙니다. 구독 한도(5시간·주간)는 달러 청구가 아니라 허용량으로 깎입니다. 국내 “프로 사용량 널널 / 오푸스 기본” 체감과 맞물립니다.

Artificial Analysis·가격 전쟁 해석

HN·블로그에는 클로드 속도·솔/루나 공식 페이지·오푸스 5.5 Intelligence 분석이 올라 있습니다. AA 쪽 분해(커뮤니티·뉴스레터 인용): 오푸스 5.5 max의 작업당 비용이 이전 오푸스 max와 비슷해 보이는 이유는 토큰을 더 쓰는 효과와 단가·캐시 인하가 상쇄되기 때문이라는 설명입니다. “40% 싸다”는 기본(medium) 작업 이야기에 가깝고, max로 끝까지 밀어 붙이면 체감이 달라질 수 있습니다. 국내 “토큰 괴물” 담론과 같은 방향입니다.

Reddit RSS는 이번 수집에서 차단

이번 아침 Reddit(r/LocalLLaMA, r/MachineLearning, r/ChatGPT) RSS·JSON은 403/Blocked. 해외 교차는 HN RSS·영문 보도·뉴스레터 요약으로 보완했습니다. 로컬 쪽은 큐웬4·오픈웨이트 로드맵 이야기(2차 요약)가 있으나, 국내 판의 주인공은 여전히 구독 한도·분업입니다. 로컬 기준(RTX 5090 Laptop 24GB / 64GB RAM) 사용자에게는 “클라우드를 로컬로 대체”보다 양적 작업은 루나·소형, 깊은 판단만 프론티어가 오늘 감정과 맞습니다.

오늘 판을 한 문장으로

국내 커뮤니티는 출시 축제를 끝내고, 루나로 끝낼 수 있는 일과 솔·오푸스가 필요한 일, 채팅에 아직 없는 모델, 주간 막대가 실제로 얼마나 가는지를 같은 화면에 올려 두고 있습니다.

목적별 모델 고르기 (한국어)

영문 리더보드만 보면 헷갈립니다. 사이트에 목적별 모델 고르기를 두었습니다. 할 일(코딩·글쓰기·대량·오픈웨이트)을 고르면 가성비 / 가장 좋음 / 가장 쌈이 한눈에 나옵니다.

확인(벤치 스냅샷 2026-09-23 서울, 오늘 풀 리프레시 없음):

  • 가장 좋음(종합): Claude Opus 5.5 (max+fallback) — Intelligence 58, 작업당 약 $5.98
  • 코딩 가성비: GPT-6 Sol (max) — Coding Agent Index 약 57, 작업당 약 $1.06
  • 대량·초저가: GPT-6 Luna (max) 작업당 약 $0.07 / Luna (low) 약 $0.0045 대역
  • 오픈웨이트 참고: MiMo-V2.6-Pro — Intelligence 46

한 줄: 점수는 Opus, 코딩 가성비는 Sol, 싸게 많이 돌리려면 Luna. 오늘 국내 개념글이 말하는 “루나 low로 일이 되는 사람”과 같은 방향입니다. 표만 외우지 말고 목적별 모델 고르기에서 내 할 일에 맞춰 고르세요.

미확인: 내 채팅·Work 드롭다운에 같은 모델이 보이는지, 갤 개인벤치·주간 실측이 내 작업에서도 같은지.

오늘이 의미하는 것 · 바꾸지 말 것

의미: “어떤 모델이 똑똑한가”에서 어떤 일을 어떤 티어·어떤 화면(Chat/Work/Codex/클로드 코드)에 올릴까로 질문이 이동했습니다. 반값 API는 개발·Work 유저에게 먼저 열린 문이고, 일반 채팅 구독자의 출시일은 목록에 아이콘이 뜨는 순간입니다.

바꾸지 말 것:

  • Codex 퍼센트·토큰 어긋남을 “회사가 몰래 깎는다”로 단정·전파하지 말 것
  • 주간 15배 실측 글을 내 플랜·내 작업의 공식 수치처럼 인용하지 말 것
  • 채팅에 솔이 없다고 해서 API/Work 가격 인하가 “가짜”라고 말하지 말 것
  • 클로드 데탑 타사 모델 우회를 약관 확인 없이 남에게 설치 강요하지 말 것
  • GPT 프로 업그레이드와 5090 성능을 한 문장으로 묶지 말 것
  • 데브데이·다음 주 기대만으로 이번 주 잔량을 다 태우거나 당장 해지하지 말 것

출시 다음다음 날 초보 루틴

  1. 모델 목록 스크린샷(채팅 / Work / Codex / 클로드 코드 각각) — 어제와 무엇이 새로 생겼는지만 동그라미.
  2. 같은 질문 하나를 지금 기본 모델과, 열리면 루나 초안 → 솔 한 방으로만 비교(길이·실수·잔량 세 줄).
  3. 주간·5시간 잔량 %를 아침·저녁 한 번씩만 적기(퍼센트와 ‘오늘 한 일’을 같은 메모에).
  4. “루나 low로 끝낼 수 있는 일” 후보 세 개를 적어 프론티어 예산을 아끼기.
  5. 구독 갱신이 가깝면 데브데이 관전 후로 결정을 미루되, 잔량·출전권 메모는 오늘부터.

시도 후보

  1. Work/Codex에 솔·루나가 보이면, 루나로 초안 → 솔로 한 번만 다듬기를 하루만 실험(토큰·시간·잔량 %).
  2. 클로드 오푸스 5.5(또는 클로드 코드 기본 오푸스)를 쓸 거면, 같은 작업을 짧은 지시 vs 긴 에이전트 루프로 나눠 총 사용량 차이 보기.
  3. 일반 채팅에 GPT-6이 아직 없으면, 불만 글만 쓰지 말고 할 일 목록을 Work 쪽으로 옮길지 오늘 결정.
  4. 「주간사용량 실측」식을 따라 하지 말고, 내 플랜 기준으로 월~수 잔량 곡선만 그려 보기.
  5. 로컬·소형으로 빼도 되는 판정·요약 한 가지를 정해 프론티어 예산을 아껴 보기.
  6. 게임·바이브코딩 장타는 “재미 예산”으로만 분리하고, 업무 잔량과 섞지 않기.
  7. Muse·고권한 에이전트·타사 모델 우회를 쓴다면 권한·약관을 최소·확인 후에.

가격표를 내 언어로 바꾸는 법 (출시 다음날 버전)

오픈AI·앤트로픽이 내놓은 숫자는 여전히 API 100만 토큰당 달러입니다. 구독 화면의 주간·5시간 막대는 퍼센트입니다. 오늘 국내 실측 글이 추가한 세 번째 언어는 **“같은 100% 안에서 몇 억 토큰이 나오느냐”**입니다. 초보가 섞지 말아야 할 번역:

  • API 반값 → 개발·자동화·Work에서 같은 예산으로 더 많은 호출이 가능하다는 신호 (채팅 목록과는 별개)
  • 구독 잔량 % → 여전히 별도 저수지. 모델·모드(fast)·리셋권을 바꾸면 같은 %가 다른 토큰 양을 의미할 수 있다
  • “오푸스 주간 토큰이 더 많다” → 그 글쓴이 플랜·작업의 관측. 내 막대가 천천히 줄어드는지만 확인
  • “6솔이 5.6솔과 점수 같은데 토큰을 더 먹는다” → 개인벤치 한 줄. 성공 한 번에 몇 분이 드는지를 내 메모에 적는 쪽이 싸움에 이깁니다

그래서 시도 후보에 “루나 초안 → 솔 한 방”과 “잔량 % + 오늘 한 일”을 같이 적으라고 한 것입니다. 남의 15배·33/34보다 내 메모 세 줄이 싸웁니다.

구독 고민이 가까운 사람에게

핫·추천에 「학식충 … 프로로 넘어가려 했는데 클로드 고민」, 「웹쫀쿠 버리고 오오푸스 쓸까요?」, 「oai 데브데이 보고 다음 구독 정하면 되겠네」, 「플러스인데 무료랑 차이 없다」가 동시에 보입니다. 초보용 정리:

  1. 오늘 나온 반값·한도 실측만 보고 바로 해지/이관하지 말 것.
  2. 채팅·Work·Codex·클로드 코드에 무엇이 보이는지 스크린샷.
  3. 이번 주 잔량이 평소보다 빨리/천천히 닳는지 이틀만 적기.
  4. 데브데이·다음 주 발표는 보너스 일정이지, 이번 주 카드 청구를 대신해 주지 않습니다.

오픈AI와 앤트로픽이 같은 주간에 싸움을 붙인 것은 선택의 폭이지만, 한도·토큰·출전권이 제각각이라 “싼 쪽만 고르면 된다”는 말은 틀리기 쉽습니다. 할 일을 ‘짧은 양적 작업 / 깊은 코딩 / 글쓰기 / 이미지’로 나누면 루나·솔·오푸스·로컬이 각각 다른 칸에 들어갑니다. 을 버릴지 말지는 프로 화면에서 솔이 보이는지·잔량이 버티는지를 본 뒤에 결정해도 늦지 않습니다.

장애 글과 품질 하락 글을 읽는 법

챗지피티 쪽에는 매일 “터졌다”, “멍청해졌다”, “정신병 걸린 듯” 글이 올라옵니다. 오늘 추천글이 가르쳐 주는 필터는 단순합니다. 한 페이지를 도배할 급이 아니면 대규모 장애로 읽지 말 것. 품질 하락 체감은 (1) 긴 대화가 쌓인 스레드, (2) 새 모델 출시 직후 라우팅 변경, (3) 내 프롬프트가 어제와 다른 경우 — 세 가지를 먼저 의심합니다. 대처는 거창할 필요 없습니다. 새 채팅, 짧은 지시, 같은 질문을 두 모델에만 비교. “나만 안 된다”를 전체 장애로 키우면, 정작 필요한 Work/Codex 출전권 확인을 놓칩니다.

이미지·검열·가상 인물 SNS·점메추는 오늘도 추천란에 섞입니다. 출시 다음날의 주인공은 한도·분업·채팅 잠금이니, 이미지 프롬프트 공유는 커뮤니티 놀이로만 읽고 업무 잔량과 섞지 마세요.

로컬·맥 리퍼·헤르메스는 짧게만

「M5U … 로컬LLM단」·「애플 리퍼비쉬 Mac 풀림」·「헤르메스 키고 …」처럼 로컬·하드웨어·성인 필터 우회 이야기도 추천란에 보입니다. 오늘은 클라우드 분업·한도가 주인공이라 깊게 풀지 않습니다. 로컬을 이미 쓰는 분(예: RTX 5090급)에게만 한 줄: 양적 작업은 로컬·루나, 깊은 판단만 클라우드 프론티어로 나누는 그림이 오늘 국내 감정과 가장 잘 맞습니다. 리퍼 맥·통합 메모리 이야기는 “살지 말지”를 오늘 결정하라는 신호가 아니라, 로컬 예산이 있는 사람용 참고 링크로만 두세요. 필터·성인 관련 우회는 브리핑에서 따라 하지 말고, 정책·법적 위험을 본인 책임으로 판단하세요.
