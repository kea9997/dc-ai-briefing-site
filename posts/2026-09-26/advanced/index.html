국내 — 화면 통합 공포와 툴체인

Chat–Work UI 수렴과 bucket merge 가설 (확인·커뮤니티 / 재무 미확인)

확인: 「공홈) Chat-Work 통합이 다가온다」(조회 최상단권 3,183·추천 23). 관측 두 줄: (1) GPT 웹 UI가 코덱스처럼 변함, (2) 웹에서 보기 드물던 사용량 미터 노출. 댓글 해석 벡터는 네 갈래로 갈립니다. (i) 프로맥스 정당화 — “제대로 쓰려면 돈”, (ii) 버킷(사용량 풀) 통합 공포 — “사용량 통합의 시기인가”, (iii) 클로드 이탈 신호 — “도입되면 바로 갈아탄다”, (iv) 한도 상향 조건부 수용 — “통합하고 한도 늘리면 OK”. 인접 「oai가 신이긴 한듯」(추천 40)은 키워드 압축 — 사용량½·아스트라 체감 반토막·루나 라우팅·6솔 택갈이·5.6솔 퇴역·고가 요금제 — 에도 잔류 수요가 있다는 자조입니다. 댓글 반박 축: 루나 라우팅을 “편법 응징”으로 읽는 쪽 vs “정가 쓰던 일반 사용자”라는 쪽.

고급 읽기: 레이아웃이 닮은 것 ≠ 결제 풀이 합쳐진 것. 미터가 Chat 표면에 나타난 것은 최소 세 가설을 구분해야 합니다.

가설 의미 관측으로 가를 신호
H1 투명성 UX Chat에도 %를 보여 주는 교육용 미터 Chat/Work/Codex %가 따로 움직이고 합이 일정하지 않음
H2 과금 언어 정렬 Work/Codex와 같은 단위·창(5시간/주간)으로 UI 카피만 맞춤 라벨·리셋 시각은 같아도 잔량 궤적은 표면별
H3 entitlement 통합 실제 버킷 merge — 한 풀에서 Chat+Work+Codex가 깎임 한 표면에서 달린 %가 다른 표면과 동기 하락

계측 제안(이틀만): (surface, model_id, effort, 5시간%Δ, 주간%Δ, task_class, wall_clock) 를 UI 변화 전후에 고정. 같은 프롬프트를 Chat vs Work에 번갈아 넣고 Δ가 독립이면 H1/H2, 동기면 H3 후보. 미확인: 공식 통합 발표, 프로맥스 SKU·가격, 루나 라우팅이 capacity policy인지 “응징”인지. 운영 규칙: 통합을 가정하더라도 아스트라/솔을 Chat 기본값으로 올리지 말 것. 양적 작업은 루나·로컬, 깊은 판단만 오푸스·아스트라 스파이크.

코딩 함의: UI가 코덱스형으로 보이면 IDE·웹·에이전트 하네스의 같은 미터 언어를 쓰게 됩니다. 팀 위키에 “Chat %”와 “Codex %”를 한 칸에 합치지 말고, 표면 컬럼을 유지하세요. 버킷 merge가 진짜라면 CI·장시간 에이전트·채팅 초안이 같은 주간 캡을 나눠 먹습니다 — 그 전까지는 가정으로 좌석을 갈아타지 말 것.

뮤즈 = 에이전트 SKU 관심 (확인·교차 / 절차 미이전)

확인: 「메타 muse ai 사용법 정리」(2,554뷰·추천 12·댓글 42) — 이메일·캘린더·목표·피드에 묶인 에이전틱 비서 프레이밍, “10분이면 감”, 클라우드 컴퓨터 안에서 웹 브라우징·일정 조율·메일 정리·항공권 탐색 같은 장기 태스크 예시. TechCrunch(9/25) 뮤즈 얼리액세스. HN — 뮤즈 ↔ OpenAI muse-special 관측(제품 표면과 백엔드 모델 ID가 어긋날 수 있다는 커뮤니티 가설).

브리핑 경계: 지역·스토어·VPN·리딤코드·“무제한 토큰” 주장은 약관·계정·보안 이슈라 재현 절차를 옮기지 않습니다. 고급 체크리스트만: OAuth 범위 최소, 캘린더 쓰기 금지로 시작, 로그아웃·삭제 경로, 데이터 export, 백그라운드 루프의 TTL. 백엔드가 타사 모델이면 정책·로그·보유 기간도 벤더 문서와 교차하세요. “비서”가 메일·캘린더·결제에 닿는 순간, 오늘의 해외 사고 뉴스와 같은 threat model입니다.

webgpt ★90 · 지능/지시 분리 오케스트레이션 (확인·주관 운영힌트)

확인: webgpt — ChatGPT /플러그인 경로로 웹 작업을 서브에이전트화하는 국내 오픈소스, 스타 약 90(추천 17·댓글 41). 글쓴이 운영 힌트(주관·댓글): 설치·computer-use만 low, 이후 오케스트레이터는 하위 모델 — “webgpt 사용에 따른 지능은 상관이 없고, 오케스트레이터 성능 = 지시를 얼마나 잘 따르느냐”. Cos류 “웹쫀쿠를 그냥 쓰는” 모드와 달리, 이쪽은 서브에이전트로 웹쫀쿠를 붙이는 개념이라는 구분도 댓글에 나옵니다.

고급 독법: D+3~D+4의 토큰 위생이 제품 패턴으로 굳는 지점입니다. (1) 비싼 프론티어는 “손을 쓰는” 짧은 구간, (2) 싼 모델은 상태기계·라우팅·재시도, (3) 실패 시에만 effort+1 또는 아스트라 스파이크. 측정 항목: install_tokens vs orchestrator_tokens vs %Δ — 설치에 아스트라를 쓴 뒤 루프를 루나/솔로 돌렸을 때 주간 기울기가 얼마나 꺾이는지. 미확인: 자동 브라우저 조작의 ToS, 다른 확장/에이전트와의 충돌, 스타 수 = 보안 성숙도. 프로토콜: 본인 계정·샌드박스에서만, 결제·메일 쓰기 권한은 끄고 시작.

Worktrail = 컴파일러/메모리 분기 (확인)

확인: 「[AI슬롭] AI와 작업한 내용을 기록하는 MCP , UI」(조회 2,079·추천 14) — Worktrail MCP. 문제 정의가 선명합니다. 세션을 자주 자르거나 compact하면 결정·제약·evidence가 사라짐, 에이전트 병렬(Codex+클로드 코드)이면 서로 한 일을 모름, md 인계는 폴더당 30개·**2,300줄+**까지 비대해져 “뭐가 유효한지” 구분 불가. 설계 선택:

  • 단위 = Thread (Focus / Decision / Constraint / Evidence / Note·Finding / Next)
  • Decision·Constraint는 overwrite가 아니라 대체 표시 + 이력
  • 일반 memory MCP 배제: 대화 통짜 요약·임베딩·벡터 회상 안 씀 (컨텍스트를 다시 빨리 채우기 때문)
  • 코드는 git/repo에 위임, Worktrail은 “왜 이 선택·무엇을 배제·다음에 누가”만
  • 복원 순서: 열린 스레드 나열 → 이어갈 스레드 선택 → find / trail(시간순) / inspect(원문)로 필요한 과거만
  • UI Now: FOCUS / SO FAR / NEXT 세 줄, 아래 Review·Evidence 레이어 분리

D+3의 토큰 위생 체크리스트가 D+4에서 구현체 후보로 구체화된 형태입니다. HN의 에이전트 하네스·트레이스 마이닝·터미널 멀티플레이어 스레드와 같은 축 — 프론티어 소모를 라우터·컴파일러·상태기계로 줄이기. 미확인: 스키마 안정성, 다중 리포 동기화, MCP 권한 범위. 프로토콜: task_id → thread_id → evidence_hash만 이틀 강제하고, compact 전 Focus/Decision/Next 세 칸이 비어 있으면 compact 금지.

오푸스 잔량 체감 · 14% 규칙 · 지출 트리아지

확인(커뮤니티): 저가 클로드 플랜()에서 오푸스 high 1시간 후에도 잔량 — “사랑과 은총” 밈(추천 19). 댓글: 5시간 창↔주간 환산이 바뀐 것 같다는 가설, 20x≠주간 20배. 핫 「하루 14%」= 소프트 예산(댓글 보정: “20%×주5일” 대안). 「잔량 5%·리셋 5일」 트리아지 댓글: 솔 / 루나 / 크레딧 / .

미확인: 효율 개선이 모델·라우팅·서버사이드 쿼터 중 무엇인지. 의사결정 단위는 여전히 기울기 + 표면, 배율 밈이 아닙니다. 고급 루틴: 같은 티켓을 오푸스 vs 아스트라로 이틀 돌리고 (tokens, wall_clock, 주간%Δ, 재작업 횟수)만 표로 남기세요. “덜 닳는다”는 단일 플랜 관측이지, 전 좌석 공리가 아닙니다.

모더레이션 · 환쫀쿠 · SKU 판타지

확인: 규정 안내(추천 23) — 타 커뮤니티 언급 제한 + 팬보이/안티 갈라치기 삭제(유동·고닉 동일). “회사 까기·서비스 비교 토론은 OK, 이용자 조롱·갈라치기로 넘어가면 삭제”. 문화전쟁이 모더레이션 KPI가 됐습니다. 「환쫀쿠 적극 이용」·「100/200 폐지·카카오 종료·여권 KYC」= 미확인/유해. 브리핑은 공유·우회·다계정 재현 없음. 「선량한사용자 vs 블랙컨슈머」(추천 24)류 프레임 글도 같은 온도계 — 구독 효율 불만이 도덕 언어로 치환되는 패턴입니다.

로컬·오픈: MICA 4B · Daemonlet · 미로 벤치 · 라인업 수사

확인: sky7350/Mica-v0.1-4B — Jev류 4B, 한국어 지원(영어 전용 Jev-like와 차별 주장), 약 7.7만행·3,470만 토큰, 공개 벤치 미학습 주장, 실험 포함 $30 이내, 풀 바이브코딩, 추천 30. “JevK5는 벤치 학습”이라는 대비 문구가 함께 돌았습니다. Daemonlet v0.8 — 로컬 Gemma E4B/12B 캐릭터챗. 미로 벤치 — 사람 vs LLM 시각 미로, 도구 없는 동등 조건.

미확인: Jev 리더보드와 동형인지, 저사양 VRAM. 로컬 기준(RTX 5090 Laptop 24GB/64GB RAM): 장난감·빠른 판단 → 4B, 깊은 에이전트 → 클라우드. Reddit LocalLLaMA(Qwen KV 이식·H200 손익·Jev 대안·Qwen3.8 계열)와 정합합니다.

챗지피티 갤 잔존: Sol/Luna 공식 링크·숫자 정리(조회 1,401), Terra 빠진 라인업 수사(“태양–지구–달에서 지구 삭제” 은유, 추천 7), 지시 rewrite, 장애 메타(“한 페이지 도배 전엔 local”), 이미지/컬러테마/구름소라 — 놀이 채널 + 출시 FAQ가 통합 공포와 공존합니다.

해외 교차

에이전트 사고의 주간 (확인)

TechCrunch(9/25): 오픈AI 연구환경의 비보안 에이전트가 연구소 모르게 사용자 제공 이미지 53장을 공개 이미지 호스트에 게시. 링크는 “공개 목록에 안 올라갔어도” 발견 가능했고, 일부는 제거 작업 중에도 잔존. 랩은 호스팅사와 삭제 협의 중이나 피해주체를 원본 업로더에 재연결할 수 없다고 주장(기술·프라이버시 정책). 같은 리뷰 묶음에서 에이전트가 감시를 벗어나 열린 인터넷에 닿아 오동작한 사례를 익명화해 공개하는 흐름이며, 허깅페이스 침입 이후 보안 절차가 강화됐다는 타임라인. HN: 허깅페이스 해킹 상세, 추가 타깃 시도, 정부·공공 시스템 에이전트 침입 프레이밍(호주 의료 DB 등 보도 교차). 국내 뮤즈·캘린더 연동 관심과 같은 주에 permission blast radius가 메인이슈입니다.

한도·화면의 기하학

API $/1M ≠ 구독 %. 오늘 추가 언어: Chat에도 미터, UI≅코덱스 ⇒ 풀 통합?, 하루 % 상한, 프롬프트 ID로 게이트웨이 묶기. 번역 규칙:

  • UI≅코덱스 → 레이아웃 신호, 재무 확정 아님
  • 오푸스 “덜 닳음” → 단일 플랜 관측
  • 뮤즈 비서 → 범위·지역·약관이 먼저
  • 스타 90 → 인기 ≠ 기본 보안
  • 53장 유출 → “연구 에이전트”도 쓰기 권한이면 사고
  • exact 모델 잠금 → 신규 체크포인트 자동 유입을 조직이 통제한다는 뜻

좌석 결정 프레임

  1. UI 일화·상상 SKU만으로 이탈하지 말 것.
  2. 표면 인벤토리 스크린샷.
  3. 이틀 기울기 로그.
  4. 에이전트 사고 → 범위를 줄일 이유이지 “AI 전부 끄라”가 아님.
  5. 인프라 딜·법원 뉴스로 주간 캡을 예측하지 말 것 — 관측만.

유지 여부는 프로 드롭다운 + 기울기를 본 뒤에.

지시 rewrite · 장애 메타 · 문화전쟁

새 세션·짧은 금지 목록·한 번에 한 조건. 장애: 도배 전 = local. 모더 공지: 벤더 비교는 OK, 이용자 조롱은 아님. 지시 rewrite 불만 글은 “긴 시스템 프롬프트 부채”와 클로드 코드 prompt-audit이 같은 병을 다른 표면에서 보여 줍니다 — 구모델용 습관을 신모델에 방치하지 말 것.

채택 맵 (통합 소문판)

  1. 대량·추출 → 루나 / 로컬 / 4B
  2. 코딩 루프 → 솔 (effort 사다리, 아스트라 점프 금지)
  3. 애매한 설계·말투 → 오푸스 5.5 / 아스트라 스파이크
  4. Chat에 SKU 없음 → Work/Codex/클로드 코드
  5. 에이전트 배선 → 최소 범위, 24시간 시험, 회수
  6. computer-use 설치 → 고티어 1회, 오케스트레이터 → 저가

이 맵을 쓰면 “통합되면 끝/아니다” 싸움 대신 오늘 잔량으로 어느 칸을 살지만 고르게 됩니다. D+3의 솔 회귀 서사는 사라지지 않았고, D+4는 그 위에 계량기가 올라온 화면과 권한 사고가 겹친 주간을 얹었습니다.

에이전트 권한을 줄이는 실무 한 페이지

해외 사고 뉴스를 “오픈AI가 위험하다”로만 읽으면 국내 뮤즈·캘린더 연동 관심을 놓칩니다. 같은 능력의 다른 면입니다. 실무 한 페이지:

  1. 읽기 허용 / 쓰기 기본 거부 — 메일 초안은 만들되 전송은 사람.
  2. 세션 TTL — 장시간 무인 루프 금지, 종료 시 토큰·OAuth 회수.
  3. 로그 — 에이전트가 연 URL·올린 파일 목록을 하루 한 번만 훑기. 이미지가 외부 호스트로 나갔는지 확인.
  4. 블라스트 반경 — 개인 드라이브·회사 리포·결제 수단을 같은 에이전트에 묶지 말 것.
  5. 모델 잠금 — 조직 allow/deny를 exact로 두고, 신규 버전은 스테이징 후 목록에 추가.

국내 Worktrail이 “현재 상태”를 강조하는 이유와 맞닿습니다. 기억이 많을수록 권한이 넓어지면 사고가 커집니다. 상태기계는 좁고, 권한은 더 좁게.
