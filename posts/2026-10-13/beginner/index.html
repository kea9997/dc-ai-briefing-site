메타가 판에 다시 끼어든 날, 센 모델은 API 문 밖에 있었다

2026년 10월 13일 · 옵티웍 AI 데일리 · 초보

공유 · 구독
텔레그램에 공유 채널 구독 X에 공유
한 줄 요약 (GEO) 원더 풀은 소넷과 점수가 같은데 구독 도구 안에서만 열리고, 티보는 투표 결과에 헷갈린다고 썼다. 오늘은 ‘어디에 붙어 있느냐’가 점수만큼 중요해진 날이다.

오늘 핵심 세 가지

  1. 메타가 새 모델 두 개를 냈고, 센 쪽은 일반 API로 안 나왔다. 10월 12일(미국) 메타는 와 을 공개했습니다. 벤치 점수 모음인 기준으로 Wonder Full(최고 설정)은 지능 지수 56으로 Claude Sonnet 5.5와 같고, API로 열리는 Wonder(최고 설정)는 52점·작업당 약 $4.52입니다. 국내 게시판에는 아직 리뷰가 거의 없고, 해외 해커뉴스·Reddit에서는 “프론티어에 돌아왔다”는 메타의 말과 “센 쪽은 API가 없다”는 조건이 동시에 화제였습니다.
  2. 티보는 투표 결과에 “헷갈린다”고 썼고, 같은 날 Sol 컨텍스트를 크게 늘렸다. 오픈AI 코덱스 책임자 는 10월 12일 새벽(서울) X에서 “Pro가 5시간 제한을 되돌리는 대신 주간 사용량 2배를 고를 줄 알았는데, 결과가 그쪽이 아니었다”고 했습니다(조회 약 179만). 같은 시각 7일차 발표는 Codex·Work에서 GPT-6.1 Sol 기본 를 27만2천에서 50만으로 올리고, 구독 사용량으로 쓸 때는 긴 컨텍스트 추가 요금을 받지 않겠다는 내용이었습니다. 국내에서는 “5시간 제한 안 하겠다던 예전 말” 캡처와 투표 후기가 다시 수천 조회를 받았습니다.
  3. 코드는 늘었는데 소프트웨어는 그대로라는 해외 연구, 국내에선 ‘잔여 프로세스’와 ‘앞머리 대각선’이 개념글이 됐다. 하버드 연구진이 718개 회사를 본 작업 논문(아스테크니카 등 중계)은 AI 코딩 에이전트 도입 뒤 코드 줄 수·커밋·풀리퀘스트는 늘었지만, 끝난 이슈·에픽 수는 통계적으로 의미 있게 늘지 않았다고 했습니다. 같은 날 국내 챗GPT 게시판 개념글(추천 47)은 클로드 코드·코덱스 세션이 끝난 뒤에도 node·python 프로세스가 메모리를 먹는다며, 그 ‘고아 프로세스’만 골라 지우는 프로그램을 직접 만들어 올렸습니다. 다른 개념글은 AI가 그린 인물 앞머리 대각선 자국이 흔적이라고 설명했습니다.

국내 커뮤니티에서 오늘 많이 나온 이야기

1) 티보 투표 후일담 — “헷갈린다”와 “5시간 안 하겠다”

확인(X 원문): 티보는 10월 12일 09:21(서울) “이 투표 결과가 나를 헷갈리게 했다. 나는 Pro 100/200/500 전 구간에서 ‘주간 2배 + 5시간 제한 복귀’ 쪽이 훨씬 우세할 줄 알았다. 수요 곡선을 부드럽게 하려고”라고 썼습니다. 직전 투표(10-11 개시·10-12 새벽 마감, 총 약 24만 표)는 ‘5시간 없음 + 지금과 같은 양’ 37.8%, ‘5시간 + 주간 2배’ 33.2%, ‘결과만 보기’ 29%였습니다. 결정은 발표되지 않았습니다.

확인(게시글): 국내 「티보 X) 투표결과 혼란스럽다」(조회 약 4.3천·추천 16), 「티보는 진심으로 당황했을거 같긴함」(조회 약 4.4천·추천 21)은 위 글을 옮기며 “명분 쌓으려다 반대로 나왔다”, “이제 5시간 넣으면 욕만 더 먹는다”고 해석했습니다(미확인 의견). 「티보) 5시간 제한 도입 안하겠다」(조회 약 4.1천·추천 21)는 예전 공지 문장 — “5시간 이용 제한을 다시 도입하지 않기로 결정했습니다” — 캡처 아래에 “한도 반토막 내면서 한 말을 믿어?”라고 적었습니다. 댓글에는 “기존 구독자는 아직 20배, 10월 지나면 반토막” 같은 개인 진술이 섞여 있어, 요금표 원문과 대조하기 전에는 사실로 단정하지 마세요.

확인(7일차): 「티보 X) 7일차 개선사항」(조회 약 3.7천·추천 14) 정리본 — Codex·Work에서 GPT-6.1 Sol 기본 컨텍스트 272k→500k(약 80%↑), 최대는 1M, 직접 바꿀 수 있음. 구독 사용량 차감 시 Sol 긴 컨텍스트 수수료 없음. 티보 원문 두 트윗(10-12 08:45·그 직후, 서울)과 일치합니다.

초보에게 남는 한 줄: 투표·옛 약속·7일차 개선은 서로 다른 층입니다. 요금제를 바꾸기 전에 사용량 화면과 Codex/Work에서 Sol 컨텍스트가 500k로 보이는지만 확인하세요. “헷갈린다”는 말은 정책 확정이 아닙니다.

2) 메타 Muse Wonder — 국내엔 아직 리뷰가 얇고, 조건이 먼저 온다

확인(공식·AA·언론): 메타 연구 블로그·저커버그 X(10-12)·AA 기사(10-12)·벤처비트 정리에 따르면 Wonder는 텍스트·이미지·음성·영상을 입력으로 받고 텍스트를 내며, 컨텍스트는 약 100만 토큰입니다. 가격은 Wonder API 기준 입력 $4 / 출력 $20 / 캐시 입력 $0.20(100만 토큰당). Wonder Full은 토큰 단가가 공개되지 않았고, Muse Code의 Power($50/월)·Maximum($200/월) 같은 상위 구독에서 씁니다. AA: Full(max) 56, Wonder(max) 52·작업당 $4.52. Coding Agent Index는 Full 68, Wonder 63(AA 기사).

국내 반응: 수집 시점(서울 07:58) 기준 국내 핫·개념 상위에 Wonder 단독 리뷰는 거의 없었습니다. 새벽 단문에 “muse가 프롬프팅에 강하다”는 체감 한 줄 정도가 보였을 뿐입니다(미확인). 해외 r/ClaudeAI·r/singularity·해커뉴스(약 482점)에서는 벤치 표와 “Full은 API 없음”, “Contributor 모드 기본값·데이터 학습” 조건이 먼저 읽혔습니다.

초보에게 남는 한 줄: 점수만 보고 “메타가 1등”이라고 말하기 어렵습니다. Opus가 58로 위에 있고, Full은 소넷과 동점이지만 지금 일반 API로는 살 수 없습니다. 써 보려면 Muse Code 구독 조건·데이터 사용 모드를 먼저 읽으세요.

3) 추천 47 — AI 코딩 도구가 남긴 ‘고아 프로세스’

확인(게시글): 「AI 코딩 도구 쓰다가 PC 자꾸 느려져서 메모리 정리 프로그램 만들어봤」(챗GPT 게시판, 추천 47) — 클로드 코드·코덱스 사용 후 node.exe·python.exe가 세션 종료 뒤에도 남아 메모리를 먹는다는 체감. 일반 RAM 클리너는 지금 쓰는 프로그램까지 건드려 불안해서, 고아 프로세스만 골라 정리하는 도구를 클로드 코드로 만들었다고 합니다. 기본 무료·일부 자동 기능 유료, 코드 서명 없어 SmartScreen 경고가 뜬다고 명시. 링크: nondevlab.com/ai-pc-memory-optimizer/

의미(미확인 해석): 어제 ‘완료라고 했는데 흔적이 남았다’는 문서 이야기의 PC 버전입니다. AI 도구가 일을 ‘끝냈다’고 해도, 컴퓨터에 남는 것은 따로 확인할 수 있습니다.

초보 주의: 서명 없는 실행 파일은 SmartScreen 경고가 정상일 수도, 위험할 수도 있습니다. 업무 PC에 바로 설치하지 말고, 작업 관리자에서 node/python이 실제로 남아 있는지만 먼저 보세요. 남아 있으면 해당 도구를 완전히 종료하거나, 공식 문서의 정리 방법을 찾는 편이 안전합니다.

4) 앞머리 대각선 = SynthID?

확인(게시글·공식 링크): 「당신의 캐릭터 앞머리에 대각선이 생기는 이유.synthid」(조회 약 987·추천 7)은 인물 앞머리의 가는 대각선, 완전 흰색이라고 시킨 이미지에 색이 22종인 점, 주파수·RGB 과장본에서 보이는 무늬를 SynthID로 읽었습니다. OpenAI ‘생성 콘텐츠 확인’ 페이지를 출처로 걸었고, ChatGPT·Gemini 생성물에 비가시 워터마크가 들어간다고 정리했습니다(서로 호환되지 않는다고 명시). iPhone 18 Pro 카메라 하드웨어 워터마크 언급은 글쓴이 주장으로, 이 브리핑에서 기기별로 재검증하지는 못했습니다.

초보에게 남는 한 줄: AI 그림의 ‘이상한 획’이 버그가 아니라 표시일 수 있습니다. 공모전·제출물에는 각 서비스의 생성 표시 정책을 확인하세요.

5) 300화 소설 — 파일을 8개로 나눈 사람

확인(게시글): 「GPT로 300화짜리 소설 쓸때 썼던 방법」(추천 13)은 소스 파일을 여덟 갈래로 나눕니다. (1) 작품 설정 통합본 (2) 집필 운영 통합본 (3) 스타일 가이드 (4) 등장인물표 (5) 연속성 관리표(챕터마다 갱신) (6) 전체 시놉시스·사건표 (7) 상세 시놉시스(챕터 단위) (8) 캐릭터 비주얼 설정집(선택). 댓글·연계글은 “계층을 나눠도 주기적으로 전수 조사·갱신·무결성 검사를 시켜야 한다”고 덧붙였습니다.

초보에게 남는 한 줄: 긴 글을 AI와 쓸 때 실패하는 흔한 이유는 ‘모델이 나빠서’보다 무엇을 사실로 둘지 한곳에 안 적어 둬서입니다. 오늘 구조는 그 처방에 가깝습니다. 취미면 1·4·5번만이라도 시작해 보세요.

6) 토큰 아끼기 스킬 — HTML을 모델이 쓰지 않게

확인(게시글·깃허브): 「스킬 하나 추천 해주고 싶어서 들고옴」(조회 약 3.8천·추천 23)은 Archify(github.com/tt-a1i/archify)를 소개합니다. 모델이 긴 HTML을 직접 쓰지 않고 짧은 마크다운만 쓰게 한 뒤, CLI가 약 50ms에 페이지로 렌더한다는 중국어 X 글을 인용했습니다. 인용 수치(Sonnet 5.5 중앙값): 출력 토큰 5341→870(약 6.1배↓), 시간 33초→12초(약 2.8배↑ 속도). 글쓴이는 “공부할 때 좋더라”고 했습니다. 수치는 원 트윗·환경 의존이므로 내 작업에서 그대로라고 보지 마세요.

7) 학생·급식 AI 지원금 논쟁

확인(게시글): 「급식들이나 대학생들은 진짜 AI정부지원해줘라」(조회 약 2.9천·추천 34·댓글 39) — 직장인 글쓴이는 Claude·Codex에 월 $400을 써도 취미로 감당 된다며, 알바로 용돈을 버는 학생에게 AI 구독 지원을 하자는 주장입니다. 댓글은 “GPT 3만 원만이라도”, “지원서만 받아도”와 “세금으로 구독료냐”로 갈렸습니다(의견).

브리핑 위치: 정책 제안이지 확정된 제도가 아닙니다. 다만 오늘 국내에서 추천이 높은 축이 ‘요금·접근권’이었음을 보여 줍니다.

8) 싸게 쓰는 길(쌀먹) 공유 — 조건·위험을 먼저

확인(게시글 존재) / 미확인(각 사이트 조건·지속성): 「쌀먹 정보 공유함」(조회 약 4.3천·추천 12)은 DeepSeek V4.1 Flash·GLM Flash 등을 OpenAI 호환 엔드포인트로 싸게 쓰는 경로를 나열했습니다(Hive 보너스 크레딧, Sail·Experiential 월 리필, Token Harbor 무료 슬롯 등). 글쓴이 본인 잔액·단가 주장입니다.

초보에게 분명히: (1) 보너스·무료 슬롯은 약관·지역·카드 인증 조건이 자주 바뀝니다. (2) 어제·그제 해외에서 나온 ‘샌드박스 API 키 남용’ 경고와 같은 주에 있습니다 — 남의 키·우회·약관 위반은 다루지 않습니다. (3) 이 브리핑은 경로를 추천하지 않습니다. “싸게 쓰려는 수요가 크다”는 신호로만 읽으세요. 공식 앱·공식 API·학교·회사 라이선스가 기본입니다.

해외 커뮤니티 교차 확인

메타 Muse Wonder — 해커뉴스 482점

확인: 메타 연구 블로그·AA 기사·벤처비트. Full은 에이전트형 지식 업무·과학 추론 일부 항목에서 상위권(AA), 지식(AA-Omniscience)은 상대적 약점이나 환각률은 낮다고 AA가 적었습니다. Spark 1.3(max·48) 대비 Full +8, Wonder +4. 작업당 비용 Wonder $4.52는 Spark($1.60)의 약 2.8배(가격·입력 토큰 증가).

  6. 모델판 북마크: /models/에서 Wonder·Wonder Full 행이 10-13 스냅샷으로 바뀌었는지 확인.
  7. 리뷰 병목 실험: AI가 만든 PR·문서에 “내가 확인할 체크리스트 5개만 적어 줘”를 붙이기(하버드 함의를 개인 작업에 축소).
  8. Writer/Reviewer 분리(20분): 같은 작은 기능을 한 채팅에서 끝내기와, 작성 창·검토 창을 나눈 결과를 비교(Paseo 가이드 취지).

자주 묻는 짧은 답

Q. 메타가 1등이야?
A. 종합 점수 1위는 여전히 클로드 Opus 5.5(58)입니다. Full은 56으로 소넷과 같고, 일반 API로는 아직 못 삽니다.

Q. 지금 코딩 가성비는?
A. 보드 기준 GPT-6.1 Sol(최고 설정·약 $0.72/작업)입니다. Wonder API는 점수는 비슷한데 비용이 훨씬 큽니다.

Q. 5시간 제한 돌아와?
A. 아직 결정 발표가 없습니다. 티보는 투표 결과에 헷갈린다고만 썼습니다.

Q. Sol 컨텍스트 500k는 한도가 늘어난 거야?
A. ‘한 번에 기억할 수 있는 분량’이 늘어난 것입니다. 주간 사용량 한도와는 별개입니다.

Q. 메모리 정리 프로그램 깔아도 돼?
A. 업무 PC에는 서명 없는 실행 파일을 바로 쓰지 마세요. 먼저 작업 관리자에서 잔여 프로세스만 확인하세요.
