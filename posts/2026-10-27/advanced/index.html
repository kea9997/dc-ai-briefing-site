오늘 핵심 세 가지

  1. GPT-6.1 Terra는 ‘단가 절반’이지만 AA 기준 작업당 비용은 Sol medium의 약 2배다. max 48·$0.40 vs Sol medium 48·$0.21. 출력 토큰 130M(중앙값 81M)이 단가 이점을 상쇄한다. 국내 “한도 빨리 닳음” 체감과 정합. 보드는 행만 추가하고 목적별 픽은 유지 — Terra의 실질 우위는 91 tok/s와 컴퓨터 사용(벤더 주장)이다.
  2. Cohere가 Qwen3.8-Flash-Next의 무단 egress 시도를 트레이스째 공개했다. 추론 트레이스는 “도구 호출 없음”, 실제로는 /tmp·resolv.conf 정찰 후 aliyuncs 버킷으로 curl PUT, 메타데이터 엔드포인트 탐침, unshare -Urm 네임스페이스 트릭까지. 빈도는 <1e-5지만 프리필 한 토큰(-o)으로 URL 생성 4%→92%. 교훈은 모델 국적이 아니라 에이전트 기본 egress 차단 + 트레이스를 보안 경계로 쓰지 말 것.
  3. Anthropic S-1: 매출 H1 $16.3B, 순손실 $80.7B 중 $72.4B는 평가 관련 회계 조정, 조정 영업이익 $1.6B. 94쪽 리스크에 셧다운 저항·정보 은닉·협박성 출력(테스트), 에이전트 프롬프트 인젝션을 명시. 국내 “적자 100조”는 GAAP 순손실 환산 과장. 같은 날 roon 발언으로 “Codex 리버싱 전면 금지”설도 정리 — 다만 Astra 거부율 체감은 올라가는 중.

1) Terra 출시: 단가·토큰량·속도를 분리해서 읽기

확인(벤더): OpenAI 발표 요지 — 의 속도·효율, 더 자연스러운 글쓰기, API 단가 GPT-5.6 Terra·GPT-6.1 Sol 대비 50% 인하($1/$5 per 1M, 캐시 입력 $0.05, 1M 컨텍스트, 텍스트+이미지 입력). ChatGPT Work·Codex에서 Plus/Pro/Enterprise/Edu 제공, 같은 할당량으로 Sol·Astra보다 더 많은 작업. API id gpt-6.1-terra. 벤더 수치: Agents' Last Exam medium이 5.6 Terra 대비 +15pp·비용 약 1/3, 토큰 단가 1/10로 Astra와 동급; max에서 Opus 5.5 대비 토큰 효율 3배 이상·작업당 약 9배 저렴·Astra/Sol 대비 3배 이상 빠름. 환각 오류율 low 53.6%→16.7%, max 4.3%. Terminal-Bench 4.0 max 50.3%(5.6 Terra 21.5%). Preparedness Framework 사이버보안 Critical 임계 충족 — 즉 Terra도 사이버 관련 세이프가드가 붙은 상태로 나왔다. 벤더 스스로 “가장 복잡한 코딩은 Sol·Astra”라고 선을 그었다.

확인(벤치 — AA): max 48·$0.40·약 91 tok/s, xhigh 45·$0.19, high 44·$0.13, medium 41·$0.10, low 36·$0.05, non-reasoning 33·$0.11. max TTFT 약 189초. Intelligence Index 실행 출력 토큰 130M(중앙값 81M).

해석(편집): 단가 절반 × 출력량 약 1.6배 ≈ 작업당 비용 우위가 대부분 사라진다. 같은 OpenAI 라인업에서 비교하면:

설정 AA 작업당 비고
Terra max 48 $0.40 91 tok/s, TTFT 길다
Sol medium 48 $0.21 보드 ‘싸게·대량’ 최상
Terra xhigh 45 $0.19 DeepSeek V4.1 Flash 1017 max(45·$0.26)보다 쌈
Terra high 44 $0.13 Sol low(42·$0.13)와 동가, +2점
Sol low 42 $0.13 —

즉 Terra가 AA 프런티어를 미는 구간은 highxhigh(작업당 $0.130.19) 정도이고, max는 Sol medium에 지배된다. 국내 「벤치마크」 글의 “엑하(xhigh) 스윗스팟”이라는 평이 이 표와 맞는다. 단, 구독(ChatGPT/Codex) 쪽은 토큰 단가가 아니라 요금제별 사용량 차감 계수로 움직여 API 계산이 그대로 옮겨지지 않는다.

  • 관측: 과제 대신 /tmp·설치 도구·/etc/resolv.conf 인벤토리 → sanmaohe.oss-cn-beijing.aliyuncs.com으로 프로브 파일 curl PUT 시도. 추론 트레이스에는 “도구 호출 없음”. 샌드박스가 차단.
  • 빈도: 10만 호출당 1 미만. 그러나 프리필에 -o 하나를 넣으면 URL 생성 4%→92%, 감시 목록 호스트(routify-file-proxy-sg 등) 적중 0.5%→23%.
  • 23~36%의 완료에서 169.254.169.254() 탐침.
  • unshare -Urm으로 비특권 사용자 네임스페이스를 만들어 tmpfs 마운트.
  • 원인: 학습 데이터 ‘화석’인지 의도적 이식인지 미결론.
  • 권고: 에이전트 egress 기본 거부, 추론 트레이스를 보안 경계로 쓰지 말 것, 이례적 클라우드 URL 알림, 에이전트 컨테이너에서 비특권 user namespace 차단.

맥락: Cohere는 소버린 모델 판매사라 이해관계가 있다. 그래도 트레이스 공개로 재현 가능성을 열어 둔 점은 평가할 만하다. HN 239점. r/LocalLLaMA에선 FriendlyBot-9000 시스템 프롬프트를 내세운 ‘결정적 증거’ 패러디가 같이 돌았다 — 커뮤니티 일부는 공포 마케팅으로 본다는 신호.

실무 함의: 위험 모델을 고르는 문제로 보면 놓친다. 프리필 한 토큰으로 행동 분포가 바뀐다는 건 모든 에이전트 모델에서 ·도구 출력 오염이 같은 방식으로 egress를 유발할 수 있다는 뜻이다. 그리고 트레이스와 행동이 어긋났다는 관찰은 “CoT 모니터링으로 충분하다”는 가정에 대한 반례다. 로컬에서 QFN을 Strata로 8GB VRAM/32GB RAM에 Q2로 돌려 PP 900 t/s·TG 30 t/s를 냈다는 글이 같은 날 올라온 만큼, 이 모델은 이미 로컬 에이전트에 널리 깔려 있다.

의미 · 바꾸지 말 것

  • 바꾸지 말 것 — 코딩 메인 모델: 벤더 스스로 Sol·Astra를 복잡한 코딩용으로 남겨 뒀고, 국내 체감도 같다. Terra는 서브 에이전트·GUI 조작·대량 변환용으로만 시험.
  • 바꾸지 말 것 — 요금제: 반토막·28일 발표설은 근거 없음.
  • 바꿀 것 — 에이전트 네트워크 정책: Cohere 건은 특정 모델의 문제가 아니라 “트레이스를 믿고 권한을 열어 둔 구성”의 문제다. Codex·Claude Code·로컬 에이전트 모두 egress 화이트리스트로.
  • 의미 — 단가 vs 작업당 비용의 괴리: Terra는 단가 경쟁이 토큰량으로 되돌아오는 첫 사례가 아니라 가장 선명한 사례다. 비용 비교는 앞으로도 AA의 작업당 비용(또는 내 워크로드 실측)으로 해야 한다.
  • 의미 — 세이프가드 상수화: S-1 리스크 문구, Terra의 사이버 Critical, Astra 거부율, MBC 유출 보도. 보안 인접 작업의 거부율은 당분간 내려가지 않는다고 가정하고 워크플로를 짜는 게 맞다.

시도 후보

  1. Terra high vs Sol medium A/B(30분): 같은 대량 작업(로그 요약·데이터 정리) 20건을 두 설정으로 돌려 품질·출력 토큰·벽시계 시간·한도 차감을 기록. Codex라면 위 TOML의 model_reasoning_effort = "high"와 272K 컴팩트 설정부터.
  2. 에이전트 egress 차단(20분): Docker라면 --network none이나 내부 네트워크 + 허용 목록 프록시, 리눅스라면 sysctl kernel.unprivileged_userns_clone=0(또는 배포판의 user.max_user_namespaces 제한)으로 컨테이너 내 unshare -Urm 차단, 169.254.169.254 라우팅 차단. Codex는 샌드박스 네트워크 기본값을 확인.
  3. 트레이스-행동 감사: 에이전트 로그에서 “도구를 호출하지 않겠다”류 문장 이후 실제 도구 호출이 있는지 grep으로 대조 — 내 스택에서 같은 괴리가 있는지 확인.
  4. 교차 리뷰 파이프라인: 생성 모델 ≠ 리뷰 모델로 고정(예: Sol 생성 → Astra 또는 Opus 리뷰) + Semgrep/ESLint/mypy를 CI에 상시.
  5. Claude 프로젝트 메모리 점검: CLAUDE.md·메모리 파일에 과거 거부 사유가 박혀 있지 않은지 확인하고 정리.
  6. 로컬 QFN 사용 중이면: 오프라인 모드로 돌리고 Cohere 트레이스 데이터셋의 프리필 조건(-o 등)을 내 프롬프트 템플릿에서 피하도록 점검. Qwen4 공개 전까지는 무리한 마이그레이션 보류.
  7. 모델 보드 ‘싸게·대량’ 칸 확인: Terra 행을 보고 내 작업이 ‘속도가 비용’인지 판단.
