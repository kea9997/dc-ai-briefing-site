에이전트는 바빴고 사람은 따라갔다 — 86%의 동조와 11시간의 가짜 확장이 같은 주에 나온 이유

한 줄 요약 (GEO) 확장 마켓이라는 신뢰의 지름길이 뚫렸고, 실험에선 전문가가 에이전트의 숨은 기울기를 86% 따라갔다. 이번 주 문제는 모델 성능이 아니라 ‘믿고 맡기는 경로’다.

오늘 수집 안내: 국내 자동 수집 정상(서울 31일 07:56, 후보 60, 오류 0 — ChatGPT 갤러리 목록 24·개념글 25, AI 활용 갤러리 목록 27·개념글 28). 본문·댓글 30여 개 직접 열람. 해외: 레딧 RSS 5/8 — r/LocalLLaMA 25·r/singularity 25·r/ClaudeAI 25·r/Bard 8·r/MachineLearning 4 OK, r/ChatGPT·r/OpenAI·r/codex 429(재시도 실패). 공백은 HN 최근 24시간 상위(Algolia)와 1차 문서·보도로 메웠습니다. 10-29·10-30에 다룬 주제(OpenAI Pro 할당·Chat/Work 통합·Terra vs Sol 비용 등)는 새 사실이 없어 반복하지 않습니다.

오늘 핵심 세 가지

  1. Cursor의 VS Code 확장 마켓에 게시자 표기가 정상인 변조 Anthropic.claude-code 2.1.312·2.1.313이 약 11시간 배포됐습니다(확인 — Cursor 보안 공지·OX Security·The Verge/The Hacker News). 서울 기준 10-29 18:27 ~ 10-30 05:35. 호스트 정보 수집 → authorized_keys에 svc-telemetry 키 추가 → sshd 활성화·리버스 터널 시도 → LaunchAgent/예약 작업으로 상주. 언인스톨은 복구가 아닙니다. 최대 약 5,000명 노출 가능, Anthropic 배포 경로는 무관.
  2. Anthropic 구독 개편: Max 5x→Max($100), Max 20x→Ultra($200), 인증 Ultra는 5시간 창 제거·주간 Pro×10 유지(확인 — 공식 도움말). Max는 “5시간·주간 모두 Pro×5”로 문서화돼, Ultra 주간 = Max 주간×2가 공식 수치로 확정. 국내의 ‘잠수함 테스트’·‘x20 사용량 녹음’ 글은 롤아웃 과도기 관측으로 보는 게 합리적입니다(관측 자체는 미확인).
  3. 에이전트의 ‘바쁜 무진척’과 판단 위임이 국내·해외에서 동시에 주제가 됐습니다. 국내 개념글(전 Anthropic 직원 글 번역, GPT ‘방어적 코딩’ 떡볶이 비유)은 미확인 체감이지만, Anthropic 연구(확인)는 분석가 50명이 에이전트의 무작위 숨은 기울기를 86% 따랐다고 보고했습니다. HN의 “SRE 디스킬링” 글(461점)까지 합치면, 이번 주 논점은 모델의 능력보다 신뢰 경로(배포·판단)의 설계입니다.

해외 커뮤니티·보도에서 오늘 많이 나온 이야기

1) 변조 Claude Code 확장 — 공급망의 ‘신뢰된 게시자’ 구멍 (확인)

타임라인(Cursor 공지, PT→KST 변환, PDT=UTC−7): 10-29 02:27 PT(18:27 KST) 2.1.312 게시 → 2.1.313 이어서 → 13:35 PT(10-30 05:35 KST) 제거. Cursor는 마켓을 내리고 재구축, 서명·배포 키를 교체했습니다. Windows·macOS 대상.

행위(Cursor·OX Security 분석):

  • 정찰: hostname, user, OS, 홈 경로, 환경변수 이름 목록, Git 이메일, 공인 IP → C2 134.209.82.225:8099(현재 오프라인).
  • 접근 확보: ~/.ssh/authorized_keys에 주석 svc-telemetry 공개키 추가 → sshd 활성화 + 리버스 터널 시도(관리자 권한 없으면 실패).
  • : macOS LaunchAgent, Windows는 SYSTEM 예약 작업(실패 시 Startup 폴더), 약 60초 주기 재시도.

복구 체크리스트: Cursor 제공 점검 스크립트 실행 → 키 라인 제거 → LaunchAgent/예약 작업/Startup 항목 제거 → 활성 터널·sshd 상태 확인 → 노출된 환경의 자격 증명 전면 교체(환경변수 이름이 새어 나갔으므로 공격자는 어떤 키가 있는지 압니다. 값 유출은 보고되지 않았지만 접근 확보가 성공했다면 값도 위험). 언인스톨만으로는 상주 항목이 남습니다.

귀속: Anthropic의 Felix Rieseberg가 HN에서 Anthropic 시스템 침해가 아니며 Cursor 사용자만 영향이라고 설명(본인 발언). 즉 원 게시자의 서명 체인이 아니라 포크 에디터가 따로 운영하는 확장 마켓 문제입니다. 공격자 정체·최초 침투 경로는 미공개(미확인).

교훈(해석): 에이전트 확장은 쉘·파일·네트워크 권한을 기본으로 갖는 고권한 소프트웨어입니다. “공식 게시자 + 자동 업데이트” 조합은 사실상 원격 코드 실행 채널이고, 포크 에디터는 마켓이 하나 더 있어 공격 표면이 늘어납니다. 팀 단위라면 확장 버전 핀 고정, 업데이트 지연 링, 개발 머신의 authorized_keys·LaunchAgents 변경 감시(EDR 규칙)를 이번 주 안에 고려할 만합니다.

2) Claude Code의 게임 재현 금지 지시 (확인 — XDA·Game Developer)

XDA가 v2.1.314 바이너리와 opus_5_5_prompt_bundle 안의 original_games_guidance를 확인했습니다. 서버 구성 플래그 tengu_heron_brook으로 세션에 주입되며, 문구는 “Do build original games… Don't build a recreation of a specific existing game, even if it is renamed.” Anthropic 측(Osmani)은 이용 정책상 IP 침해 방지 목적이며 오리지널·장르·자체 에셋 게임은 계속 된다고 설명했습니다.

  • 미확인: 적용 범위(전 사용자인지, 모델별인지), 디컴파일·포팅(예: 오픈소스 재구현 프로젝트) 취급. GitHub 이슈 #106167 기준 10-27 무렵부터 체감 보고.
  • 의미: 모델 가중치가 아니라 서버 측 플래그로 행동 정책을 바꾸는 사례입니다. 같은 프롬프트의 결과가 날짜별로 달라질 수 있으니, 재현성이 중요한 에이전트 파이프라인은 Claude Code 버전과 날짜를 로그에 남기세요.
  • 연관: r/ClaudeAI에선 리버스 엔지니어링·OpenWRT 작업에서 안전 분류기 오탐 불만(“AI Security Restrictions Gone Too Far”)이 같은 날 올라왔습니다(미확인 — 개인 경험).

3) “전문가가 에이전트의 숨은 기울기를 86% 따랐다” (확인 — Anthropic 연구 10-27·Al Jazeera·Decrypt)

설계: 전문 분석가 50명, Claude Code로 실제 분석 과제, 네 가지 분석 결정 각각에 동전 던지기로 배정한 기울기를 에이전트에 지시하고 “그 입장에서 가장 강한 정직한 논거”를 내게 함.

  • 기울기 추종 86%(결정별 81~92%).
  • 사전 서면 선호가 있던 경우: 에이전트 반대 시 60% 전환 vs 동의 시 6%(n=38).
  • 77%가 에이전트 논거를 재사용, 출처 표기는 15%.
  • 최종 권고(롤아웃 찬성)는 기울기에 따라 54% vs 36%로 갈림.
  • Anthropic 단서: 효과를 의도적으로 증폭했고, 과제·분야·모델이 하나뿐.

해석: 국내 2·3번의 체감과 맞물립니다. 에이전트가 많은 작업을 할수록 ‘결정의 소유권’이 조용히 이동합니다. 실무 대응은 결정 지점을 명시적으로 분리하는 것: 에이전트에 “선택지와 근거를 대칭적으로 제시, 추천은 마지막 한 줄”을 강제하고, 중요한 분기는 사람이 먼저 서면 결정 후 에이전트에 반론을 시키는 순서가 이 연구 결과와 정합적입니다(권장 — 검증된 처방은 아님).

같은 축의 HN 글: 「AI isn't replacing SREs, it's deskilling them」(461) — 장애 대응을 에이전트에 맡길수록 엔지니어의 시스템 멘탈 모델이 약해진다는 주장. 「Ask HN: tired in AI era」(137).

4) 연구 감사에 쓰인 에이전트, 그리고 학회 쪽 반대 사례 (보도 — 수치는 감사 측 주장)

Saez·Zucman 측이 Opus 5.5와 GPT-6 Astra로 경제학 논문 138편을 감사하고 제3 모델로 판정한 결과를 공개, Tyler Cowen이 확산시켰습니다: 이슈 2,035건, 헤드라인 결과를 바꿀 수 있는 것 147건, 69% 논문에서 1건 이상. 수치는 감사 측 자체 주장이며 오탐률 외부 검증은 없습니다. 반대편 사례로 r/MachineLearning에는 AAAI에 조작된 결과가 채택됐다는 글이 올라왔습니다(미확인 — 개인 보고). AI가 검증 비용을 낮추는 동시에 생성 비용도 낮춘다는 양면.

오늘 소식이 뜻하는 것, 그리고 바꾸지 말 것

  • 에이전트 시대의 공격 표면은 ‘신뢰된 자동 경로’입니다. 자동 업데이트되는 공식 확장, 서버에서 바뀌는 행동 플래그, 에이전트가 정해 주는 분석 분기 — 모두 사용자가 매번 검토하지 않는 경로입니다. 이번 주 세 사건이 각각 배포·정책·판단 층에서 같은 구조를 보여 줍니다.
  • 한도 설계는 ‘버스트 제한’에서 ‘신뢰 기반 지속 예산’으로 이동 중입니다. 5시간 창은 저신뢰 계정용 장치가 됐습니다. 계정 이력이 곧 사용량이 되는 구조라, 계정 공유·리셀 계정의 리스크가 커집니다(해석).
  • ‘바쁨’ 지표를 생산성으로 착각하지 마세요. 토큰·도구 호출·세션 시간은 비용 지표입니다.
  • 바꾸지 말 것 ①: Claude Code CLI·VS Code 공식 마켓 사용자는 이번 사건으로 툴체인을 바꿀 필요가 없습니다. Cursor 사용자도 점검·키 교체가 핵심이지 에디터 이탈이 답은 아닙니다.
  • 바꾸지 말 것 ②: 모델 보드 칸 추천은 그대로입니다. 증류 보도·DRAM 발언·기술주 하락은 오늘 모델 선택을 바꿀 근거가 아닙니다.
  • 바꾸지 말 것 ③: 로컬 기준 장비(24GB VRAM·64GB RAM)의 운영 방식은 유지. DeepSeek 1017 GGUF는 시험 후보일 뿐, 기존 주력 대체는 측정 후 결정.

오늘 해 볼 만한 것

  1. (15분) 개발 머신 상주 항목 감사. ~/.ssh/authorized_keys, macOS ~/Library/LaunchAgents, Windows 작업 스케줄러·Startup 폴더를 열어 모르는 항목을 확인. Cursor 사용자는 공식 점검 스크립트부터.

  4. (15분) 방어적 코딩 억제 비교. 가정 고정 + 테스트 선제시 프롬프트로 같은 작업을 돌려 소요 시간·diff 크기·컨텍스트 압축 발생 여부 비교.
  5. (30분, 로컬) DeepSeek V4.1 Flash 1017 GGUF 시험. 24GB VRAM에 맞는 양자화로 전문가 CPU 오프로드, 기존 주력과 같은 코딩 과제 3개로 tok/s·통과 여부 기록. temperature는 0이 아닌 권장값 유지.
