한 달을 기다린 ‘마지막 깜짝 발표’는 없었다 — 그 사이 화면 구석 세 단어가 한도를 갉아먹고 있었다

2026년 11월 3일 · 옵티웍 AI 데일리 · 초보

공유 · 구독
텔레그램에 공유 채널 구독 X에 공유
한 줄 요약 (GEO) 28일 이벤트는 새 모델 없이 끝났고, 사람들은 ‘어느 AI에 돈을 낼지’를 다시 계산하기 시작했다.

오늘 수집 안내: 국내 자동 수집 정상(서울 11-03 07:57, 후보 60, 오류 0 — ChatGPT 갤러리 개념글 25·목록 23, AI 활용 갤러리 개념글 28·목록 27). 본문·댓글 25개 정도를 직접 읽었습니다. 해외: 레딧 RSS 3/8 성공(r/LocalLLaMA·r/OpenAI·r/codex), r/ChatGPT·r/ClaudeAI·r/singularity·r/MachineLearning·r/Bard는 429 차단. 빈 곳은 해커뉴스와 공식 문서·보도로 채웠습니다. 11-02에 다룬 12월 한도 통합은 새로 생긴 이야기만 덧붙입니다.

오늘 핵심 세 가지

  1. Codex 책임자의 28일 이벤트가 새 모델 없이 끝났습니다(확인). 마지막 날 선물은 두 번째 지급이었습니다. 국내 반응은 “고생했다”와 “엔딩이 허망하다”가 반반이었고, 모두가 기다린 GPT-6.2 Astra는 여전히 **발표 전(미확인)**입니다.
  2. “Opus가 낫냐, Astra가 낫냐”가 오늘 국내 최고 조회 글이었습니다(미확인 — 개인 경험). 두 구독을 동시에 쓰는 사람이 “대충 시키면 Opus, 꼼꼼히 지시하면 Astra”라고 정리했고 댓글 59개가 붙었습니다. 해외에서도 “같은 20달러인데 Claude Code가 훨씬 넉넉하다”는 갈아타기 후기가 떴습니다.
  3. Claude Code 사용자라면 오늘 꼭 알아 둘 두 가지(일부 확인). 하나, 화면 구석 상태 표시줄을 채우려고 한도의 15~20%를 쓴다는 측정이 나왔습니다. 둘, 앤트로픽이 “남의 게임을 그대로 베끼는 작업”은 거절하도록 Claude Code 지시문에 두 문장을 넣었다고 직원이 직접 밝혔습니다.

국내 커뮤니티에서 오늘 많이 나온 이야기

1) Opus 5.5 대 Astra — “초보들이 착각하는 것” (미확인 / 개인 경험)

AI 활용 갤러리 후기 글(조회 약 4,700·추천 42·댓글 59)입니다. 글쓴이는 Claude 220달러 요금제와 ChatGPT 200달러 요금제를 같이 쓴다고 밝혔습니다. 요지는 이렇습니다.

  • Opus(앤트로픽 Claude의 가장 좋은 모델)가 칭찬받는 이유: “대충 이런 프로그램 만들어 줘”라고만 해도 알아서 흔한 기능 20개와 무난한 화면을 붙여 줍니다. 갤러리 말로 입니다. 그래서 처음 만드는 사람에게 인기가 많다고 봅니다.
  • Astra(오픈AI GPT-6 Astra)가 앞선다고 보는 경우: “기능 후보 50개 뽑아 봐, 내가 20개 고를게”, “설계안 5개 내 봐” 식으로 사람이 하나하나 고르며 만드는 경우입니다. 수학·공학 계산이나 게임 제작은 Astra가 낫다고 했습니다.
  • 사용량: 반대로 Opus는 한도가 넉넉하고, Astra는 토큰을 많이 먹어 주간 작업량이 더 적다고 합니다.
  • 숨은 장점: Codex는 자체 이미지 모델이 있어서 작업에 필요한 그림 소재를 추가 비용 없이 자동으로 만든다고 합니다. 글쓴이는 매주 소재 그림을 2,000장 넘게 뽑는다고 적었습니다.

결론은 “둘 다 장단점이 있어 같이 쓰는 게 좋고, 한쪽이 다른 쪽을 압도하진 않는다”였습니다. 한 사람의 경험이라 벤치 점수로 확인된 이야기는 아닙니다. 다만 아래 ‘목적별 모델 고르기’ 표에서도 코딩 최상위는 Opus, 가성비는 Sol로 나뉘어 있어 방향은 비슷합니다.

2) 티보의 28일 챌린지 엔딩 — “리셋권 두 개로 끝?” (확인)

Codex 책임자 티보(Thibault Sottiaux)는 한 달 동안 매일 X(옛 트위터)에 “오늘의 개선 사항”을 올렸습니다. 28일째 글은 “Banked 2/2”, 즉 이틀에 나눠 주겠다던 적립 리셋권의 두 번째였습니다. AI 활용 갤러리에서 매일 번역해 올리던 이용자의 마지막 글(조회 약 3,900·댓글 25)에는 “한 달 동안 옮기느라 고생했다”는 인사가 줄을 이었습니다.

동시에 실망도 컸습니다. “마지막엔 깜짝 발표가 있을 줄 알았다”, “6.2 Astra 떡밥만 나오고 모델은 안 나오네”, “6.2가 계획보다 늦어진 듯”이라는 댓글이 이어졌습니다. 해외 r/codex 이용자가 정리한 한 달 결과는 이렇습니다(이용자 집계, 미확인).

  • 리셋 14번(자동 11·적립 3), 개선 27건
  • Pro·Business Premium 한도 2배(20배 요금제는 반토막 계획이 취소돼 그대로)
  • Sol·Terra·Astra 속도가 초당 약 30토큰에서 약 50토큰으로
  • Sol 기본 27만 2천에서 50만 토큰으로

글쓴이 평가는 “좋지만 대단하진 않다, 새 모델 하나가 이걸 다 덮는다”였습니다. 같은 게시판에는 “요즘 GPT가 평범한 질문에도 지나치게 경고를 띄운다”는 불만 글도 올라왔습니다.

3) 12월 통합 후속 — “막히는 거냐, 의미가 없어지는 거냐” (일부 확인)

어제 확인된 12월 ChatGPT·Codex 한도 통합 이후 질문이 이어졌습니다. 「는 언제부터 막히냐」 글에는 “막히는 게 아니라 한도가 합쳐져서 따로 쓸 의미가 없어지는 것”이라는 답이 달렸습니다. 이게 정확한 설명입니다. 오픈AI 도움말 기준으로 Instant 채팅은 계속 한도 밖이고, 고급 모델 채팅만 같은 통에서 빠집니다.

반발도 여전합니다. ChatGPT 갤러리에는 “통합은 결국 채팅에서 고급 추론을 빼고 Instant만 남긴 뒤 포장한 것”이라는 해석 글(미확인)과, “서버를 많이 먹는 건 이미지가 아니라 오래 생각하는 코딩 작업인데 왜 이미지 쓰는 사람을 탓하냐”는 반박 글이 각각 올라왔습니다. 「사용량 2배라더니 오히려 반토막?」 글은 숫자를 잘못 읽은 경우였습니다. 화면의 퍼센트는 남은 양이 아니라 쓴 양 기준이라, 남은 칸에 100을 더 받으면 퍼센트가 늘어나는 게 맞다는 댓글 설명이 정리했습니다.

4) Claude Code 한도 20% 아끼는 팁 (일부 확인)

AI 활용 갤러리 정보 글(조회 약 2,200)이 해외 공개 메모를 소개했습니다. Claude Code는 뒤에서 도는 마다 약 30초에 한 번씩 “지금 뭐 하는 중인지 3~5단어로 말해”라고 모델에 묻습니다. 그 답은 화면의 상태 표시줄에만 쓰입니다. 문제는 그때마다 그 보조 AI의 대화 전체를 다시 보낸다는 점입니다.

측정 결과(확인 — 공개 측정): 만든 쪽 측정으로는 일주일 동안 전체 사용량의 약 16%, 요청의 약 20%가 이 상태 표시줄에 쓰였습니다. 앤트로픽 깃허브 이슈에도 보조 AI가 많은 세션에서 18~26%라는 측정이 모여 있습니다. 반면 해커뉴스의 한 사용자는 “많아야 8%”라고 했습니다. 보조 AI를 많이 돌릴수록 커지고, 평범하게 한 창만 쓰면 거의 영향이 없습니다.

주의할 점: 이걸 끄는 공식 설정은 아직 없습니다. 공개된 방법은 비공식 스크립트라 업데이트 때 깨질 수 있습니다. 초보라면 따라 하기보다 “보조 AI를 여러 개 오래 켜 두면 한도가 빨리 준다”는 사실만 기억해도 충분합니다.

5) “대(大) 해킹의 시대” — 내 사이트, 내 계정 지키기 (미확인)

  • 개인 사이트를 운영하는 이용자가 새벽에 해킹 로봇이 문의 입력창에 공격 문자열을 넣고 다닌 기록을 올렸습니다(추천 29). 댓글은 “개인 사이트라도 보안 설정 안 하면 모르는 새 털린다”였습니다. AI로 사이트를 뚝딱 만드는 사람이 늘면서 이런 기본 점검이 더 중요해졌습니다.
  • 반대로 「구글을 공격한 최후」 글(조회 약 3,400)은 한 이용자가 구글 AI 개발 도구 안에서 내부 서버 주소를 찾아 침투를 시도했다가 경고 메일을 받았다는 내용입니다. 댓글 대부분이 “하지 마라”였습니다. 남의 서비스를 허락 없이 찔러 보는 건 계정 정지뿐 아니라 법적 문제가 될 수 있습니다.
  • 「컴퓨터 24시간 켜 두면 해킹 안 무섭냐」 질문에는 “공유기 보안 설정만 잘하면 집 PC는 바깥에서 바로 보이지 않는다. 중요한 자료는 백업과 암호화”라는 답이 달렸습니다.

6) 작은 화제들 (미확인)

  • 딥시크 코딩 ‘슈퍼 에이전트’: AI타임스 보도를 옮긴 글(조회 약 3,300)입니다. 딥시크가 여러 AI 일꾼에게 작업을 나눠 주는 연구용 도구를 공개했습니다. 자체 실험에서 처리 시간이 약 47% 줄었다지만, Claude Code·Codex와 직접 비교한 결과는 아닙니다. 댓글은 “구독제나 내놔라”가 많았습니다.
  • AI 티 안 나는 디자인: 「폰트슬롭을 멈추고 싶다면」 글(조회 약 4,400)은 서체 회사 Dinamo를 추천했습니다. 오픈AI가 쓰는 Favorit 서체를 만든 곳이고 한글판도 있다고 합니다. 을 피하려면 글꼴부터 바꾸라는 이야기로, 유료지만 학생·비영리 할인이 있다고 합니다. 「픽셀 효과 만드는 클코 스킬」 글은 그림 파일 없이 코드만으로 픽셀 효과 244개를 만드는 공개 도구를 소개했습니다.
  • ChatGPT 갤러리 4주년 대회: 11월 1일부터 29일까지 AI 활용 사례 대회가 열립니다. 상금은 총 10만 원, 결과 발표는 11월 30일이라 이번 달 내내 따라 해 볼 만한 활용 사례가 쌓일 것 같습니다.

해외 커뮤니티·보도에서 오늘 많이 나온 이야기

1) 앤트로픽 “남의 게임 베끼기는 거절” (확인 — 직원 발언)

Tom's Hardware 보도에 따르면 앤트로픽 직원 애디 오스마니가 “Opus 5.5로 돌아가는 Claude Code 지시문에 두 문장을 추가해, 특정 기존 게임을 그대로 다시 만드는 작업을 피하게 했다”고 밝혔습니다(10-30). 직접 만든 게임, 장르 게임, 내 디자인과 그림으로 만드는 게임은 계속 된다고 했습니다. 다만 같은 시기부터 “내 프로그램을 분석하는 작업까지 거절당한다”는 보고가 늘었고, 한 기자는 구버전 Opus 4.8로 바꾸니 다시 됐다고 했습니다(미확인). 국내 「클로드 저작권에 집착하는 거 슬슬 뇌절 느낌」 글(조회 약 3,300)과 같은 흐름입니다.

2) “Astra가 다른 AI의 머릿속을 직접 고쳤다” (확인 — 연구 발표 / 의미는 지켜볼 것)

MIT 연구진이 11-02 공개한 글이 해커뉴스 1위(1,500점 이상)에 올랐습니다. GPT-6 Astra에게 작은 AI 모델의 를 숫자 그대로 보여 주자, 어떤 게임을 배운 모델인지 맞혔다고 합니다. 또 작은 Qwen 모델의 숫자 0.016%만 직접 고쳐서, 수학 시험 점수를 7.9%에서 48.1%로 올렸다고 보고했습니다. 학습을 다시 돌리지 않고 “생각해서 고쳤다”는 점이 놀라움을 샀습니다. 아직 아주 작은 모델 실험이라 큰 모델에도 통할지는 모릅니다.

3) 6.2 Astra, 아직도 ‘로그에만’ (미확인)

r/OpenAI에 「Astra 6.2 배포 시작?」 글이 다시 올라왔습니다. 몇몇 사용량 화면에 gpt-6.2-astra가 찍힌다는 캡처는 계속 나오지만, 오픈AI 모델 목록과 변경 기록에는 여전히 없습니다. 같은 이름으로 실행해 본 사람 중엔 “된다”와 “모델 없음 오류”가 엇갈립니다. 발표가 날 때까지는 지금 쓰는 설정을 그대로 두세요.

4) 올트먼 램 발언 후폭풍 — 아마존 GPU 주문 취소 소동 (미확인)

어제 다룬 “집 PC 램은 낭비” 발언 뒤로 레딧은 패러디로 가득했습니다. 국내 「샘 알트만 이제 뒤졌다」 글(조회 약 3,200)도 같은 유행입니다. 그런데 진지한 소식도 붙었습니다. 한 AI 교육자가 아마존에서 엔비디아 DGX Spark(책상 위 AI 컴퓨터) 4대를 주문했다가 모두 취소되고 계정까지 닫혔다고 주장했고, 에픽게임즈 대표 팀 스위니도 GPU 2장 주문이 배송 직전 취소됐다고 했습니다. 아마존은 이유를 밝히지 않았고, 되팔이 방지일 가능성이 거론됩니다. 그래픽카드 직구를 생각한다면 한 번에 여러 대를 주문하지 않는 편이 안전해 보입니다.

5) 로컬 AI 진영 — “Qwen은 끝까지 공개” (미확인)

r/LocalLLaMA 1위는 “Qwen 4·5도 계속 공개 모델로 낸다”는 알리바바 Qwen 책임자 발언 소개였습니다. “다음부터는 유료 API만 낸다”는 소문을 부인한 것입니다. 원문 출처가 레딧 글이라 공식 확인은 못 했습니다. 같은 게시판에선 램 16GB 그래픽카드와 64GB 램으로 딥시크 V4.1 Flash를 돌리며 첫 응답 대기를 100초에서 크게 줄였다는 글이 화제였습니다. 우리 기준 장비(RTX 5090 노트북 24GB·램 64GB)라면 더 여유가 있지만, 직접 엔진을 고쳐야 하는 수준이라 초보에겐 아직 이릅니다.

목적별 모델 고르기 — 어제 주간 점검 그대로

오늘은 새 모델 정식 출시나 가격 개편이 없어 모델 보드는 11-02 주간 점검(10-31 수치와 동일) 그대로입니다. 원문은 AA 리더보드에서 볼 수 있습니다.

  • 확인(AA 벤치): 괄호 안은 AA 지능 점수와 작업당 비용(API 기준)입니다. Opus가 점수는 가장 높지만 작업당 비용은 Sol의 약 8배입니다.
  • 미확인(커뮤니티 해석): 오늘 국내 후기처럼 “대충 시키면 Opus, 직접 고르며 만들면 Astra·Sol”이라는 체감은 벤치 점수와 별개인 개인 경험입니다. 표의 비용은 API로 쓸 때 기준이라 구독 한도 체감과는 다릅니다.

오늘 소식이 뜻하는 것, 그리고 바꾸지 말 것

  • 뜻하는 것: 한 달 이벤트가 끝나고, 사람들은 “리셋권”이 아니라 “어느 회사 구독이 내 작업에 넉넉한가”를 따지기 시작했습니다. 12월 한도 통합, 앤트로픽의 거절 규칙, 상태 표시줄이 먹는 토큰까지, 이제는 모델 점수만큼 한도와 규칙이 선택 기준이 됐습니다.
  • 바꾸지 말 것: 6.2 Astra는 발표 전이라 설정을 바꿀 근거가 없습니다. “같은 20달러에 Claude가 넉넉하다”는 후기도 한 사람 경험이니, 갈아타기 전에 한 주 동안 내 사용량을 기록해 비교하세요.
  • 바꾸지 말 것 2: 비공식 스크립트로 Claude Code 내부를 고치거나, 남의 서비스 내부를 찔러 보는 건 하지 마세요. 아끼는 토큰보다 잃을 계정이 더 큽니다.

오늘 해 볼 만한 것

  1. Claude Code를 쓴다면 보조 AI(서브에이전트)를 몇 개, 얼마나 오래 켜 두는지 확인해 보세요. 쓰지 않는 보조 AI는 끄는 것만으로 한도가 덜 줄어듭니다.
  2. Opus와 Astra·Sol 중 고민 중이라면, 같은 작은 과제를 한 번은 대충, 한 번은 “후보 5개 내 봐, 내가 고를게”로 시켜 보세요. 오늘 후기의 차이를 직접 느낄 수 있습니다.
  3. AI로 만든 개인 사이트가 있다면 문의 입력창에 이상한 글이 들어온 기록이 있는지 한 번 열어 보세요. 입력값 검사와 관리자 페이지 비밀번호만 챙겨도 대부분 막힙니다.
  4. 게임을 만든다면 “○○ 게임 똑같이 만들어 줘” 대신 내 규칙과 내 그림으로 설명하세요. Claude Code의 새 거절 규칙에 덜 걸립니다.
  5. ChatGPT 갤러리 4주년 대회(11월 29일까지)에 올라오는 활용 사례를 몇 개 훑어보세요. 내 일에 바로 가져다 쓸 아이디어가 나올 수 있습니다.
