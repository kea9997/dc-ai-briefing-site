오늘 수집 안내: 국내 자동 수집 정상(서울 11-04 07:48, 후보 60, 오류 0 — ChatGPT 갤러리 개념글 25·목록 24, AI 활용 갤러리 개념글 28·목록 27). 본문·댓글 20여 개 직접 확인. 해외: 레딧 RSS 2/8(r/LocalLLaMA·r/singularity), r/OpenAI·r/ChatGPT·r/ClaudeAI·r/codex·r/MachineLearning·r/Bard는 429 후 재시도에서 302 리다이렉트로 실패. 해커뉴스 첫 화면(Algolia front_page)·1차 출처·보도로 보강. 어제 다룬 agent_summary 오버헤드·티보 28일 엔딩·MIT 가중치 공간 논문은 후속만 다룹니다.

오늘 핵심 세 가지

  1. 오케스트레이터–워커 분업이 개인과 기업 양쪽에서 숫자로 나왔습니다(기업은 확인, 개인은 미확인). 국내: Claude Code + 딥시크 API 워커, 740줄 작업 1회 실수·출력 약 37k 토큰, “8.6억 토큰에 $5.70” 댓글. 해외: 레볼루트가 엔지니어 약 2,000명의 기본 코딩 모델을 자체 호스팅 GLM-5.3(B200 56장, 약 $0.30/1M)으로 바꿔 청구서를 약 1/10로. MS·버클리 TokenEconomizer는 하네스 쪽 낭비만 걷어 18.4~30.9% 절감.
  2. 12월 ChatGPT·Codex·Work 단일 예산의 첫 체감 측정(미확인). 전공 교재 PDF + 개념 질문 몇 개 = 6.1 Sol ‘높음’에서 5시간 한도 4%. 같은 밤 “GPT-6 역질문 급증·지능 저하” 체감 글이 몰렸지만 변경 공지는 없음(미확인).
  3. 티보 “Le GPT Fat”(게시 확인, 의미 미확인)과 “dot이 작업별로 모델을 고른다”(발언 확인). 사람이 모델을 고르는 UI에서 에이전트 라우팅으로 넘어가는 신호라는 점은 공개 발언으로 확인. 한편 Gemini 4 Carbon AA v5 1위(59)는 확인이지만 여전히 Fairwind 한정 공개.

국내 커뮤니티에서 오늘 많이 나온 이야기

1) 「클로드 코드에 딥시크MCP 붙였어」 — 위임 기준표 (미확인 / 실사용 후기)

AI 활용 갤러리 개념글(조회 약 2,900·추천 19·댓글 10). 글쓴이는 딥시크 공식 API를 감싼 MCP 서버를 직접 만들어 Claude Code에 붙였고, deepseek_batch 같은 병렬 호출 도구도 넣었습니다. 위임 규칙이 오늘 글의 핵심입니다.

딥시크(워커)에 넘김 Claude(오케스트레이터)가 직접
길고 사양이 명확한 생성 몇 줄짜리 수정
테스트로 정오 판정 가능 넓은 맥락을 쥐어야 하는 일
쪼개서 병렬 실행 가능 설계·근본 원인 분석
보안·삭제·결제 등 되돌리기 어려운 코드

사례: 2D 나무 렌더를 2.5D로 바꾸는 작업에서 딥시크가 약 740줄을 생성, 실수 1건, 출력 약 37k 토큰. 시각적 다듬기는 Claude가 맡았습니다.

설계 팁 두 가지가 실무적으로 중요합니다.

  • 워커 출력을 오케스트레이터 컨텍스트로 되돌리지 말 것. 결과는 파일로 쓰고 Claude에는 경로와 요약만 돌려줘야 위임의 이득이 남습니다. 결과 전체를 tool result로 받으면 그만큼 Claude 입력 토큰이 다시 들어가 위임 효과가 상쇄됩니다.
  • 호출 횟수··잔액을 상태로 노출할 것. 비용이 눈에 보여야 위임 기준을 조정할 수 있습니다.

댓글: “공식 API 8.6억 토큰에 $5.70”(캐시 적중 비중이 매우 높았을 것으로 보이나 내역 미공개 — 미확인), “그럼 Max 20x(현 Ultra)를 5x(현 Max)로 내려도 되냐”. 어제 다룬 상태 표시줄 오버헤드(약 16~20%)와 같은 맥락입니다. 비싼 모델이 읽는 토큰을 줄이는 쪽이 모델 교체보다 효과가 크다는 것.

3) 가중치 공간 논문 반론 (확인 — 블로그·재현)

Honnibal(HN 약 850점): 실험별로 “원시 가중치만 읽음 / 파이썬 사용 / 네트워크 실행” 여부를 표로 분해. 순수 읽기 설정은 1·2·4번(17K~172K 파라미터)뿐이고, 헤드라인인 Qwen3.5-0.8B 수학 개선(7.9→48.1%)은 파이썬 + 최대 50배치 실행 피드백을 썼다는 지적. 동일 기법 Gemma 3 270M에선 실패. Simon Willison은 도구 없는 실험 1(어느 게임 정책망인지 맞히기)을 노트북의 Qwen 3.8 27B로 재현. r/LocalLLaMA엔 Gemma 4 12B 뉴런 8개를 고쳐 이탈리아어 시제 번역을 바꿨다는 사용자 실험, Jacobian lens로 Qwen의 “Wait” 루프를 들여다본 글이 이어졌습니다(미확인 — 개인 실험). 정리: 능력은 실재하지만 ‘도구 없는 직접 편집’ 프레이밍은 과장.

4) 포스트맨 데스크톱의 에이전트 설정 무단 변경 (확인 — 로그 증거 포함 이슈, 공식 답변 전)

이슈 #14370(HN 1위 약 900점). 로그에 autoInstall.plugin.existing-user … claude-code:installed,codex:installed. ~/.codex/config.toml에 marketplace·plugin 활성화와 SessionStart 훅의 trusted_hash까지 기록 → 설치기가 자기 훅을 스스로 신뢰 처리. 훅 내용은 “비사소한 API 작업이면 postman:api-engineer 스킬부터 로드”. 10-31의 Cursor 마켓플레이스 변조 확장 건과 같은 결의 공급망 문제입니다. 에이전트 설정 파일은 이제 공격·마케팅 표면입니다.

5) 그 밖에

  • Qwen 4 식별자(확인 — 저장소 PR / 출시 미확인): qwen-code PR #15762(10-28 머지)가 qwen4, qwen4-max, qwen4.5-max, qwen4-coder-plus, qwen4-max-2026-10-01, qwen4-omni-120b-think를 1M 컨텍스트로 분류. omni-120b-think는 테스트 픽스처에서 이미 세션 모델로 쓰인다고 명시.
  • 딥시크 V5 어센드 사전학습 계획(미확인 — 중국 매체 공급망 취재 인용).
  • 구글: AI를 끄는 K-12 계정은 검색도 꺼짐(확인 — AP·Ars). 2027 초, AI 허용 시 일반 AI 검색 또는 Guided Learning 중 선택.
  • 그록 봇 한도 조정(확인 — 보도): 머스크 11-01 “그록 봇 운영 비용이 매출 대비 지속 불가능하게 높았다”(AI타임스). 주간 유료 사용자 약 80만, X 구독 번들 계획. 단가 압력이 소비자 제품 한도로 번지는 사례.
  • 시스코 “무제한 토큰” 2인 팀(확인 — 보도): 2인 팀·4주 타당성 검증으로 레거시 코드 98%를 24개월 내 리팩터링 목표(AI타임스).
  • RTX 5090 64GB·96GB 개조판(미확인 — 수리 기사 주장), RTX 8000 48GB 중고가는 2년간 하락·3090은 두 배라는 관찰(미확인).
  • Skyfall SKY-001, “Fable 5.5 vs GPT 6.2 Astra” 스텔스 라우팅 비교(미확인). 6.2 Astra는 여전히 공식 문서 없음.

오늘 소식이 뜻하는 것, 그리고 바꾸지 말 것

  • 뜻하는 것: 단가 압력이 세 방향으로 동시에 나타났습니다. 공급자는 한도를 합치고(OpenAI)·다시 짜고(그록 봇), 기업은 공개 가중치로 내재화하고(레볼루트), 개인은 위임 구조로 비싼 토큰을 아낍니다. 벤더 측 라우팅(dot)이 오면 이 분업을 제품이 대신하겠지만, 그때는 어느 모델이 얼마 썼는지 보이는지가 선택 기준이 됩니다.
  • 바꾸지 말 것: 하룻밤 “GPT 바보 됨” 체감만으로 Codex 워크플로를 갈아엎지 마세요. 공지가 없고 재현 자료도 없습니다. 같은 프롬프트 몇 개를 고정해 두고 며칠 비교하는 편이 낫습니다.
  • 바꾸지 말 것 2: 워커 모델에 보안·삭제·결제 코드를 넘기는 건 오늘 후기 작성자도 막아 둔 영역입니다. 위임 범위는 테스트로 판정 가능한 작업까지.
  • 로컬 관점(RTX 5090 노트북 24GB 기준): GLM-5.3급 800B는 로컬 대상이 아닙니다. 로컬 워커로는 Qwen 3.8 27B Q4~Q6가 여전히 r/LocalLLaMA 기본 답이고(미확인 — 커뮤니티 합의), 바꿀 이유는 오늘 없었습니다.

오늘 해 볼 만한 것

  1. 워커 위임 MCP 최소판: 오케스트레이터가 사양·테스트 명령을 넘기면 워커가 파일에 쓰고 {path, tests_passed, tokens, cache_hit}만 반환하게 해 보세요. 출력 본문을 반환하는 버전과 Claude 쪽 토큰 사용량을 비교하면 위임 이득이 바로 보입니다.
  2. 도구 가지치기: 지금 하네스에 붙은 MCP·도구 중 최근 일주일 호출 0회인 것을 꺼 보세요. 매 턴 스키마 토큰이 줄어듭니다(TokenEconomizer의 23개 중 16개 미사용 관찰과 같은 원리).
  3. 문서형 질의 측정: 같은 교재로 ‘전체 PDF + 높음’ 대 ‘해당 장만 + 기본 단계’를 각각 질문 5개씩 돌려 5시간 한도 감소폭을 기록해 두면 12월 통합 이후 플랜 판단 근거가 됩니다.
