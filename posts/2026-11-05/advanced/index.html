CDN 파일 네 개가 바뀐 지 38일 — 공격을 잡은 건 에이전트였고, 제보자를 몰아낸 것도 AI 답변이었다

2026년 11월 5일 · 옵티웍 AI 데일리 · 고급

공유 · 구독
텔레그램에 공유 채널 구독 X에 공유
한 줄 요약 (GEO) 니케 런처 공급망 공격이 공식 확인된 날, 국내는 ‘검증을 누가 하느냐’를 두고 Pro의 과잉 검증과 Gemini 판정을 함께 이야기했고, 해외는 1.56TB 공개 가중치와 증명 가능한 추론을 내놨다.

오늘 수집 안내: 국내 자동 수집 정상(서울 11-05 07:57, 후보 60, 오류 0 — ChatGPT 갤러리 개념글 25·목록 24, AI 활용 갤러리 개념글 28·목록 25). 수집기 본문 한도(갤러리당 8개)를 넘는 글은 별도로 받아 25개 안팎 본문·댓글 직접 확인. 해외: 레딧 RSS 1/8(r/LocalLLaMA만 성공; r/OpenAI·r/ChatGPT·r/ClaudeAI·r/codex·r/MachineLearning·r/singularity·r/Bard는 429·302). 해커뉴스 첫 화면·1차 출처·보도로 보강. 어제 다룬 Work 4% 실험·티보 ‘Le GPT Fat’은 후속만.

오늘 핵심 세 가지

  1. 니케 PC 런처 공급망 공격 확인(확인 — 보안뉴스·연합뉴스·블리핑컴퓨터, 제작사 패치). 9/27 CDN의 런처 웹 리소스(JS) 4개가 변조돼 외부 스크립트(insightjs.com/l.js)를 로드했고, 이것이 LuaJIT 기반 원격 접근 도구(K2F)를 떨궜습니다. 페이로드 첫 실행 흔적 10/23, 노출 구간 10/24 이후. 국내 개념글은 “Codex로 점검하다 먼저 잡았는데 제보자는 차단·신상 공개를 당했고, 반박 측은 Gemini 답변을 근거로 들었다”는 경위를 전했습니다(경위 미확인).
  2. “검증 과잉이 한도를 태운다” — Pro 주간 한도 90% vs 정밀 지시 1%(미확인 — 개인 측정). Claude 최상위 요금제에서 ChatGPT Pro로 옮긴 사용자의 비교 후기. 반대편에선 Claude 계정 정지 이의 신청 때 신분증 제출이 재가입 차단으로 이어졌다는 경고(미확인). 두 글 모두 결론은 “구독 선택은 모델 점수보다 운영 비용과 계정 리스크”.
  3. Kimi K3.1 Pro 가중치 공개(확인 — HF moonshotai/Kimi-K3.1-Pro). 2.8T 전체/104B 활성 MoE, MXFP4 1.56TB. AA v5 46으로 가중치 공개 모델 중 최고라 모델 보드 오픈 웨이트 1위를 DeepSeek V4.1 Flash에서 교체. 같은 날 Anthropic은 ‘이 답이 정말 그 모델에서 나왔는가’를 zkSNARK로 증명하는 FlashProve를 공개 — 공개 가중치 시대의 바꿔치기 검증 문제가 같이 나왔습니다.

국내 커뮤니티에서 오늘 많이 나온 이야기

1) 니케 런처 공급망 공격 — 탐지·부인·판정의 순서 (사건 확인 / 국내 경위 미확인)

AI 활용 갤러리 개념글 「니케 해킹사건 제보자 파악경위」(조회 약 5,200·추천 28·댓글 34)와 관련 글(조회 약 3,300·추천 43)이 오늘 국내 상위를 차지했습니다.

확인된 타임라인(보도·제작사 공지 종합):

  • 9/27 — 배급 CDN에 있는 런처 UI용 JS 4개 변조. 변조본은 외부 도메인에서 l.js를 불러옴.
  • 10/23 — 원격 접근 페이로드(LuaJIT 런타임 + 스크립트, 분석 측 명칭 K2F) 첫 실행 기록. 모든 실행에서 내려온 게 아니라 조건부 배포로 보임.
  • 10/24 이후 — 런처 실행 이력이 있으면 노출 가능 구간.
  • 11/3 — 레벨 인피니트가 문제 파일 3개 교체.
  • 11/4 02:30(서울) — 시프트업 클라이언트 패치.
  • 미해결 — CDN 쓰기 권한 획득 경로는 미공개.

노린 대상은 브라우저 저장 자격 증명·세션, API 키·토큰, 암호화폐 지갑입니다. 런처가 웹 기술(임베디드 브라우저)로 화면을 그리면서 원격 JS를 서명 검증 없이 실행하는 구조였던 게 핵심 취약점입니다. 실행 파일 서명은 멀쩡해도, 런처가 매번 받아 오는 웹 리소스는 서명 체계 밖에 있었다는 뜻입니다. 게임 런처·데스크톱 AI 앱·IDE 확장이 같은 구조(Electron·WebView)를 많이 쓴다는 점에서, 이 사건은 게임 이야기만이 아닙니다. 10/31에 다룬 Cursor 마켓플레이스 변조 확장(SSH 백도어)과 같은 계열입니다.

국내 경위(미확인): 글에 따르면 최초 제보자는 Codex로 PC 상태를 점검하던 중 수상한 프로세스·네트워크 동작을 잡았고, 게임 보안 프로그램(뱅가드)도 탐지했다고 합니다. 그러나 게임 커뮤니티에선 ‘어그로’로 차단, 깃허브에선 신상이 공개됐고, 다른 게시판은 해킹 언급을 금지했다는 주장까지 나왔습니다. 관련 글은 반박 측이 Gemini에게 물어본 답을 “가짜라는 증거”로 제시했고 이후 집단 괴롭힘이 있었다고 적었습니다.

기술적 의미:

  • 같은 ‘AI’라도 이 있는 에이전트의 관찰과, 아무 증거도 못 본 채팅 모델의 추론은 증거 등급이 다릅니다. 앞의 것은 로그·해시·네트워크 기록이 남고, 뒤의 것은 그럴듯한 문장만 남습니다.
  • 채팅 모델은 “이 보고는 사실인가?”에 대해 기본값으로 회의적인 답을 내기 쉽습니다(검증 불가 → “근거 부족”). 이게 커뮤니티에서 ‘판결’처럼 쓰이면 정상적인 경보를 꺼 버리는 효과가 납니다.
  • 댓글의 정리 — “결국 쓰는 사람 실력 차이” — 는 정확합니다. 에이전트에게 맡길 땐 실행한 명령과 산출물(해시·연결 주소)을 같이 내놓게 해야 사람이 재검증할 수 있습니다.

대응(보안 매체 권고): 저장 비밀번호 교체·2FA, API 키 재발급 후 구 키 폐기(OpenAI·Anthropic·클라우드·깃허브 토큰 포함), 지갑 이전. 노출 구간 실행 이력이 있으면 insightjs.com 접속 기록과 낯선 LuaJIT 프로세스를 점검하라는 분석 보고서(MotherSphere 깃허브)도 공개돼 있습니다.

2) 검증 과잉의 비용 — Pro 90% vs 1% (미확인 / 개인 측정)

「클맥 환불한 김에」(댓글 20)의 주장:

  • ChatGPT Pro(Codex 포함)는 Claude 대비 체감 5배 느림.
  • 작업을 끝낸 뒤 스스로 재검증 루프(테스트·린트·재조회)를 반복해 주간 한도 90%를 소모.
  • “이 범위만 확인하고 종료” 같은 정지 조건을 넣자 동일 작업이 1%.
  • 댓글: 상위 에이전트를 감독으로 두고 불필요한 검증 호출을 끊는 구성을 쓴다는 사람도 있음.

이건 11-03에 다룬 Claude Code agent_summary 오버헤드(약 16~20%)와 같은 층의 문제입니다. 모델 품질보다 의 종료 조건이 한도 소모를 좌우합니다. 12월 ChatGPT·Codex 한도 통합(11-02 확인) 뒤엔 이 차이가 채팅 사용량까지 잡아먹습니다. 어제 「WORK로 전공책 넣고 실험」(이제 조회 약 4,900)의 4%와 오늘 90%/1%는 측정 조건이 달라 직접 비교할 수 없지만, 방향은 같습니다 — 컨텍스트 재주입과 반복 검증이 비용의 대부분.

3) 계정 리스크와 구독 선택 (미확인)

  • 「클로드는 절대 신분증 주지 마라」(조회 약 3,100·추천 22): 정지 이의 신청 중 신분증 제출 → 정지 유지 + 동일 신원 재가입 차단 주장. Anthropic 공식 설명 없음. 10/30 Ultra 개편에서 ‘인증된 Ultra’ 조건이 생긴 만큼, 신원 인증과 계정 제재가 연결되는 구조 자체는 앞으로 더 중요해질 수 있습니다(해석).
  • 「[챗GPT 사용량 통합]이고 뭐고 클로드 써보고 결정」(조회 약 2,800): GPT 사용자 관점에서 Claude는 컴퓨터 사용·이미지 생성이 약하고 거절이 잦음, Codex는 한도당 작업량은 많지만 느림 → 단일 구독이면 GPT. 댓글 다수는 대화 GPT·코딩 Claude 분업, 불만 1순위는 Claude 검열.
  • 11-01에 확인한 OpenAI 기기 제한 도움말과 합치면, 양사 모두 다계정·우회 사용을 점점 어렵게 만드는 중입니다.

4) 이미지 2.6·자동화·기타

  • 이미지 2.6 기본값 변화(사용자 해석): 「그냥 2.5 프리셋이 화려했던 것뿐」은 2.5가 숨은 스타일 보강을 많이 넣었고 2.6은 프롬프트 충실도를 올렸다는 가설. 실사 인물 보정 팁(「2.6에서 개박살 난 실사 외모 바로잡기」)은 특징을 반대로 과장 묘사해 평균 얼굴로의 회귀를 상쇄하는 요령. 게임 아이콘에 부적절한 손 제스처가 섞였다는 사례도 있어 배포 전 확대 검수 필요.
  • 쇼츠 자동화 오픈소스(조회 약 4,700, CHE0DAN/recap-shorts-automation): 게시글 → 30~40초 한국어 쇼츠 파이프라인(윈도우). 저작권·플랫폼 정책 확인은 사용자 몫.
  • 티켓 매크로 + DeepSeek 캡차 풀이 후기(조회 약 3,400): 약관 위반·업무방해 소지. 기술 소개로도 권하지 않습니다.
  • 시댄스(젠트리) 7,200크레딧 첫 달 0원: 480p 생성 후 업스케일 팁, 미해지 시 33,000원 자동 결제.
  • ‘램 알트만’(확인 — 비즈니스 인사이더·전자신문·GIGAZINE): Cheeky Pint 팟캐스트에서 PC용 대용량 DRAM이 비효율이라는 취지 발언 → 11/4 X 이름을 ‘Ram Altman’으로 바꿨다 당일 복구. 머스크 “The people deserve to have their RAM too!”. 메모리 가격이 오른 상황이라 로컬 사용자 반감이 컸습니다.
  • GPT 품질·한도 불만, Argon 너프설, “금요일 6.2 공개” 소문: 모두 공지 없음(미확인).

해외 커뮤니티·보도에서 오늘 많이 나온 이야기

1) Kimi K3.1 Pro 가중치 — 공개됐지만 ‘로컬’은 아님 (확인)

  • HF moonshotai/Kimi-K3.1-Pro: 2.8T total / 104B active MoE, MXFP4 1.56TB. API $2/$10 per 1M. 해커뉴스 300점대.
  • 라이선스: 연매출 $20M 초과 기업의 MaaS 제공 시 별도 조건.
  • 서빙: B300급 8장 이상 권장 수준. RTX 5090 노트북(24GB)·64GB RAM 기준으로는 2비트 양자화를 해도 현실적이지 않습니다. 의미는 “집에서 돌리기”보다 자체 호스팅·벤더 교체 가능성(11-04 레볼루트 GLM 사례와 같은 축)입니다.
  • r/LocalLLaMA 체감: 공개는 반갑지만 장비가 없다 → 관심은 Unsloth의 Qwen3.8-Flash-Next GGUF, Gemma 4를 15% 크기로 줄인 실험, Intel B580 같은 저가 VRAM 쪽으로.
  • 오픈라우터 일간 토큰 중 DeepSeek 53% 집계가 돌았음(집계 사이트 수치, 미확인). 새로 나온 Hy4·Ripple-65B는 아직 AA 점수 없음.

2) FlashProve — 증명 가능한 추론 (확인 — Anthropic 연구 공개, 11/2)

  • 목표: API 중개·호스팅 업체가 “모델 X로 답했다”고 할 때 실제로 그 가중치로 계산했는지 zkSNARK 증명으로 확인.
  • 수치(발표 기준): Llama 4 Maverick, H100 1장, 110 tok/s 생성과 함께 약 19MB 증명, 증명 생성 비용은 일반 추론 GPU 시간의 약 70~95배, CPU 검증 17초. Lean 형식 증명, Apache 2.0.
  • 의미: Kimi처럼 공개 가중치가 많아질수록 “싼 양자화본으로 몰래 바꿔 서빙”하는 문제가 커집니다. 다만 70~95배 오버헤드라 당장은 감사용 표본 검증 수준입니다(해석).

3) Gemini 구독자 대화 학습 (확인 — 구글 도움말, HN 600점대)

개인 계정은 유료여도 ‘활동 기록 유지’ ON이면 학습 사용·사람 검토 가능, 사람이 검토한 대화는 삭제 후 최대 3년 보관. OFF면 72시간 뒤 삭제. 워크스페이스는 제외. 니케 사건과 합쳐 읽으면 채팅창에 키·로그·자격 증명을 붙여 넣는 습관이 이중으로 위험합니다.

4) RTX Spark 노트북 + 리눅스 = 1/5 속도 (확인 — MindStudio 실측)

전원 연결 상태에서 GPU가 약 780MHz에 고정. 전원 테이블이 암호화돼 리눅스 드라이버가 못 읽는 탓. GPT-OSS-120B 13.9 tok/s(리눅스) vs 65.4(윈도우), WSL 65.1. 96GB 통합 메모리는 기본값이 GPU 예약. 당분간 WSL이 우회책.

5) 그 밖에 (확인)

  • OpenAI, 피에르 인수(11/4): Codex 앱의 파일 트리·Diff 컴포넌트(Trees/Diffs), Code Storage, Pando를 만든 팀.
  • IEEE Spectrum, “AI가 40년 기술 부채를 갚게 만든다”(11/2): PHP2Shell 계열 자동 익스플로잇이 레거시 코드의 오래된 취약점을 대량으로 드러내는 흐름.

오늘 소식이 뜻하는 것, 그리고 바꾸지 말 것

  • 뜻하는 것 1: 공급망 공격의 표면은 실행 파일이 아니라 런처·앱이 매번 받아 오는 원격 웹 리소스로 옮겨 가고 있습니다. 데스크톱 AI 앱·에디터 확장도 같은 구조입니다.
  • 뜻하는 것 2: ‘AI가 말했다’는 증거가 아닙니다. **도구로 관찰한 결과(로그·해시)**만 증거로 쓰고, 채팅 답변은 가설로 다루는 습관이 필요합니다. 같은 원리로 하네스의 검증 루프도 종료 조건이 있어야 비용이 됩니다.
  • 뜻하는 것 3: 공개 가중치의 상한이 올라가면서(Kimi 46) 문제는 “쓸 수 있냐”보다 “서빙 업체가 진짜 그걸 돌리냐”로 바뀝니다 — FlashProve가 그 질문에 대한 첫 답안입니다.
  • 바꾸지 말 것: 코딩·글쓰기 기본 픽(Opus max / Sol max / Terra)은 그대로입니다. 1점 변동은 측정 오차 범위 수준입니다.
  • 바꾸지 말 것 2: Kimi 공개만 보고 로컬 장비를 늘릴 이유는 없습니다. 24GB 노트북의 현실적 로컬 후보는 여전히 30B급 이하 GGUF입니다. 리눅스 이전 계획이 있다면 RTX Spark 노트북은 드라이버 문제가 풀릴 때까지 보류.

  1. 10/24 이후 니케 PC 런처 실행 이력이 있으면 저장 비밀번호·세션, API 키(OpenAI·Anthropic·클라우드·깃허브 PAT) 순으로 교체하고, 키 사용 기록에서 낯선 호출이 있는지 확인.

  4. 데스크톱 앱·확장 점검: 쓰는 AI 앱·에디터 확장 중 원격 리소스를 받는 것과 자동 업데이트 출처를 한 번 목록화.
