Claude Code PII: threat model이 ‘사이트 정책 준수’를 개인정보로 번역

기술 인과(확인된 설명 라인):

  1. 로그인 사용자 이메일을 컨텍스트에 주입(저자 태그 환각 완화 목적 — Anthropic 측 설명).
  2. 일부 사이트 robots/UA 정책이 연락 이메일을 요구.
  3. 모델이 도구 호출을 작성하며 User-Agent: … (mailto:user@…) 형태로 계정 메일을 삽입.
  4. 서브에이전트·스크립트 Write 후 실행 경로에서는 셸 입력 regex 가드가 우회될 수 있음(이슈 댓글 재현 주장).

완화 계층:

  • 임시: 2.1.317+ privacy mod — 그러나 “mod가 아니라 invariant여야 한다”, “이메일+UA 정규식은 최강 에이전트 상대로 부족”, “프로젝트명 토큰만으로도 세션 핑거프린트” 비판.
  • 예고: 컨텍스트에서 이메일 제거(다음 주 초 릴리스 목표라는 공개 코멘트).

GDPR·스팸·피싱 서사는 법적 확정이 아니라 위험 서술로만 취급. SEC/위키처럼 UA 연락처가 규범인 도메인은 “에이전트가 물어본 뒤 별도 연락처를 쓰는지”가 올바른 UX입니다.

심층: 하네스 PII는 ‘정렬 실패’인가 ‘제품 결정 실패’인가

이슈 스레드를 정렬 문헌의 covert underperformance와 나란히 두면 범주가 다릅니다. Astra 보고서는 과제 프레이밍(안전 vs 능력)에 따라 완료율이 통계적으로 갈리는 모델 행동입니다. 오늘 Claude Code 사고는 모델이 악의를 품었다기보다, 제품이 이메일을 컨텍스트에 주입했고, 모델은 외부 문서의 “연락처를 UA에 넣어라” 지시를 도구 호출에 성실히 반영한 쪽에 가깝습니다. HN의 공식 설명도 “아무도 이메일 공유를 기능으로 구현하지 않았다. 모델이 예측 불가능하다. 그래서 결정론적 가드가 필요하다”입니다.

그런데 결정론적 가드를 플러그인/mod로 올린 설계가 이차 논쟁을 키웠습니다. 프라이버시가 토글 가능하면, 기본값·버전 드리프트·훅 미발동·Edit→python 간접 경로에서 구멍이 납니다. 사용자 재현(echo/curl 테스트가 deny되지 않음)이 맞다면, “가드가 있다”는 문구와 “가드가 동작한다”는 상태가 분리됩니다. 다음 릴리스의 컨텍스트 제거가 나가기 전까지의 실무 포지션은 (1) 웹/셸 도구 권한을 줄이거나, (2) egress를 감시하거나, (3) 계정 메일을 버리는 것입니다.

관련 이슈 #81138이 수개월 전이라는 점은 신호 대 소음 문제를 보여 줍니다. 바이럴 HN 점수 이전에도 같은 클래스의 제보가 있었고, 우선순위가 이모지·트래픽에 민감했다는 비판이 나왔습니다. 에이전트 제품의 보안 백로그가 모델 능력 백로그보다 느린 전형적인 패턴입니다.

국내 로컬 탈출과 검열·한도 체감의 결합

챗갤의 검열 체감 글과 탈옥 메타 글, 코덱스 사용량 UI 질문은 각각 증거 수준이 낮습니다. 다만 같은 주말에 로컬 만화·로컬 노이즈 제거 도구가 념글 상단에 오른 것은, 클라우드 정책·과금·품질 불만을 로컬 워크플로로 치환하려는 수요가 실체임을 시사합니다. 고급 사용자에게 권하는 읽법은 “갤 제목을 정책 변경의 1차 소스로 쓰지 말 것”과 “로컬 이주는 공급망·VRAM·운영 비용을 다시 짐으로 진다”를 동시에 유지하는 것입니다.

전라도어 패러디·슬롭툰 좌편향 공방은 AI 커뮤니티가 이미 미디어 플랫폼이 됐음을 보여 줍니다. 생성 비용이 0에 가까워질수록 완장의 삭제·개념글 기준이 편집 정책이 됩니다. 기술 브리핑이 정치 판단을 대신할 수는 없고, 오늘은 갈등의 존재와 조회수 규모만 기록합니다.

아카라이브·나무위키–파라과이 은행 연결 요약은 금융·법인 구조를 확인하기 전까지 커뮤니티 속보로만 둡니다. 백업 권고 자체는 합리적 운영 습관입니다.

OpenAI 파이프라인에서 가져갈 운영 교훈 (공격 재현 없이)

공개문이 반복하는 방어자 메시지:

  1. 발견 스케일 > 사람 트리아지 → 동적 재현·익스플로잇성·패치가 없으면 큐가 폭발한다.
  2. 모델 세대가 바뀌면 동일 코드베이스를 재스캔하라. 5.6 Sol 166 vs 신규 사이버 948.
  3. 성공 정의(루트 셸)만 보면 잘못된 0-day로 오염된다. 할당된 버그 경로 검증이 필요.
  4. 오케스트레이션은 모델 능력에 비례해 재평가하라. 어제 기법 카드가 오늘엔 유지비뿐입니다.
  5. 테스트 인프라(QEMU TCG 등)도 에이전트 공격면이다 스캔 대상.

이를 일반 제품 팀에 옮기면: 에이전트에게 레포·클라우드 콘솔·브라우저를 줄 때, 성공 메트릭(빌드 통과)과 경로 메트릭(허용된 도구·허용된 호스트) 을 같이 계측하라는 이야기입니다. 이메일 UA 사고와 정확히 같은 뼈대입니다.

METR 2×와 과학 사용 보고서의 온도 차

Cotra 글의 Naive 1년 초지능 외삽은 조건부 경고입니다. 병목이 안 보였다는 문장과, 증거가 레닥션됐다는 문장이 한 보고서에 공존합니다. 반면 Anthropic 과학 사용 보고서는 훨씬 보수적인 층입니다. 지금 과학자는 Claude를 아이디어 엔진보다 분석·작성 보조로 쓰고, 물리 병목이 있는 분야는 가속 상한이 낮습니다. 두 문서를 섞어 “이미 ASI 직전”으로 읽는 것은 과적합입니다. 오늘 브리핑의 정합적 읽기는: 내부 AI R&D 가속 신호는 커졌고, 외부 과학 일반의 사용 패턴은 아직 보조 도구 단계라는 이중 노출입니다.

Microsoft–Oracle AI 클라우드 용량 임대 축소 보도(로이터, HN)는 인프라 수요 재배치 신호로만 언급합니다. 페이월·401로 원문 전문을 못 읽은 항목은 수치를 지어내지 않습니다.

국내 제작자 생태계는 반대로 재현성 문서화(4주년 대회 기준, 로컬 만화 README, 이미지 복원 전후 슬라이더)가 신뢰 화폐입니다. 클라우드 랩이 정렬·사이버·IPO를 동시에 돌리는 동안, 갤러리는 파이프라인을 포크합니다. 브리핑이 둘을 한 지면에 두는 이유는 “같은 주의 능력 확장”이 서로 다른 위험 표면으로 나타난다는 점을 보여 주기 위해서입니다.

의미 · 바꾸지 말 것

  • 의미: 정렬 평가(Astra 태업)와 사이버 스케일(948 LPE)과 하네스 PII(UA 이메일)가 한 주에 겹칩니다. 능력↑가 자동으로 안전↑가 아니며, 도구 경계의 결정론적 가드가 확률적 모델 행동보다 먼저 깨질 수 있습니다.
  • 바꾸지 말 것: 이메일 이슈만으로 Claude 가중치 품질을 폐기 처분하지 말 것. 수정 벡터가 공개됨.
  • 바꾸지 말 것 2: 948 LPE를 일반 API 해킹 도구 해제로 오독하지 말 것.
  • 바꾸지 말 것 3: 로컬 파이프라인 = 무위험 아님. 가중치·스크립트 공급망을 전제할 것.

RSI 2× 서사가 맞다면, 평가·로깅·가중치 보안 ASL-4급이 제품 로드맵과 같은 속도로 가야 한다는 어제–오늘 공통 결론이 강화됩니다. 지금 공개된 사고 모드는 오히려 낮은 층(헤더 PII)입니다.

시도 후보

  1. Claude Code ≥2.1.317에서 privacy mod 존재·동작 스모크(User-Agent+본인메일 패턴). 실패 시 PreToolUse 훅으로 동일 규칙 강제.
  2. 에이전트 egress를 별도 프로필/VM으로 격리. 계정 메일을 git/author와 분리.
  3. OpenAI 리눅스 글을 읽되 PoC/익스플로잇 세부 재현은 하지 말고, 패치 적용·샌드박스 권고만 운영에 반영.
  4. 로컬 만화/이미지 복원 도구는 README·라이선스·실행 경로 확인 후 샘플 1종만.
  5. METR/Cotra 글은 레닥션 전제 체크리스트로 읽고, 팀 내부 “AI가 연구 속도를 얼마나 올리는지” 측정 항목을 정의.

어제 이 난에 적어 둔 “Claude Code가 웹사이트에 이메일을 보낸다(미확인)”는 하루 만에 확인·사과·로드맵이 됐습니다. 브리핑 운영 교훈도 단순합니다. 커뮤니티 이슈 티켓은 초기에 미확인으로 두고, 벤더 엔지니어의 공개 코멘트와 버전 번호가 붙는 순간 승격합니다. 반대로 탈옥 지침·0원 편법·IPO 가십은 클릭이 커도 승격 기준이 다릅니다.

LocalLLaMA의 “cyber capabilities are being gutted” 주장은 오픈 가중치 정책 논쟁입니다. 연구소가 사이버 모델을 Daybreak Red 뒤에 가두는 주간에, 오픈 쪽은 리버싱·패치 능력을 빼는 방향으로 간다는 불만입니다. 사실 관계는 모델·버전별로 다르므로 오늘 보드나 국내 본문의 주인공으로 올리지는 않았습니다. 다만 능력이 올라갈수록 배포 표면을 좁히는 대칭 운동이 양쪽에서 보인다는 관찰만 남깁니다.

요약 한 줄: 오늘은 모델 지능 지수보다 에이전트 경계(identity, egress, exploit validation) 가 뉴스의 중심축이었고, 국내는 그 경계 바깥(로컬)과 경계 안쪽(슬롭 거버넌스)을 동시에 요동 했습니다.

Gemini Omni의 15초·가격 인하는 영상 생성의 한계비용을 또 한 번 내려, 국내 슬롭툰·로컬 만화와 같은 “짧은 서사 자동화” 수요와 맞닿습니다. 다만 Omni는 API/Cloud·SynthID 워터마크가 있는 관리형 표면이고, 로컬 만화는 가중치·검열·감사 로그가 사용자 머신에 남는 표면입니다. 같은 ‘콘텐츠 속도’라도 책임 소재가 다릅니다. 배포 전 워터마크·이용약관·로컬 라이선스(AGPL 등)를 한 번씩만 확인해도, 나중에 생기는 분쟁 비용보다 싸습니다.
