‘덜 깎였다’는 40%였고, 같은 날 6.2가 덜 생각한다는 p값이 나왔다

2026년 11월 27일 · 옵티웍 AI 데일리 · 고급

공유 · 구독
텔레그램에 공유 채널 구독 X에 공유
한 줄 요약 (GEO) OpenAI는 미터링 보정 폭을 숫자로 밝히고 banked reset으로 봉합했지만, 외부 대전 데이터는 6.2의 추론·출력 토큰 감소를 유의하게 잡아냈다. 구글은 같은 오후 쿼터 전면 초기화와 OpenRouter 지출 역전으로 응수하면서도, Workspace에선 에이전트 접근을 자사 MCP로 묶는 약관을 냈다. 관대함과 통제가 동시에 커지는 국면.

수집: 국내 자동 수집 정상(11-27 07:49 KST, 후보 60, errors 0 — chatgpt 개념 24·목록 24, ai_utilize 개념 28·목록 27). 추가로 전일 아침 이후 신규 목록 전체(ai_utilize 167p ≈1,970편, chatgpt 19p ≈210편)를 받아 조회·추천·댓글 상위 약 60편 본문·댓글을 직접 읽음. 해외: Reddit RSS 0/8(429×7, 404×1) — 레딧 반응 없음. HN 1면 + Algolia 36h(points≥40, 71건), X 원문(티보·바룬 모한·OpenRouter·샤빈스키·타리크), arXiv·블로그·보도로 교차. 11-26에 다룬 Codex 메일·T3 Code·수학 배치·국내 결제액은 델타만, GPT-5.6 12-23 종료(11-24)·Chat/Work 통합(11-25)은 반응만.

오늘 핵심 세 가지

  1. Codex 6.2 미터링 보정 폭 공개 — 지난주 대비 Astra 40%·Sol 25% 빨리 한도 도달(확인 — 티보 X, 11-26 11:50 KST). 소급 청구 없음, 6 Astra·6.1 Sol 대비로는 여전히 allowance 효율 우위라는 단서, Go·Plus·Pro·Business 전원 1회(16:26 KST 지급 확인 글). “40% 빨리”의 정의(소모율 ×1.4 vs 소요시간 −40%)는 미공개라 처리량 감소 폭은 29%~40% 범위로만 말할 수 있음.
  2. 같은 날 외부 데이터: 6.2는 ‘덜 생각한다’(측정 확인 / 원인 해석 미확인). micjm의 OpenCode 기반 대전 데이터에서 6.2 Astra·Sol의 상대 ·출력 토큰이 6/6.1 대비 이탈치 수준으로 감소, 추론 감소 p=0.00013(Sol)·0.0064(Astra). 보정 이전의 “6.2 효율 체감”은 미터 버그 + 실제 토큰 감소가 겹친 결과일 가능성.
  3. 구글: 관대함과 통제를 동시에(확인). Antigravity 전 사용자 Gemini 쿼터 추수감사절 초기화(16:19 KST), OpenRouter 주간 지출에서 OpenAI 대비 구글 비중 50% 돌파(11-16 주) — 그러나 Workspace 약관 부록으로 2027-02-01부터 AI 에이전트는 Google MCP 서버 경유 의무, 공개 Gmail MCP는 send/reply/forward/draft 수정이 partner-only.

1) 맥시멀리즘 이미지 프롬프트 — 「아까 념글 간 ai붕이 프롬공유함」(7,281·37·35) / 「이미지 생성 해봤는데 이렇게 하는거 맞나」(5,307·44·37) / 「이런식의 이미지 만들려면…」(4,218·23·37) (개인 경험 — 미확인)

  • 불변 제약: 원본 화면 비율·레이아웃·제품 외형·핵심 정보·UI 요소 유지.
  • 스타일 스택: 파칭코 잭팟 연출 + 할인점 POP + 중국 모바일 MMORPG VIP 이벤트 + 카지노 광고 + 가챠 SSR 연출, 황금 3D·무지개 크롬 타이포, 금속 테두리·네온 발광, 초고채도·초고대비.
  • 밀도 지시: 화면 전체를 문구·체크리스트·순위표·인증 마크로 채우고 같은 정보를 다양한 크기로 반복, “미니멀리즘·여백 절대 금지”.
  • 그라운딩 조항: “공식 홈페이지 정보를 참고해 기능을 배치하되 확인되지 않은 사양은 만들어내지 말 것.” 장식 과잉 지시와 사실성 제약을 분리한 점이 포인트.
  • 댓글 팁: “더 빽빽하게”를 n회 반복 요청. Claude SVG 재현 시도(435·8·12)는 “깔끔해서 감동이 덜함” — 래스터 이미지 모델과 벡터 코드 생성의 질감 차이.

반대 축: 「념글 존나 기괴하네」(3,503·29·14)는 AI 칭찬 캡처 자랑 문화를, 「지피티한테 아이큐 물어보고…」(2,520·19·11)는 IQ 추정 놀이를 비판(“적당히 말 통하면 110~125”). 11-26의 ‘갤러리 스레드’ 프롬프트 이후 소비가 놀이로 굳는 중.

2) 리셋권 — 「코덱스 리셋권」(4,254·18·28) / 「GPT-6.2 오류 수정…Astra 한도 40% 빨리 소진」(489·8) / 「진짜 ㅈ까 소리 듣고있는 티보」(433·11) (발표 확인 / 폭 해석 미확인)

  • 공식 문구: “same work will use more of your plan’s usage allowance … reach your limits 40% faster on GPT-6.2 Astra and 25% faster on Sol … should still see these go further compared to 6 Astra and 6.1 Sol. Other models weren’t affected, and we won’t charge you for the difference.”
  • 해석 범위(계산): 소모율 ×1.4로 읽으면 allowance당 처리량 1/1.4 ≈ 0.714(−28.6%), 소요시간 −40%로 읽으면 0.60. Sol은 ×1.25 → 0.80, 또는 0.75. 댓글 “1.4배냐 1.67배냐” 논쟁이 정확히 이 모호성. OpenAI는 기준을 명시하지 않음.
  • 리셋 인플레이션: 11-24 Business banked reset + 이번 전원 1회로 “초기화권 왜 이렇게 쌓임”, “난 리셋권 다섯 개” 글. 리셋 재고가 많으면 단기 체감 손실은 상쇄되나, 주간 기본 allowance 자체는 줄었다는 점은 불변.
  • “서버 부하 때문에 버그라고 포장” 류 주장은 근거 없음(미확인).

3) 6.2 불만 정리 — 「GPT <--지금 이 새끼가 왜 욕먹는지 간단정리」(974·15·9) / 「6.2아스트라…수준」(650·15·15) / 「나만 6.2 들어서…이해가 안되는거야?」(866·11·4) (체감 — 미확인)

요지: 기대 이하 신모델, 추론 약화 체감, 한도, 지시 불이행·소통 비용 증가 → 작업 지연 → 한도 누수, 가격, “실무는 Claude”. 블렌더 MCP + Astra xhigh 5시간 무성과, 5.6 Sol 대비 장황한 3문단 응답, 5.6 종료(12-23) 애도 글 다수. 「갤 대문 변경」(628·17·17) 작성자도 “다음 달 Claude Max로 이동, x10 플랜 유지 이유 없음”. 해외 2번 측정과 방향이 일치하지만, ‘장황함’ 체감과 ‘출력 토큰 감소’ 측정은 겉보기에 반대 방향이라 원인을 하나로 묶기 어려움(채팅 UX 튜닝과 에이전트 추론 예산은 별개 노브일 가능성).

Chat/Work 통합 사전 적용 후기(번역 정리 — 「Gpt chat work 통합 사용자 후기」 776·4, 미확인): 레딧 Pro 테스트 대상자 후기를 옮긴 글. 쟁점은 세 가지다. ①대화용 기본이 GPT-6.2 Instant로 좁아지고 더 높은 추론은 Work 모델로 가야 해 답이 건조해졌다는 주장과, “‘Latest’를 누르면 Instant·Medium·High·Extra High·6 Pro를 다 고를 수 있다”는 반박이 공존. ②GPT-6 Pro도 통합 사용량을 소모하며, 드라이브 파일 생성·테스트 30분에 사용량 21%가 줄었다는 실측 주장. ③맞춤 성격·문체가 평범한 비서 톤으로 평탄화됐다는 불만(추천 501). 국내 댓글은 “프로 횟수제가 없어지는구나”와 “일반 채팅 무제한을 작업용으로 악용하던 게 문제였다”로 갈렸고, 「[챗GPT 통합] 발작하는 이유가 뭐야??」(582·18)·「통합 그렇게 손해면 옮기면 되는 거 아님?」(447·19)처럼 이번 반발의 상당 부분이 6.2 품질이 아니라 ‘무제한 대화’라는 예외적 혜택의 종료에 대한 것이라는 관점도 나왔다. 품질 불만과 혜택 축소 불만을 분리해 읽어야 6.2 자체의 평가가 흐려지지 않는다.

  • 플랫폼 통제는 커진다. 구글 Workspace MCP 의무화, Fable 사이버 분류기 폴백, Antigravity 타사 호출 경계 — 에이전트가 무엇을 ‘대신 할 수 있는가’를 벤더가 정하는 방향.
