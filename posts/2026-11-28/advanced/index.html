Anthropic이 발표문에 적어 둔 한 문장이, 110만 뷰짜리 ‘사보타주’ 논쟁이 됐다

2026년 11월 28일 · 옵티웍 AI 데일리 · 고급

공유 · 구독
텔레그램에 공유 채널 구독 X에 공유
한 줄 요약 (GEO) Fable 5.2의 ‘AI R&D 역량 학습 단계 제한’은 11-09부터 공개된 사실인데, 픽셀아트 확산모델 학습 비교 한 장이 그 경계가 어디까지인지 아무도 모른다는 점을 드러냈다. 같은 날 구글은 할인과 비공식 하네스 정지, 서드파티 OAuth 개방 신호를 한꺼번에 냈고, 암호 쪽에선 ‘조건부’ 결과와 검증기 건전성 버그 목록이 나란히 올라왔다. 성능표보다 ‘정책 경계’가 더 중요한 변수가 된 하루.

수집: 국내 자동 수집 정상(11-28 07:52 KST, 후보 60, errors 0 — chatgpt 개념 24·목록 24, ai_utilize 개념 28·목록 26). 추가로 전일 아침 이후 신규 목록(ai_utilize 154p ≈1,600편, chatgpt 12p ≈50편)을 받아 조회·추천·댓글 상위 약 57편 본문·댓글을 직접 읽음. 해외: Reddit RSS 0/8(429×7, 404×1) — 레딧 반응 없음. HN 1면 + Algolia 36h(points≥40, ≈70건), X 원문(Astropulse·Zane·바룬 모한), Anthropic 발표문, GitHub PR/이슈, IACR ePrint, 보도로 교차. 11-27에 다룬 맥시멀리즘 프롬프트·Antigravity 초기화·OpenRouter·중국 증류는 새 전개만.

오늘 핵심 세 가지

  1. Fable 5.2 ‘AI R&D 역량 제한’ — 문구는 확인, ‘은밀한 사보타주’는 미확인. Anthropic 발표문(11-09)은 “AI 개발을 가장 직접 가속하는 연구 역량의 발전을 학습 중 제한했고, 가속기 커널 최적화·LLM 아키텍처 개선에서 Fable/Mythos 5.2는 Opus 5.5 수준”이며 “이 영역 일부 주제(비표준 가속기 커널 개발 등)는 Opus 5로 transparent fallback”이라고 적었습니다. 11-27 Astropulse(Retro Diffusion)가 Claude 설계 학습 24k step vs Gemini Neon 4k step 비교를 올려 110만 뷰, HN 523·265. 핵심 쟁점은 ‘학습 시 ’은 런타임 표시가 불가능하다는 점입니다 — fallback 표시는 안전장치(분류기)에만 적용됩니다.
  2. Google: 할인·정지·OAuth 개방 신호가 같은 날 (부분 확인). 신규 가입자 BF 할인은 11-27(미국)부터 계정·국가별 롤아웃(미국 AI Pro 연간 첫해 $99.99). 국내는 “40%만”, “한국 미노출” 보고가 혼재. 동시에 Antigravity를 ACP/MCP/프록시로 물린 계정의 6시간 정지 보고, 그리고 Pi(earendil-works/pi) PR #12614 “Google AI plan”(11-27 17:09 KST 오픈, 미병합)이 “구글 구독 OAuth를 서드파티 에 연다”는 신호로 읽혔습니다(2,723·13·24).
  3. 암호: ‘조건부’ 결정적 준지수 DLP + 검증기 건전성 목록 (공개 확인 / 실효 미확인). 저장대 Liu·Zhang·Ren(ePrint 2026/3020)은 OpenAI의 Cauchy–Hermite Boolean tensor contraction(10월)을 가정하면 𝔽ₚ*와 소수위수 타원곡선 DLP를 결정적으로 2^{O(b/√(log log b))} = p^{o(1)}에 푼다고 주장. 같은 날 더타임스의 숄체 인용(“공개키 암호 파괴의 순수 난도는 리만보다 높지 않다”), djb의 증명검증기 soundness 버그 목록(Lean 23, Coq/Rocq 111)이 함께 돌았습니다.

해외 커뮤니티·1차 자료

1) Astropulse “It’s very very real” + HN(523·265) (발표 문구 확인 / 사보타주 미확인)

경과: Fable 5(초기) 시스템 카드 p.13에 “frontier LLM 개발 대상 요청에서 효과를 제한, 이 안전장치는 사용자에게 보이지 않음” → 반발 후 수일 만에 가시화로 변경(Wired 보도) → 5.2 카드·발표문: 분류기 차단은 Opus 5로 표시, Claude Code에서 “flag 시 모델 전환” 설정으로 계속/중단 선택 + 별도로 학습 단계 역량 제한(커널 최적화·LLM 아키텍처에서 Opus 5.5 수준). HN 상위 반론(jsnell)은 “동적 열화가 아니라 학습 후 역량일 뿐”, 재반론은 “내부용 스냅샷이 다르면 파인튜닝이 사실상 safeguard와 같다”, “거절이 아니라 ‘수행하는 척’이면 기만”.

기술적 쟁점 정리:

  • 표시 가능성: 분류기 기반 차단은 이벤트가 있어 표시할 수 있지만, 가중치에 녹은 역량 저하는 요청 단위로 탐지·표시할 방법이 없습니다. 사용자가 체감하는 건 “이상하게 못함”뿐.
  • 범위: 공지 범위는 “AI 개발을 가장 직접 가속하는 역량”인데, Astropulse의 대상은 소형 픽셀아트 확산모델(rd-flow-64 계열) 학습 파이프라인. 이 정도까지 열화가 번진다면 공지 범위보다 넓은 것이고, 아니라면 단순 품질 편차입니다. 비교는 step 수(24k vs 4k)만 공개됐고 데이터·하이퍼파라미터·시드 동일성 미공개 → n=1, 미통제.
  • 실무 신호: HN 일부 사용자도 “Fable·첫 Sol 이후 RL 실험 관리가 불필요한 실험 남발·처리량 무시로 나빠졌다”는 일화를 보탬. 다만 OpenAI 모델도 같이 언급돼 Anthropic 특정 효과로 분리 불가.

권고: ML 학습 파이프라인 작업은 (a) 핵심 설계 단계에 타사 모델 교차 생성, (b) loss 곡선·처리량 같은 정량 지표로 에이전트 산출물을 회귀 검증, (c) Claude Code의 fallback 설정을 ‘중단’으로 두어 전환 이벤트를 눈에 보이게.

2) 암호 클러스터 — ePrint 2026/3020(HN 200·90) / 더타임스(115·149) / djb falseccp(152·73) (공개 확인 / 실효 미확인)

  • 2026/3020: 10월 ETH 반박 이후 나온 타원곡선 DLP Las Vegas 준지수 알고리즘(Akshima et al., Kaarelson)을 결정적으로 만들고 𝔽ₚ*까지 확장. 재료는 (i) 2m-fold sumset이 군 전체를 덮는 소형 affine-interval factor base의 결정적 조건부 기댓값 구성, (ii) 저차 산술 코어를 Θ(b) 경계 와이어로 압축하는 terminal-preserving partial contraction. GRH·smoothness 휴리스틱 불요, 무작위 비트 0. 단 OpenAI의 Cauchy–Hermite Boolean tensor contraction을 가정. 공간 2^{O(b/(log b)^{1/4})}이라 실용 크기에서의 상수·메모리는 논외. 실전 ECC 파괴 주장 아님.
  • 더타임스: HN에 인용된 숄체 발언이 쟁점. 토론은 “P=NP여도 갤럭틱 지수면 무의미” vs “고가치 루트 인증서 몇 개만 깨져도 PKI 붕괴”, PQC 안전성에 대한 연쇄 질문.
  • djb: 증명보조기 보고 수 — HOL Light 3, Mizar 7, Metamath 9, Isabelle 20, Lean 23(native_decide 제외), HOL4 24, Coq/Rocq 111. 2026년 보고가 다수. 권고는 최소화·다중 검증기 교차·검증된 커널(Candle 등). 11-21 GRH Lean 증명처럼 “컴퓨터 검증 완료”를 근거로 삼을 때 어느 커널·옵션으로 통과했는지까지 봐야 한다는 신호.

의미 — 그리고 바꾸지 말 것

  • 벤더 정책 경계가 벤치 점수만큼 중요한 사양이 됐습니다. 오늘 세 축 — Anthropic의 역량 형상, Google의 하네스 정지/OAuth 개방, OpenAI의 계정 간 로컬 대화 차단 — 은 모두 “이 모델로 무엇을, 어느 경로로 할 수 있나”를 바꿉니다. AA 점수표에는 이 축이 없습니다.

  • ‘검증됨’의 계층을 구분하세요. 조건부 정리(2026/3020), 커널 soundness(djb), 실전 파라미터 공격은 서로 다른 층위입니다. 헤드라인의 “암호 붕괴”는 아직 첫 번째 층위입니다.
