## 국내 — 화면 통합 공포와 툴체인

### Chat–Work UI 수렴 (확인·커뮤니티)

**확인:** 「공홈) Chat-Work 통합이 다가온다」(조회 최상단권·추천 23). 관측 두 줄: (1) GPT **웹 UI가 코덱스처럼** 변함, (2) 웹에서 보기 드물던 **사용량 미터** 노출. 댓글 해석 벡터: 프로맥스 정당화 / 버킷 통합 / 클로드 이탈 / “한도 늘리면 OK”. 인접 「oai가 신이긴 한듯」(추천 40)은 키워드 압축 — **사용량½·아스트라 체감 반토막·루나 라우팅·6솔 택갈이·5.6솔 퇴역·고가 요금제** — 에도 잔류 수요가 있다는 자조입니다.

고급 읽기: **레이아웃이 닮은 것 ≠ 결제 풀이 합쳐진 것.** 미터가 Chat 표면에 나타난 것은 (i) 투명성 UX, (ii) Work/Codex와 같은 과금 언어로 정렬, (iii) 실제 entitlement 통합 — 세 가설을 구분해야 합니다. 계측 제안: `(surface, model_id, 5시간%Δ, 주간%Δ, task_class)` 를 UI 변화 전후에 이틀만 고정.

**미확인:** 공식 통합 발표, 프로맥스 SKU·가격, 루나 라우팅이 “편법 응징”인지 capacity policy인지. 운영 규칙: 통합을 가정하더라도 **아스트라/솔을 Chat 기본값으로 올리지 말 것**. 양적 작업은 루나·로컬, 깊은 판단만 오푸스·아스트라 스파이크.

### 뮤즈 = 에이전트 SKU 관심 (확인·교차 / 절차 미이전)

**확인:** 「메타 muse ai 사용법 정리」(2.5천뷰) — 이메일·캘린더·목표·피드에 묶인 **에이전틱 비서** 프레이밍, “10분이면 감”. TechCrunch(9/25) 뮤즈 **얼리액세스**. HN — **뮤즈 ↔ OpenAI `muse-special`** 관측.

**브리핑 경계:** 지역·스토어·VPN·리딤코드·“무제한 토큰” 주장은 약관·계정·보안 이슈라 **재현 절차를 옮기지 않습니다.** 고급 체크리스트만: OAuth 범위 최소, 캘린더 쓰기 금지로 시작, 로그아웃·삭제 경로, 데이터 export. 백엔드가 타사 모델이면 **정책·로그·보유 기간**도 벤더 문서와 교차하세요.

### webgpt ★90 · Worktrail = 컴파일러/메모리 분기 (확인)

**확인:** webgpt — ChatGPT computer-use/플러그인 경로로 웹 작업을 **서브에이전트**화하는 국내 오픈소스, 스타 약 90. 글쓴이 운영 힌트(주관): **설치·컴퓨터 사용만 아스트라 low**, 이후 오케스트레이터는 하위 모델 — “지능이 필요한 구간과 지시 준수 구간을 분리”. Worktrail MCP — 세션을 자주 자르거나 compact하면 **결정·제약·evidence가 사라지는** 문제를, 대화 통짜 요약 메모리(임베딩·전체 재주입)가 아니라 **Thread 계보**(Focus/Decision/Constraint/Evidence/Next) + UI Now(지금까지/다음)로 풀겠다는 설계입니다. 일반 memory MCP와 차별: 벡터 회상 배제, 코드는 git에 위임, **현재 유효 상태** 우선.

D+3의 토큰 위생 체크리스트가 D+4에서 **구현체 후보**로 구체화된 형태입니다. HN의 에이전트 하네스·트레이스 마이닝·터미널 멀티플레이어 스레드와 **같은 축** — 프론티어 소모를 라우터·컴파일러·상태기계로 줄이기.

**미확인:** 자동 브라우저 조작의 ToS, 다른 도구와의 충돌, Worktrail 스키마 안정성. 프로토콜: `task_id → thread_id → evidence_hash`만 이틀 강제.

### 오푸스 잔량 체감 · 14% 규칙 · 지출 트리아지

**확인(커뮤니티):** 저가 클로드 플랜에서 오푸스 **high** 1시간 후에도 잔량 — “사랑과 은총” 밈. 댓글: 5시간 창↔주간 환산이 바뀐 것 같다는 가설, **20x≠주간 20배**. 핫 「하루 14%」= 소프트 예산. 「잔량 5%·리셋 5일」 트리아지 댓글: 솔 / 루나 / 크레딧 / 웹쫀쿠.

**미확인:** 효율 개선이 모델·라우팅·서버사이드 쿼터 중 무엇인지. 의사결정 단위는 여전히 **기울기 + 표면**, 배율 밈이 아닙니다.

### 모더레이션 · 환쫀쿠 · SKU 판타지

**확인:** 규정 안내 — 타 커뮤니티 언급 제한 + **팬보이/안티 갈라치기 삭제**. 문화전쟁이 모더레이션 KPI가 됐습니다. 「환쫀쿠 적극 이용」·「100/200 폐지·카카오 종료·여권 KYC」= **미확인/유해**. 브리핑은 공유·우회·다계정 **재현 없음**.

### 로컬·오픈: MICA 4B · Daemonlet · 미로 벤치

**확인:** `sky7350/Mica-v0.1-4B` — Jev류 4B, 한국어, 약 7.7만행·3.47천만 토큰, 공개 벤치 미학습 주장, 풀 바이브코딩, 추천 30. Daemonlet v0.8 — 로컬 Gemma E4B/12B 캐릭터챗. 미로 벤치 — 사람 vs LLM 시각 미로, 도구 없는 동등 조건.

2. 코딩 루프 → 솔 (effort 사다리, 아스트라 점프 금지)

이 맵을 쓰면 “통합되면 끝/아니다” 싸움 대신 **오늘 잔량으로 어느 칸을 살지**만 고르게 됩니다. D+3의 솔 회귀 서사는 사라지지 않았고, D+4는 그 위에 **계량기가 올라온 화면**을 얹었습니다.

### 에이전트 권한을 줄이는 실무 한 페이지

해외 사고 뉴스를 “오픈AI가 위험하다”로만 읽으면 국내 뮤즈·캘린더 연동 관심을 놓칩니다. 같은 능력의 다른 면입니다. 실무 한 페이지:

1. **읽기 허용 / 쓰기 기본 거부** — 메일 초안은 만들되 전송은 사람.
2. **세션 TTL** — 장시간 무인 루프 금지, 종료 시 토큰·OAuth 회수.
3. **로그** — 에이전트가 연 URL·올린 파일 목록을 하루 한 번만 훑기.
4. **블라스트 반경** — 개인 드라이브·회사 리포·결제 수단을 같은 에이전트에 묶지 말 것.

국내 Worktrail이 “현재 상태”를 강조하는 이유와 맞닿습니다. **기억이 많을수록 권한이 넓어지면 사고가 커집니다.** 상태기계는 좁고, 권한은 더 좁게.
