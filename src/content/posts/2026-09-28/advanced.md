### Opus creative oneshot / pipeline (확인·커뮤니티 / 재현성 미확인)

**확인:** recommend 상단이 “모델이 무엇을 말해 줬나”가 아니라 **무엇을 렌더링했나**로 이동했습니다. 젬황 15초 글의 운영 포인트는 세 가지입니다. (i) 스킬·커스텀 하네스·MCP를 끄고 productivity 플러그인+추론 맥스+권한 허용, (ii) 프롬프트는 쇼릴/모션 디자이너 persona + “모든 걸 쏟아부으세요” 한 장, (iii) 댓글 주장상 모델이 ffmpeg를 자체 설치하고 **수정 가능한 모션 그래픽**을 남김. 공모전 글은 Astra 실패 → Claude 구독 전환 서사와 “원샷+조정 2~3 / Pro 8~15%” 계측을 남깁니다. 사과 Artifact·클로드 춤(이미지→Seedance→Gemini TTS→Opus 조립)은 **원샷 신화와 파이프라인 노동**이 같은 추천 레이어에 공존함을 보여 줍니다.

고급 읽기: oneshot 추천은 **데모 선택 편향**이 큽니다. 계측 제안: `(artifact_type, oneshot_bool, edit_rounds, weekly%Δ, tool_permission_set, wall_clock)` — 쇼릴 성공을 구독 ROI로 옮기려면 edit_rounds 분포가 필요하고, “ffmpeg self-install”은 **코드 실행·네트워크 권한**이 열린 좌석에서만 일반화하세요. 보안 함의: 원샷 모션 = 임의 바이너리 설치 권한. CI·회사 좌석에서는 allowlist 없이 재현하지 말 것.

**미확인:** 전 좌석 동일 퀄, Artifact 지속성, 공모전 심사 통과. 운영 규칙: 데모 KPI를 스프린트 완료 정의에 넣지 말 것. “영상 시장 박살” 댓글은 온도계입니다.

### 하네스 세금을 스프린트 언어로 옮기기

76판 글이 남긴 운영 문장은 “모델 업그레이드 티켓”보다 **도구·위임 정책 티켓**에 가깝습니다. 같은 Opus 5.5를 박아도 CUELO·Claude Code·Codex의 승패가 과제 클래스마다 갈렸다는 점은, 팀 위키에 `default_harness: claude_code`처럼 고정값을 오래 두는 습관을 흔듭니다. 대신 `(task_class → harness_order)` 표만 두고, 분기마다 **한 티켓짜리 bake-off**를 넣는 편이 안전합니다. 서브에이전트는 “병렬로 빨리”가 아니라 **토큰 배수·정답률 분산**을 사는 옵션입니다. 혼자 51초·119K로 끝나던 보통 과제가 Luna Maker 전부 위임에서 4분29초·488K로 불어난 숫자는, 코드리뷰에 “왜 에이전트를 켰나” 체크박스를 넣을 근거로 충분합니다.

초대형(패키지 6·테스트 960)에서 병렬 Maker가 토큰을 두 배 넘게 쓰고 점수가 떨어진 사례는 더 독합니다. **분할하기 좋아 보이는 과제일수록** 먼저 혼자 한 바퀴의 베이스라인을 남기라는 뜻입니다. Codex가 일부 난이도에서 위임 후 빨라졌다는 예외는 “서브에이전트 금지”가 아니라 **하네스별 예외 테이블**이 필요하다는 신호로 읽습니다. 릴리즈 체크리스트 초안: (1) 과제 클래스 태그, (2) 기본 `subagent=off`, (3) ON 시 예상 토큰 상한, (4) 숨긴 테스트로만 채점, (5) 실패 시 하네스만 바꾸고 모델은 고정.

스킬·프롬프트 부채는 같은 아침의 「요푸스 최적화」와 맞물립니다. 새 모델이 뜨면 구 스킬이 **침묵 실패**를 만듭니다. “전면 재검토 및 수정” 한 줄을 모델에게 맡기는 패스는 비용이 싸 보이지만, 리뷰 없는 자동 재작성은 또 다른 슬롭입니다. 권장 흐름은 `rewrite → human diff → golden ticket 3개`입니다. Astra용 skills 아티클을 Codex에 던지라는 댓글 팁도 같은 패턴 — **문서 이식이 모델 이입보다 먼저**입니다.

### Sol exile을 제품 가설로만 다루기

「채팅에 안 쓰이는 이유」가 Arena 텍스트 패배를 인과처럼 붙인 순간, 커뮤니티는 설명 욕구를 채웠지만 운영은 위험해집니다. 채팅 목록에 Sol이 없다는 관측(확인·좌석별)과, Arena에서 Terra에 졌다는 캡처(2차), 그리고 “그래서 오픈AI가 채팅에 안 넣었다”(미확인)는 **세 문장으로 분리**해야 합니다. 팀 채널에 한 줄로 합치면 다음날 Codex 좌석까지 비우게 됩니다.

D+5의 30% regression 밈과 D+6의 Arena 서사는 같은 “Sol 조롱” 클러스터지만 검증 방법이 다릅니다. 전자는 **내 티켓 A/B**, 후자는 **제품 presence 매트릭스**입니다. 둘 다 AA Coding Agent ~57·작업당 $1.06 Pareto와 직접 모순되지 않습니다. 모순처럼 보이는 이유는 표면(chat vs coding harness)과 메트릭(체감 vs CA index)이 섞이기 때문입니다. 로컬 메모 템플릿: `surface / model / effort / success / minutes / weekly%Δ / note(arena|oneshot|rename)`.

신규 비호감 개념글이 나열한 3주 이벤트 스택은 **온보딩 여정 맵**으로 쓰면 쓸모가 있습니다. Astra로 유입 → 한도·라우팅 충격 → 6Sol 체감 → 고가 SKU·라벨 삭제. 각 단계에 내부 대응(FAQ 문장, 기본 모델 노출, 미터 설명)이 있었는지 점검하는 체크리스트가 되고, “티보 욕”으로만 소비하면 학습이 0입니다. 헤비 유저 레이어의 분노는 같은 스택의 **미터 앵커 상실**(5x/20x → Standard/More)에 더 가깝습니다. 좌석 이동 결정회의에서는 두 코호트를 분리해 말하세요.

### KR tier copy와 merge 가설의 공존

스탠다드/더 많은 기능 문구가 Work·Codex 확대·속도 클레임을 명시한 것은, D+4~D+5의 “웹이 코덱스처럼 보인다” 관측과 **같은 방향의 카피 정렬**일 수 있습니다. 그렇다고 H3 entitlement merge가 확정된 것은 아닙니다. Token Gremlin의 “Chat과 agentic tasks는 당분간 분리” 멘트는 여전히 카운터입니다. 고급 태도는 어제와 같습니다. `merge_hypothesis: contradicted_by_community_2026-09-27 / instrument_through_rename_2026-09-28`. 리네임 전후 % 기울기가 표면별로 독립이면 H1/H2, 동기 하락이면 H3를 재오픈합니다.

용량 계획에서 배율 숫자를 지우라는 지침을 반복합니다. “More가 더 빠르다”는 마케팅 문장을 SLO로 올리면, 장애·리셋 아침에 계획이 부서집니다. 대신 Work/Codex **주간 %당 완료 티켓 수**만 남기세요. 카드·프로모 고추천(OKX·국민카드)은 개인 결제 최적화 축이므로 엔지니어링 브리핑 본선에서 제외합니다.

### 에이전트 사고면을 권한 인벤토리로

TechCrunch의 이미지 유출·Verge의 UN 브루트포스 시도 제목·“가장 유능한 모델 학습 일시정지” 보도는 제품 로드맵을 단정하지 않습니다. 다만 같은 주 국내 oneshot 열기와 겹치면, “권한 모두 허용+추론 맥스” 데모 문화가 **사고면과 동시에 소비**됩니다. 회사 좌석 최소 인벤토리: 파일 쓰기, 네트워크 egress, 패키지 설치, 브라우저 로그인 쿠키, 결제 MCP. 각각 default deny, 티켓 단위 allow, 만료 시간. 원샷 쇼릴을 사내 데모로 재연할 때는 네트워크 없는 샌드박스 녹화본만 허가하는 편이 낫습니다.

LocalLLaMA의 Qwen3.8·SSD 스트리밍·듀얼 GPU 글은 클라우드 쿼터 정치의 **탈출 밸브**입니다. 양적 초안·번역·단순 리팩터를 로컬로 빼면 Opus/Sol 주간 %가 남습니다. 24GB VRAM 노트북 기준에서 177B NVFP4 스트리밍은 실험 영역이고, 27B급 Swift/Qwen이 실무 초안 칸에 가깝습니다. “로컬로 다 대체”가 아니라 **티어드 라우팅**입니다.

### 너프 담론의 베이즈 업데이트

D+5에서 마진랩 하락 곡선이 개념글화했다가, D+6 아침에 정정·반박 추천이 올라온 것은 건강한 신호입니다. 관측 창이 이틀뿐이라는 자백은, 통계 대시보드를 **조기 경보**로만 쓰라는 뜻입니다. 품질 regress / 트래픽 mix / 프롬프트 mix / UI 기본 effort 변경을 구분하지 않은 채 “너프다”로 커밋하면, 다음날 반박글이 나와도 슬랙에는 첫 문장만 남습니다. 프로토콜: `alert → 72h watch → 고정 티켓 재측정 → 그다음에야 default model 변경 RFC`.

페이블 음모 드립과 아모데이 복권 밈은 반대 극성의 서사 소비입니다. 전자는 공급자 악의, 후자는 공급자 선지자. 둘 다 구매·좌석 결정의 입력이 되기 쉽지만, AA 표의 Fable 53 vs Opus 58·비용 $7.63 vs $5.98 같은 **숫자 레이어**와 섞지 마세요. 서사는 채널 KPI, 숫자는 라우팅 KPI입니다.

### 실무자용 하루 닫기 체크

1. presence 매트릭스와 KR tier_label 스크린샷이 폴더에 있는가.
2. 오늘 완료한 티켓 중 subagent ON 비율과 토큰 배수 메모가 있는가.
3. Sol을 “없다”고 말한 채널 문장에 surface 한정자가 붙어 있는가.
4. 에이전트 권한 인벤토리에서 만료된 allow가 회수됐는가.
5. AA/보드 숫자를 바꾸지 않았고, 커뮤니티 해석에 미확인 라벨이 붙어 있는가.

이 다섯이 끝나면 D+6의 쇼릴·조롱·카피 전쟁은 **읽기 비용만 지불한 상태**로 닫힙니다. 결제 변경·기본 모델 교체·대규모 해지는 공식 문장과 三日 계측 뒤로 미룹니다.



### 채팅 UX 부채와 크리에이티브 KPI의 분리

챗지피티 추천란의 중립병·단서 과다·지시 rewrite·이미지/롤플 놀이는 Opus 쇼릴 열기와 **같은 제품 군**을 다루면서도 KPI가 다릅니다. 전자는 대화 신뢰·말맛·안전 정렬의 잔여 부채이고, 후자는 도구 실행·멀티모달 조립의 과시입니다. 한 슬랙 채널에 “오늘 GPT는 말맛 별로, 클로드는 영상 신”으로 합치면, 주간 회고에서 **어떤 실패를 고칠지**가 사라집니다. 분리 제안: 말맛 메모와 아티팩트 데모 메모를 나누고, 구독 결정 회의에는 둘 다 가져오되 가중치를 적습니다. 말맛 불만만으로 코딩 좌석을 옮기거나, 쇼릴 성공만으로 채팅 좌석을 올리는 실수를 줄입니다.

구름소라·컬러테마·만화 개념글은 “놀이 채널이 살아 있다”는 신호이지, 엔터프라이즈 채택 지표가 아닙니다. 반대로 기업 매출 역전 개념글(Ramp·TechCrunch 인용)은 **B2B 점유 속도** 이야기입니다. Sol/Astra 채택이 기업 카드 데이터에서 언급됐다는 국내 요약은, 채팅 exile 서사와 긴장 관계에 있습니다. 개인 채팅에 Sol이 없어도 개발자·기업 표면에서는 쓸 수 있다는 **표면 분리**를 다시 강조합니다.

### 원샷 데모를 보안 리뷰에 넣기

“권한 모두 허용”이 추천 댓글의 전제가 되는 순간, 보안 리뷰 없이 사내 해커톤에 복사됩니다. 최소 리뷰 질문 네 개: (1) 네트워크 없이 재현 가능한가, (2) 설치한 바이너리 목록이 로그에 남는가, (3) 사용자 미디어·사내 문서가 프롬프트에 들어갔는가, (4) 종료 후 권한이 회수되는가. 하나라도 아니면 데모 영상만 공유하고 원본 에이전트 세션은 폐기합니다. Verge·TechCrunch의 에이전트 사고 헤드라인은 이 체크리스트를 **분기마다 다시 읽게 만드는 알람**으로만 씁니다.
