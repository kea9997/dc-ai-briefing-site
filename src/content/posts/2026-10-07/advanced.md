## 국내 — 2일차 해부, 은행 해킹, 만들며 자랑, 스코프 통제

### 2일차 해부 (확인=원문 인용·추적 기록 / 비용 효과 미확인)

- **자동 검토의 비용 구조:** 긴 에이전트 세션에서 권한 상승이 필요한 동작마다 두 번째 에이전트가 검토하는 방식이라, 검토 호출이 많을수록 플랜 소진에 섞여 들어갔습니다. Tibo가 스스로 제시한 “2에서 10%”는 **자동 검토를 켠 세션 기준 상한 범위**로 읽는 게 맞고, 켜지 않던 사용자에게 효과는 0입니다. 국내 댓글 “그래서 [[풀 액세스|검토 없이 모든 명령을 바로 실행하게 두는 권한 모드]]만 쓰던 이슈가 있었다”, “토큰 먹으며 검토 vs 하위 모델로 라우팅” 논쟁이 이 지점을 정확히 짚었습니다. 실무적으로는 **풀 액세스 → 자동 검토로 내려올 비용 명분이 생겼다**는 게 2일차의 진짜 의미입니다.
- **반응 지표 읽기:** 추적 사이트 버튼은 표본 편향(관심층·중복 클릭)이 큰 비공식 지표지만, 1일차 대비 🤷 비율이 **약 12.5% → 약 76%**로 뒤집힌 건 “체감 한도에 닿지 않는 개선은 개선으로 안 친다”는 어제 판단을 수치로 재확인합니다.
- **리셋 소문(미확인):** 「티보) 리셋 예정」(07:05, 약 **628**, 본문 “언젠지 모름”), r/OpenAI 「New reset coming soon」, 국내 「원래 내일 리셋 예정을 투표로 돌려 선심 쓰는 척할 것」. 일정 확정 정보 없음. 국내 「조삼모사」 글(속도를 60에서 80% 깎았다가 50% 돌려줬다)은 측정 근거가 없는 주장입니다.
- **Decisions API(확인=공식 문서):** `POST /v1/decisions`, 현재 `gpt-6-luna`만 지원, Responses API 대비 **약 10배 빠른** 타입 지정 답. 질문 타입은 `predicate`(조건 참 확률 0에서 1), `choice`(고정 선택지), `score`(순서 있는 등급의 확률 가중 평균). “몇 주 안 GA”. 어제 r/OpenAI 「Decisions API는 어디 갔나」의 답이 하루 만에 나온 셈이고, Tibo는 “앱 경험 개선에도 쓰겠다”고 했습니다 — 즉 **챗GPT 내부 라우팅·분류에 Luna 기반 판정기가 들어갈 가능성**입니다(해석·미확인). 어제 다룬 Chat/Work 통합·모델 선택 제거와 맞물려 볼 지점입니다.
- **API 등급(확인=OpenAI Developers X):** 유료 5등급 → Build·Launch·Grow 3등급, 최상위 Grow 자격 누적 $1,000 → **$500**. 실제 RPM/TPM 수치는 미공개. 소규모 팀의 상위 레이트 리밋 진입이 빨라집니다.
- **Meetings 베타(확인):** 맥 데스크톱 앱 Pro·Business, 요약·다음 단계를 Space에 저장, Enterprise 예정. Tibo의 사용 제안은 “회의 맥락을 쌓아 코덱스로 로드”. 자동 직결 발표는 아님(정리글도 명시). 녹취 동의·보존 정책이 먼저입니다.

### 은행 해킹과 ‘거절 비대칭’ (확인=헤럴드경제 10/06·금융당국 발표 인용 / 딥시크 실사용 미확인)

금융당국 기준 9/28에서 10/3 사이 최소 6개 은행(신한·하나·KB국민·부산·NH농협·우리)에서 해킹 시도, 유출 신한 약 25,000명·KB 119명·하나 89명. 공격들에서 동일 IP, 그 IP에서 아르텍스 흔적 → 경찰청 사이버수사국 공조. 아르텍스는 공격 목표를 분석해 하위 에이전트에 작업을 분배하는 [[자율 침투 테스트 시스템|사람 대신 에이전트들이 정찰·취약점 탐색·실행을 나눠 맡는 공격 자동화 도구]]이고, 지난달 13일 딥시크 기반 웹 검색을 공식 연동. 기사 인용: 텐센트 보안 연구소의 TSecBench 에이전틱 순위 1에서 4위가 딥시크 플래시 기반, 유닛42(팔로알토)의 7월 사례 — 오픈소스 Hermes Agent + 딥시크로 8개 취약점·460개 이상 시스템 공격, 공격자는 서구 모델의 안전장치 때문에 갈아탔다는 분석. **기사도 이번 사건의 딥시크 사용은 미확인**이라고 적었습니다.

고급 읽기: 미스트랄이 ML4 발표에서 든 논리 — “방어는 결함이 실재함을 증명하는 데서 시작하는데, 닫힌 모델은 그걸 거절한다” — 와 이 사건은 같은 비대칭입니다. 공격 쪽은 이미 **덜 거절하는 모델 + 에이전트 하네스**로 자동화했고, 방어 쪽은 벤더 거절 정책에 막힌다는 것. 그래서 ML4는 검증된 파트너·정부에 **완화된 모더레이션과 확장 사이버 능력 버전**을 먼저 돌리고 있고, r/ClaudeAI엔 「Mythos가 사이버 검증 프로그램(CVP) 계정에서 열렸다」, 「사이버 검증 프로그램 확대」가 올라왔습니다. 국내 금융권 보안팀이라면 (1) 에이전트형 공격의 요청 패턴(짧은 간격 다단계 정찰) 탐지 규칙, (2) 내부 레드팀용 모델 접근 경로(검증 프로그램 신청 또는 온프렘 오픈웨이트)를 이번 분기 과제로 올릴 근거가 생겼습니다.

### 만들며 자랑 — 에이전트 분업이 ‘가족 단위’로 내려왔다 (확인=본문·댓글 / 사용량 미확인)

- 「아들이랑 마크 모드 만드는 중」(약 **2.1천**·**21**·고정닉 추천 **16**·댓글 **43**): **환경 세팅은 6.1 Sol에게 프롬프트 한 번 → 무인 1시간 21분 완료**, 기능·아이콘·UI는 Opus 5.5. 기획은 9살 아들(주인 버프·참여자 디버프 비대칭 설계). 베드락·태블릿 사용자가 많아 배포 경로가 과제라는 후일담. 모델 분업 패턴(**셋업·잡무 = Sol, 디자인·판단 = Opus**)이 어제 「모르는 분야로 돈벌이 하지 마라」 계열의 “도메인 보유자 주도” 테제의 가정판입니다.
- 「(AI 활용 쪽에) 감사합니다 (추첨)」(약 **1.8천**·추천하기 **30**·고정닉 추천 **28**·댓글 **85**): AI 제작 MMORPG, 구글 최상단·**최대 동접 63·신규 계정 3천+**, 해외 클라우드 도쿄 리전, 총비용 “60에서 70”(단위 미기재). 약관·처리방침은 “공공 표준 양식을 손보면 된다”는 댓글, 하단 주소 노출 지적. 1인 서비스의 **컴플라이언스 표면**(약관·개인정보·사업자 표기)이 바이브코딩의 마지막 병목이라는 게 반복 확인됩니다.
- 「드디어 만들었다 영화관」(약 **3.3천**·**18**·댓글 **28**): 영상 직접 입력 대신 **스틸 컷 약 10장 + 음성 전사/자막**으로 멀티모달 컨텍스트를 압축. 구독제, “Pro 3시간에 변화 없음”, “제미나이 Pro 3시간 약 4%”. 비디오 토큰 비용을 피하는 [[키프레임 샘플링|영상 전체 대신 대표 장면 몇 장만 뽑아 넣는 방식]]의 실전 사례.
- 「딸깍으로 만든 레이싱게임」(약 **1.6천**·**11**): 강남 실도로 브라우저 오픈월드, 최대 10인 온라인, 생성 음악 라디오. 사파리 키 입력 버그 제보.
- 「개인용 윈도우 독(슬롭)」(약 **2.4천**·**11**): Windhawk 모드 2종 + 프리셋, “에이전트에게 설치해 달라 하라”. 댓글 「설치해 달라 했더니 구글 AI 울트라가 결제됐다」(사실 여부 미확인·농담 가능성). 어제 채굴 프로그램 건에 이어 **‘에이전트에게 설치 위임’의 결제·권한 리스크**가 또 언급됐습니다.

### 스코프 통제와 노력 단계 (확인=글·댓글 / 체감)

- 「이 짤은 예전부터 틀린 적이 없다」(약 **4.8천**·**33**·댓글 **21**): ‘시킨 대로 vs 알잘딱’ 밈. 실사용 댓글 — “알잘딱의 단점은 시키지 않은 걸 해서 망치는 것, 아스트라 초기가 그랬다. 오푸스 5.5는 불쾌하게 망치는 일이 없다(클로드 코드 사용 데이터로 학습했을 것)”. 반대편 사례: 「아스트라가 너무 넓게 해석했습니다」 — 법령 MCP를 붙인 비판 작업에서 검증 범위를 스스로 넓혔다 좁히며 **사용량 약 3배**. 해법 댓글 “육하원칙으로, 스티어링 여러 번”.
- 노력 단계: 「5.5 보통 뭐 쓰냐」 — “medium이 가장 효율, 중요한 리팩터링·픽스만 high”, 「오푸스 high → max로 올리면 떨어지냐」 — “6.1 Sol은 올리면 오히려 떨어지는 느낌”(미확인). AA 표로 보면 Opus 5.5는 high 54($1.82) → xhigh 56($3.46) → max 58($5.98), 6.1 Sol은 medium 48($0.21) → high 50($0.32) → xhigh 51($0.39) → max 52($0.72)로 **Sol은 상단 3단계 차이가 2점 안**입니다. 체감 “올려도 별 차이 없다”와 일치하는 방향(인과는 미확인).
- 「클로드 5시간 제한은 다 쓰기 어렵네」 — 병렬로 돌려도 5시간 창 55%, 주간 20%. r/ClaudeAI 「한도 리셋 시 자동 이어서 하기」 기능 발견 글과 함께, 클로드 쪽 병목이 **5시간 창보다 주간 상한**으로 옮겨 가는 신호(체감).

### 구독 경제의 두 얼굴 (확인=SemiAnalysis 공개 부분·AI타임스 / 결론 수치 미확인)

- 국내 챗GPT 쪽: 「GPT가 비싸서 클로드 간다는 게 제일 웃김」 — “클로드는 채팅만 해도 사용량이 빠진다”.
- SemiAnalysis(10/05, 대부분 유료): **“앤트로픽 구독이 오픈AI보다 5배 이상 값어치”**. 공개 부분 방법론: 월 구독 = 크레딧, (모델, 토큰 타입)마다 크레딧 소모가 달라 **(플랜, 모델, 워크로드) 튜플**로만 가치가 정의됨, 랩은 크레딧 비용을 조용히 바꿀 수 있어 일 단위 추적 필요. 앤트로픽 추정: 구독은 매출의 약 10%지만 추론 연산의 **40% 이상**, MW당 블렌디드 매출을 약 3,600만 달러 낮춤. “오픈AI의 후한 리셋이 코덱스 도입 급증의 일부 원인이고, 앤트로픽은 계획했던 너프를 여러 번 철회했다”는 문장도 있습니다.
- 동시에 디인포메이션(AI타임스 경유): MS는 직원 클로드 지출을 3분의 1 이상 줄이고 1인 월 사용 한도를 대부분 10만 달러 → 1만 달러로 낮춤, 메타 사내 클로드 코드 이용자 6만 → 3만(자체 Muse Code 6천+, MetaCode 3만+), “토큰맥싱” 억제 예산 도입.

### 미스트랄 라지 4 — 벤더 표 vs AA (확인=공식 블로그·AA 라이브 / 벤더 수치는 벤더 주장)

- **벤더 수치:** DeepSWE v1.1 61.7, SWE-Atlas-QnA 59.4, Terminal-Bench 4 28.3, Coding Agent Index 49.8%(“DeepSeek V4 Pro 0813·Qwen3.8 Max 위”), AutomationBench 59.9%, AA-Briefcase 1,393 Elo, Surge 블라인드 코딩 평가 3.74로 5개 중 2위(Opus 5 4.22 다음, Kimi K3 3.59·GLM-5.3 3.60 위), Dense 200 시각 그라운딩 42% vs Astra 41%, Lakera B3 공격 저항 93.3%, 사이버 프롬프트 거절률은 오픈 모델 최고.

- **간극 해석:** (1) 종합 지수는 지식·추론·수학 비중이 큰 복합 지표라 **도메인 특화(사이버·법률·금융·그라운딩) 강점이 희석**됩니다. (2) 프리뷰이고 RL이 진행 중이라 수치가 움직일 수 있습니다. (3) 첫 응답 1.46초·총 23초로 보아 AA 측정 구성이 **긴 추론 모드가 아닐 가능성**도 있습니다(AA 원표에서 추론 모드 표기 확인 못 함·미확인). 결론: **ML4는 “범용 1등”이 아니라 “거절 없는 보안·문서 그라운딩 + 주권형 배포” 카드**로 보는 게 숫자와 맞습니다.

### 오픈AI 수학 공개 (확인=공식 글·openai/math README / 개별 결과 정합성 미확인)

- Decisions API를 **프로덕션 라우팅에 바로 넣지 말 것.** 베타·Luna 단일 모델, 오분류 비용부터 측정.
- 인기 스킬·에이전트 템플릿을 **위약 대조 없이 전사 배포하지 말 것.**

## 시도 후보 (고급)

1. **자동 검토 vs 풀 액세스 A/B(30분).** 같은 에이전트 작업을 두 모드로 돌려 벽시계 시간·승인 대기 횟수·주간 % 차감을 기록. 2일차 이후 검토 비용이 0이면 기본값을 자동 검토로.
2. **Decisions API 판정기 시험(40분).** 고객 문의 100건에 `choice`(부서)와 `predicate`(긴급 여부)를 걸어 기존 Responses+구조화 출력 분류와 지연·정확도·비용 비교. 확률 임계값별 사람 검토 비율도 산출.
3. **노력 단계 사다리 측정(30분).** 대표 작업 3개 × 6.1 Sol medium/high/xhigh/max로 품질·시간·토큰 비교. AA상 2점 안의 차이가 내 작업에서도 그런지 확인하고 기본 단계를 정하기.
4. **스킬 위약 대조(30분).** 팀이 쓰는 스킬 하나를 같은 길이의 무관 텍스트로 바꿔 10회씩 돌려 통과율·비용 비교. 이기지 못하면 제거.
5. **에이전트형 공격 탐지 규칙 초안(40분, 보안 담당).** 단일 IP·세션의 짧은 간격 다단계 정찰(디렉터리 열거 → 버전 탐지 → 익스플로잇 시도) 시퀀스를 WAF·SIEM 규칙으로 작성하고 지난 2주 로그에 소급 적용.
6. **로컬 MoE 스트리밍 측정(40분, 24GB VRAM·64GB RAM).** POCKET-Darwin-180B-GGUF 또는 Qwen3.8-Flash-Next를 최신 llama.cpp로 띄워 SSD 스트리밍 on/off·컨텍스트 길이별 tok/s 기록. 같은 작업을 클라우드 6.1 Sol medium과 시간·비용 비교.
7. **EmbeddingGemma 2 교체 실험(30분).** 기존 로컬 RAG 임베딩을 교체해 같은 질의 세트의 상위 5 적중률 비교, 이미지 포함 문서 검색도 시험.
