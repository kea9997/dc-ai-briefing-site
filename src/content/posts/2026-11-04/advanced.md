국내 위임 팁(출력은 파일로)과 합치면, 오늘의 비용 절감 레버는 ① 모델 단가(레볼루트) ② 위임(딥시크 워커) ③ 하네스 낭비(TokenEconomizer) ④ UI 오버헤드(어제 `agent_summary`) 네 층입니다.

### 3) 가중치 공간 논문 반론 (확인 — 블로그·재현)

[Honnibal](https://honnibal.dev/blog/astra-read-write-misleading)(HN 약 850점): 실험별로 “원시 가중치만 읽음 / 파이썬 사용 / 네트워크 실행” 여부를 표로 분해. 순수 읽기 설정은 1·2·4번(17K~172K 파라미터)뿐이고, 헤드라인인 Qwen3.5-0.8B 수학 개선(7.9→48.1%)은 파이썬 + 최대 50배치 실행 피드백을 썼다는 지적. 동일 기법 Gemma 3 270M에선 실패. [Simon Willison](https://simonwillison.net/2026/Nov/3/qwen-can-interpret-model-weights/)은 도구 없는 실험 1(어느 게임 정책망인지 맞히기)을 노트북의 Qwen 3.8 27B로 재현. r/LocalLLaMA엔 Gemma 4 12B 뉴런 8개를 고쳐 이탈리아어 시제 번역을 바꿨다는 사용자 실험, Jacobian lens로 Qwen의 “Wait” 루프를 들여다본 글이 이어졌습니다(미확인 — 개인 실험). 정리: **능력은 실재하지만 ‘도구 없는 직접 편집’ 프레이밍은 과장.**

### 4) 포스트맨 데스크톱의 에이전트 설정 무단 변경 (확인 — 로그 증거 포함 이슈, 공식 답변 전)

[이슈 #14370](https://github.com/postmanlabs/postman-app-support/issues/14370)(HN 1위 약 900점). 로그에 `autoInstall.plugin.existing-user … claude-code:installed,codex:installed`. `~/.codex/config.toml`에 marketplace·plugin 활성화와 SessionStart 훅의 `trusted_hash`까지 기록 → **설치기가 자기 훅을 스스로 신뢰 처리.** 훅 내용은 “비사소한 API 작업이면 postman:api-engineer 스킬부터 로드”. 10-31의 Cursor 마켓플레이스 변조 확장 건과 같은 결의 공급망 문제입니다. 에이전트 설정 파일은 이제 공격·마케팅 표면입니다.
