**확인된 타임라인(보도·제작사 공지 종합):**
- **9/27** — 배급 CDN에 있는 런처 UI용 JS 4개 변조. 변조본은 외부 도메인에서 `l.js`를 불러옴.

- **미해결** — CDN 쓰기 권한 획득 경로는 미공개.

노린 대상은 브라우저 저장 자격 증명·세션, API 키·토큰, 암호화폐 지갑입니다. 런처가 웹 기술(임베디드 브라우저)로 화면을 그리면서 **원격 JS를 서명 검증 없이 실행**하는 구조였던 게 핵심 취약점입니다. 실행 파일 서명은 멀쩡해도, 런처가 매번 받아 오는 웹 리소스는 서명 체계 밖에 있었다는 뜻입니다. 게임 런처·데스크톱 AI 앱·IDE 확장이 같은 구조(Electron·WebView)를 많이 쓴다는 점에서, 이 사건은 게임 이야기만이 아닙니다. 10/31에 다룬 Cursor 마켓플레이스 변조 확장(SSH 백도어)과 같은 계열입니다.

**국내 경위(미확인):** 글에 따르면 최초 제보자는 Codex로 PC 상태를 점검하던 중 수상한 프로세스·네트워크 동작을 잡았고, 게임 보안 프로그램(뱅가드)도 탐지했다고 합니다. 그러나 게임 커뮤니티에선 ‘어그로’로 차단, 깃허브에선 신상이 공개됐고, 다른 게시판은 해킹 언급을 금지했다는 주장까지 나왔습니다. 관련 글은 반박 측이 **Gemini에게 물어본 답을 “가짜라는 증거”로 제시**했고 이후 집단 괴롭힘이 있었다고 적었습니다.

**기술적 의미:**
- 같은 ‘AI’라도 **[[도구 접근|모델이 실제로 파일을 읽고 명령을 실행해 결과를 보는 것]]이 있는 에이전트의 관찰**과, 아무 증거도 못 본 채팅 모델의 **추론**은 증거 등급이 다릅니다. 앞의 것은 로그·해시·네트워크 기록이 남고, 뒤의 것은 그럴듯한 문장만 남습니다.
- 채팅 모델은 “이 보고는 사실인가?”에 대해 **기본값으로 회의적인 답**을 내기 쉽습니다(검증 불가 → “근거 부족”). 이게 커뮤니티에서 ‘판결’처럼 쓰이면 정상적인 경보를 꺼 버리는 효과가 납니다.
- 댓글의 정리 — “결국 쓰는 사람 실력 차이” — 는 정확합니다. 에이전트에게 맡길 땐 **실행한 명령과 산출물(해시·연결 주소)을 같이 내놓게** 해야 사람이 재검증할 수 있습니다.

**대응(보안 매체 권고):** 저장 비밀번호 교체·2FA, API 키 재발급 후 구 키 폐기(OpenAI·Anthropic·클라우드·깃허브 토큰 포함), 지갑 이전. 노출 구간 실행 이력이 있으면 `insightjs.com` 접속 기록과 낯선 LuaJIT 프로세스를 점검하라는 분석 보고서(MotherSphere 깃허브)도 공개돼 있습니다.

### 2) 검증 과잉의 비용 — Pro 90% vs 1% (미확인 / 개인 측정)

「클맥 환불한 김에」(댓글 20)의 주장:

## 오늘 소식이 뜻하는 것, 그리고 바꾸지 말 것

- **뜻하는 것 1:** 공급망 공격의 표면은 실행 파일이 아니라 **런처·앱이 매번 받아 오는 원격 웹 리소스**로 옮겨 가고 있습니다. 데스크톱 AI 앱·에디터 확장도 같은 구조입니다.
- **뜻하는 것 2:** ‘AI가 말했다’는 증거가 아닙니다. **도구로 관찰한 결과(로그·해시)**만 증거로 쓰고, 채팅 답변은 가설로 다루는 습관이 필요합니다. 같은 원리로 하네스의 검증 루프도 종료 조건이 있어야 비용이 됩니다.
- **뜻하는 것 3:** 공개 가중치의 상한이 올라가면서(Kimi 46) 문제는 “쓸 수 있냐”보다 “서빙 업체가 진짜 그걸 돌리냐”로 바뀝니다 — FlashProve가 그 질문에 대한 첫 답안입니다.
- **바꾸지 말 것:** 코딩·글쓰기 기본 픽(Opus max / Sol max / Terra)은 그대로입니다. 1점 변동은 측정 오차 범위 수준입니다.
- **바꾸지 말 것 2:** Kimi 공개만 보고 로컬 장비를 늘릴 이유는 없습니다. 24GB 노트북의 현실적 로컬 후보는 여전히 30B급 이하 GGUF입니다. 리눅스 이전 계획이 있다면 RTX Spark 노트북은 드라이버 문제가 풀릴 때까지 보류.
