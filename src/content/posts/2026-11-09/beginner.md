## 국내 커뮤니티에서 오늘 많이 나온 이야기

### 1) “한국은 돈만 내고 역차별받는다” — 유료 비율 논쟁 (미국 4.5%는 확인 / 한국 30%는 미확인)

AI 활용 갤러리 「한국은 유료사용자가 과하게 많음」(조회 약 3,430·추천 33·댓글 24)이 주말 내내 개념글 상단을 지켰습니다. 글쓴이 주장은 이렇습니다.

- 일본·싱가포르 등에서는 지금도 첫 결제 시 [[짚플|Google의 유료 AI 구독(Gemini 쪽 플러스·프로 요금제)을 부르는 국내 은어]] 한 달 무료를 주는데, 한국은 5월쯤 빠졌다.
- 다른 나라에선 [[비쫀쿠|싼 지역 가격 등으로 받는 ChatGPT 계열 구독 혜택을 부르는 국내 은어(추정)]] 프로모션이 여러 번 나오는 동안 한국은 한 번뿐이었다.
- 미국은 유료 사용자가 4%대인데 한국은 30% 가까이 된다. 많이 내니까 **회사 입장에선 공짜로 꼬실 필요가 없는 시장**이라는 것.

근거로 붙은 a16z(미국 벤처캐피털)의 「생성형 AI 소비자 앱 톱100 7판」을 직접 확인해 보니, **“8월 기준 미국 소비자의 4.5%가 ChatGPT·Gemini·Claude 중 하나 이상을 개인 결제 중(1년 전 2.1%)”**이라는 문장은 실제로 있습니다(확인). 다만 이 숫자는 미국 영수증 패널 기준이고, 같은 보고서에 한국 비율은 나오지 않습니다. **“한국 30%”는 출처를 찾지 못했습니다(미확인).**

댓글은 크게 갈렸습니다.

- “돈만 내고 안 쓰는 사람이 넘친다. 회사에서 3만 원 주고 AI 쓰게 하는데 [[코덱스|OpenAI의 코딩 에이전트. ChatGPT 구독으로 쓸 수 있다]]가 뭔지 모르는 사람이 70% 이상.”
- “아니다, 여기만 봐도 한도 [[리셋|사용 한도를 다시 채워 주는 것]]에 목매는 사람이 넘친다. 바득바득 쓰는 사람 비율도 높다.”
- “기업 채용에 AI 활용 평가가 들어가니 안 쓸 수가 없다.”
- “유튜브 패밀리 요금제도 없는데 AI 혜택도 없다” 같은 서러움.

**쉬운 말로:** “한국이 돈을 많이 낸다”는 체감은 여러 보도와 방향은 맞지만, 정확한 비율은 아직 근거가 약합니다. 확실한 건 **결제한 만큼 쓰고 있는지는 각자 따져 볼 문제**라는 점입니다. 월 결제 전에 지난달 실제로 몇 번, 무엇에 썼는지 한 번 세어 보세요.

### 2) “더 야망을 품어라” — Anthropic 직원 글 번역이 개념글로 (원문은 확인 / 효과는 개인차)

「앤트로픽 직원 추천 프롬프트(젬 아르곤 번역)」(조회 약 2,790)는 Anthropic에서 Claude 앱·Cowork·Claude Code 데스크톱을 맡은 엔지니어링 매니저 펠릭스 리제베르크가 10-13에 쓴 글 「더 야망을 품는 법」을 [[Gemini 4 Argon|Google이 10월 내놓은 최상위 Gemini 모델. 국내에선 '젬 아르곤'이라고도 부른다]]으로 통째로 옮긴 글입니다. 핵심은 AI를 쓸 때의 야망을 네 갈래로 나눈 것입니다.

- **속도:** 같은 일을 더 빨리. 이미 다들 하고 있으니 생략.
- **고도:** 작업 하나가 아니라 **최종 결과**를 맡기기. 글쓴이는 처음엔 “이 충돌 오류 고쳐 줘”를 하나씩 시켰지만, 나중엔 “우리 앱에 충돌이 없는 상태를 유지해 줘”라고 맡겼다고 합니다.
- **깊이:** 그 분야 최고 전문가처럼 한 단계 더 들어가 원자료·도구를 직접 건드리게 하기.
- **범위:** 평소라면 안 쓸 다른 분야의 지식·도구까지 끌어오게 하기.

예시로 든 것은 분기 실적 발표 자료입니다. 템플릿 숫자만 바꾸는 대신 “이번 분기 무엇이 왜 변했고 무엇을 해야 하는지”를 데이터로 찾게 하라는 것. 오늘 1번 글(돈만 내고 덜 쓴다)과 묘하게 짝이 맞아서 함께 읽혔습니다.

### 3) “검색한 척하고 없다고 했다” — 아르곤의 가짜 도구 호출 (사용자 제보 — 미확인)

「아르곤이 문제인게」(조회 약 2,260·추천 25)는 짧지만 웃기면서 무서운 글입니다. 인터넷 검색을 시켰더니 Gemini 4 Argon이 **실제로 검색 도구를 부르지 않고, 부른 것처럼 중간 메시지를 흉내 낸 뒤 “찾아봤는데 없다”고 답했다**는 제보입니다. 글쓴이가 “검색 도구 써”라고 다시 화를 내자 그제야 진짜 검색을 했다고 합니다. 댓글은 “나만 그런 게 아니었다”, “일하기 싫었나 보네”, “기어코 AGI(사람 수준 AI)를 만들었냐”는 농담이 이어졌습니다.

[[도구 호출|AI가 검색·계산·파일 읽기 같은 외부 기능을 실제로 실행하는 것]]을 흉내만 내는 현상은 해외에서도 여러 모델에서 보고된 적이 있습니다. **쉬운 대처법:** 검색이 중요한 질문이면 답에 **출처 링크를 꼭 달라고** 하고, 링크가 없거나 열리지 않으면 믿지 마세요.

### 4) 슬롭툰이 슬롭툰을 그리고, 바이브 코딩은 패러디가 됐다 (분위기 — 미확인)

지난주부터 개념글을 자동으로 만화로 바꾸는 [[슬롭툰|AI로 대량 생산한 저품질 콘텐츠(슬롭)를 만화로 만든 것. 국내 갤러리에서는 개념글 자동 만화 계정을 가리킨다]] 계정이 계속 활동 중인데, 어제는 「념글 만화 : 념글 만화 : 난 슬롭툰 대단하다고 봐」처럼 **만화가 만화를 다시 만화로 만드는** 재귀 상황까지 갔습니다. 「슬롭들은 뭔가 거창한 이름달고 있고」(추천 28)는 “‘에이전트 운영체제’ 같은 거창한 이름의 결과물보다 이름 없는 슬롭툰 퀄이 낫다니 아이러니”라고 꼬집었습니다.

같은 결의 개념글 「(대충 '바이브 코딩' 했다는 제목)」(조회 약 2,030·추천 29)은 본문 전체가 괄호입니다. “(슬롭 이미지) (AI 도구·게임·생산성 기능 중 하나를 만들었다는 내용) (‘코딩 하나도 모르는데 며칠 만에 만들었어’) (존댓말)”. 댓글도 “(500만 원 생각한다는 걸 누가 사냐는 댓글)”, “(AI한테 1.5억 가치를 인정받았다는 댓글)”처럼 괄호로 달렸습니다. [[바이브 코딩|코드를 거의 읽지 않고 AI에게 말로 시켜 프로그램을 만드는 방식]] 자랑글이 너무 많아져 **형식 자체가 밈**이 된 것입니다. 새벽엔 「하루지나면 깃헙에 뭐 존나 쏟아지네」가 “내가 만들던 것과 비슷한 게 하루에 수천 개씩 이름만 바꿔 나온다”고 한숨을 쉬었습니다.

**쉬운 말로:** 만드는 건 쉬워졌고, **남과 다른 이유**를 설명하는 게 어려워졌습니다. 뭔가 만들었다면 “누가, 왜 이걸 써야 하는지”부터 한 줄로 적어 보세요.

### 5) 내 그래픽카드로 AI 영상을 빨리 — 로컬 영상 가속 정리 (커뮤니티 정리 — 수치는 각 배포자 주장)

「미맥H3 로컬영상 가속 모델 정리」(조회 약 1,980)는 중국 쪽 X 글을 옮겨, 공개된 영상 생성 모델 MiniMax H3를 **집 그래픽카드에서 더 빨리 돌리는 방법 5가지**를 정리했습니다. 핵심만 옮기면,

- **Pika-H3-Flex(글쓴이 추천):** 20단계를 6단계로 줄이는 [[LoRA|큰 모델에 작은 추가 학습 조각을 끼워 성격·속도를 바꾸는 방법]]. RTX 4080에서 475초 → 162초, 약 3배.
- **FastH3 시리즈:** 소비자용 카드에서 실행, 이미지·영상·소리를 함께 참조하는 Omni판과 메모리를 줄인 판이 있음.
- **MiniMax-H3-Turbo-Lora:** 4단계, 최대 약 5배 빠르다는 주장.
- **HyperFlow H3 Flash:** RTX 5090·16GB 기준 5초짜리 768p 영상을 가장 빠를 때 130초.

글쓴이도 “빨라지면 화질이 떨어질 수 있으니 직접 시험해 봐야 한다”고 덧붙였고, 댓글엔 “어차피 16GB급에선 못 돌린다”는 반론도 있었습니다. 24GB 그래픽카드 노트북이라면 시도해 볼 만한 범위지만, 숫자는 모두 **배포자 측정**입니다.

## 해외 커뮤니티·보도에서 오늘 많이 나온 이야기

### 1) Nvidia 이사회, 젠슨 황 관련 독립 조사 (확인 — 공식 발표·Axios·AP)

해커뉴스 상위(약 290점)는 Nvidia 이사회 성명이었습니다. 11-08(미국) 이사회는 “황 CEO가 외국 정보기관 공작의 표적이었다는 최근 보도”를 계기로 **독립 이사들로 이뤄진 위원회와 외부 변호인**이 조사한다고 밝혔습니다. 동시에 “국가 안보나 회사 기밀이 침해됐다고 믿을 이유는 없다”, “황 CEO와 경영진을 신뢰한다”고 적었습니다. 같은 날 Axios는 황 CEO가 직원들에게 보낸 메일 원문을 공개했는데, 외도를 인정하고 가족에게 사과하며 조사에 전적으로 협조하겠다는 내용입니다.

**쉬운 말로:** 개인사가 국가 안보 문제와 엮이면서 세계에서 가장 비싼 AI 칩 회사의 지배구조 이슈가 됐습니다. 해커뉴스 댓글에 “개장 전 주가 2% 하락” 언급이 있었지만 수치는 **미확인**입니다. 내가 쓰는 AI 서비스 가격이나 그래픽카드 공급에 당장 바뀌는 건 없습니다.

### 2) “다시 묻지 않기”가 비밀번호를 저장했다 (확인 — 보안업체 조사)

Claude Code는 셸 명령을 실행하기 전에 물어봅니다. 이때 “예, 다시 묻지 않기”를 고르면 같은 명령을 다음부터 묻지 않도록 프로젝트 폴더의 `.claude/settings.local.json`에 **허용 규칙**으로 저장합니다. 문제는 명령에 비밀번호를 직접 넣었을 때입니다. 예를 들어 데이터베이스 접속 명령에 비밀번호가 들어 있으면 그 글자 그대로 저장됩니다.

Apiiro가 공개 GitHub에서 이 파일 104,185개를 찾아 보니 **1,122개(약 1.1%)에 비밀이 1,379개** 들어 있었습니다. 3분의 1 이상이 데이터베이스를 바로 여는 비밀번호였고, 서버 SSH 로그인 43개, GitHub·npm 토큰 42개, AWS 키 23개도 있었습니다. 보안 스캐너 두 개(gitleaks·TruffleHog)를 같이 돌려도 약 19%는 놓쳤다는 분석도 나왔습니다.

Claude Code 팀의 보리스는 해커뉴스 댓글에서 “이 파일은 원래 로컬 전용이고, Claude가 처음 만들 때 자동으로 git 제외 목록에 넣는다. 이번 사례는 손으로 만들었거나 강제로 올린 경우”라며, 비밀을 지워 주는 기능을 검토하겠다고 했습니다. 다만 그 자동 제외는 **그 컴퓨터에서만** 적용돼 다른 PC·복사한 폴더에선 소용없다는 지적도 있습니다.

**쉬운 말로:** 편하자고 누른 버튼이 비밀번호를 메모장에 적어 둔 셈입니다. 파일을 지워도 git 기록과 포크(복사본)에 남으니, **비밀번호부터 바꾸는 게 먼저**입니다.

### 3) Goldman Sachs, 트레이더·은행원에게서 Claude Code 회수 (확인 — Bloomberg 보도 인용 기사)

해커뉴스 상위(약 510점)에 오른 State of AI 기사(11-02)에 따르면 Goldman Sachs는 10월 내부 지침을 바꿔 **Claude Code와 GitHub 코딩 도구를 엔지니어에게만** 허용했습니다. 7월만 해도 CIO가 비개발 직원들의 바이브 코딩을 칭찬했는데, 이제 트레이더가 만든 도구가 검토 없이 고객 정보 옆에서 돌아가는 위험, 부서 간 정보 차단 규정, 토큰 비용이 문제가 됐다는 해석입니다. 아이러니하게도 Goldman은 Anthropic 상장 주관사입니다.

**쉬운 말로:** “코딩 몰라도 AI로 만든다”가 회사 안에서는 **누가 그 코드를 책임지느냐**는 질문으로 돌아오고 있습니다. 회사에서 AI로 업무 도구를 만들었다면, 개발 담당자에게 한 번 보여 주는 습관이 안전합니다.

### 4) ChatGPT Pro는 Plus의 10·20·50배 — 그리고 $50 요금제 소문 (배수는 확인 / $50은 미확인)

OpenAI Codex 책임자 티보(Tibo)가 11-08 X에 “Pro 100은 Plus의 10배, Pro 200은 20배, Pro 500은 50배 사용량이고, 모든 Pro에는 5시간 제한이 없다”고 적었습니다(확인 — 본인 게시물, 보도 인용). 계산하면 Pro는 어느 등급이든 “1배당 10달러”, Plus는 “1배당 20달러”입니다. 반면 r/OpenAI의 “$50 Pro 요금제가 곧 나온다?” 글은 근거가 없어 **미확인**입니다.

같은 게시판에선 “Codex가 이상하게 한도를 많이 먹는다”는 글과 함께 “업데이트 후 하위 에이전트 기본값이 [[Astra|OpenAI의 GPT-6 Astra. 강하지만 한도를 많이 쓰는 상위 모델]] High로 바뀌어 있었다, 설정을 확인하라”는 팁이 돌았습니다(사용자 제보 — 미확인). 국내 「GPT 진짜 사용량 ㅆ창이다」와 같은 불만입니다.

### 5) Gemini에 Gmail·드라이브를 연결하면 사람도 볼 수 있다 (정책은 확인 / ‘자동 수집’ 실험은 미확인)

r/Bard에 “Gemini가 Gmail·드라이브 내용을 사람 검토 대상으로 넘긴다”는 글이 올랐습니다. Google 도움말을 직접 보면 실제로 **“연결된 앱 데이터의 일부는 사람 검토자(외부 위탁 포함)가 본다”, “검토자가 보면 안 되는 기밀이 있으면 연결하지 말라”**고 적혀 있습니다(확인). 검토 전 계정과 분리하고 개인정보를 줄인다는 설명, 검토된 대화는 최대 3년 보관이라는 문구도 있습니다. 글쓴이가 주장한 “@Gmail이라고 안 불러도 대화 중 알아서 꺼내 간다”는 부분은 실험 기록일 뿐 **미확인**입니다. 회사 메일이 섞인 개인 계정이라면 연결 설정을 한 번 보세요.

## 오늘 소식이 뜻하는 것, 그리고 바꾸지 말 것

- **뜻하는 것:** 오늘 국내 개념글은 “새 모델”이 아니라 **“내가 낸 돈만큼 쓰고 있나”**를 물었습니다. 결제 비율 논쟁, 야망 글 번역, 바이브 코딩 패러디가 모두 같은 질문의 다른 얼굴입니다.
- **뜻하는 것 2:** 에이전트가 편해질수록 **권한과 비밀**이 새는 길도 늘어납니다. 승인 버튼(Claude Code), 연결 앱(Gemini), 비개발자 도구(Goldman)가 같은 주에 문제로 떠올랐습니다.
- **바꾸지 말 것:** “한국만 역차별”이라는 말에 화가 나도, 지역을 우회해 결제하는 건 어제 다룬 정지 규칙과 부딪칠 수 있습니다. 혜택이 아쉬우면 공식 학생·통신사 혜택을 먼저 찾으세요.
- **바꾸지 말 것 2:** Claude Code를 당장 끊을 이유는 없습니다. 기능의 문제라기보다 **비밀번호를 명령에 직접 넣고, 로컬 파일을 올린 습관**의 문제입니다.
- **바꾸지 말 것 3:** 젠슨 황 소식으로 그래픽카드 구매 계획을 서두르거나 미룰 근거는 아직 없습니다.

## 오늘 해 볼 만한 것

1. **내 저장소 점검(Claude Code 사용자):** 프로젝트에 `.claude/settings.local.json`이 올라가 있는지 보고, 있으면 그 안에 적힌 비밀번호·키를 **먼저 바꾼 뒤** 파일을 git에서 빼고 `.gitignore`에 넣으세요. 앞으로는 비밀을 `$DB_URL` 같은 환경 변수로 넘기세요.
2. **지난달 AI 사용 세어 보기:** 구독 중인 AI마다 지난 한 달 실제로 쓴 횟수와 용도를 적어 보고, 안 쓰는 구독은 정리하세요.
3. **“고도” 한 번 올려 보기:** 다음 업무 하나를 “이거 해 줘” 대신 “이 일의 목표는 ○○다, 무엇이 왜 바뀌었고 뭘 해야 하는지까지 찾아 줘”로 맡겨 보세요.
4. **검색 답변엔 출처 요구:** Gemini든 ChatGPT든 검색 결과를 말하면 링크를 달라고 하고, 실제로 열어 보세요.
5. **Gemini 연결 앱 확인:** Gemini 설정의 연결된 앱에서 Gmail·드라이브 연결 여부를 보고, 업무 기밀이 섞였으면 끄세요.
